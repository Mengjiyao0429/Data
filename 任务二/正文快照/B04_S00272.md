## 正文
tl;dr Easy 10x on generating sequence diagrams, flow charts and system diagrams. I tweeted about using Excalidraw's AI tool recently: I have a hunch that because it's not a standalone tool or a GitHub repo, it didn't get the love it deserved. Aside from ChatGPT/Claude and Supermaven/Copilot, this has been one of the best AI tools I use on an almost daily basis. Anytime I need to build a diagram, the first 50% (if not more) is done with this tool. I even have the option of a mermaid diagram for our docs or a pretty diagram for marketing material. Like any AI tool, don't expect it to be perfect or get you 100% of the way there, but it will definitely save you some time and solve the blank page problem.
