## 正文
I’m implementing search and recommendations for a books catalog using Azure AI Search and I’m looking for guidance on configuring semantic + vector/hybrid search so conversational queries focus on the topic intent (e.g., “anatomy”) rather than generic terms (e.g., “books”, “give”). Scenario / Goal End users submit conversational queries such as: “Hi, how are you — can you recommend books related to anatomy?” “Give me books about anatomy” Our goal is: return books that are actually related to anatomy , and avoid results that match generic words like “books” when the user intent is clearly the topic “anatomy”. What we are observing (problem) In practice, the results appear to be influenced by all words in the query, not just the topic being asked for. For example, we are getting matches driven by generic terms such as “books” (and other non-topic words), even when our intent is to retrieve results strictly related to “anatomy”. Index / Setup (high level) Documents are books (metadata fields such as Id/Title/Author, etc.) We store vectors in a field named: embedding We created a semantic configuration in the Azure portal: SemanticConfigurationName: semantic-trial We are using the .NET SDK ( Azure.Search.Documents ) and SearchClient . (If needed, I can share a sanitized index schema + sample documents.) Approach 1: Pure vector search (searchText = null) We intentionally keep searchText = null to avoid keyword matching and run pure vector similarity over the embedding field. public async Task Results)> PureVectorSearchAsync(float[] vector, int top) { var vectorQuery = new VectorizedQuery(vector.AsMemory()) { KNearestNeighborsCount = top, Fields = { "embedding" } }; var options = new SearchOptions { Size = top, VectorSearch = new VectorSearchOptions { Queries = { vectorQuery } } }; var response = await _searchClient.SearchAsync (null, options); var list = new List (); await foreach (var r in response.Value.GetResultsAsync()) { list.Add(new ScoredBookResult { Document = r.Document, Score = r.SemanticSearch.RerankerScore ?? r.Score ?? 0 }); } return (response.Value.TotalCount, list); } Observed outcome: We still see results that do not appear to be tightly focused on the topic intent (e.g., “anatomy”), and we need clarification on what scoring should be used here (see questions below). Approach 2: Hybrid + semantic reranking (vector + semantic) We run a hybrid request where: We set QueryType = SearchQueryType.Semantic We use SemanticConfigurationName = "semantic-trial" We disable captions/answers for performance We include a vector query with a larger candidate pool ( KNearestNeighborsCount = 50 ) We select only small fields (Id/Title/Author) public async Task Results)> OptimizedSearchAsync( string userQuery, float[] vector, int top = 5) { var vectorQuery = new VectorizedQuery(vector.AsMemory()) { KNearestNeighborsCount = 50, Fields = { "embedding" } }; var options = new SearchOptions { Size = top, IncludeTotalCount = true, QueryType = SearchQueryType.Semantic, SemanticSearch = new SemanticSearchOptions { SemanticConfigurationName = "semantic-trial", QueryCaption = new QueryCaption(QueryCaptionType.None), QueryAnswer = new QueryAnswer(QueryAnswerType.None) }, VectorSearch = new VectorSearchOptions { Queries = { vectorQuery } } }; options.Select.Add(nameof(BookDocument.Id)); options.Select.Add(nameof(BookDocument.Title)); options.Select.Add(nameof(BookDocument.Author)); var response = await _searchClient.SearchAsync (userQuery, options); var list = new List (); await foreach (var r in response.Value.GetResultsAsync()) { list.Add(new ScoredBookResult { Document = r.Document, Score = r.SemanticSearch.RerankerScore ?? r.Score ?? 0 }); } return (response.Value.TotalCount, list); } Observed outcome: With user queries like “give me books about anatomy”, results still appear influenced by generic term
