## 正文
Today, I’m introducing an AI agent workflow to help everyone grind Leetcode data structures and algorithms. Usually, after solving a Leetcode problem, if there's a part I don't quite understand, I have to spend a ton of time digging through documentation, and using Claude or ChatGPT directly burns through tokens way too quickly. To solve this, I built my own agent that automatically analyzes the problem and exports a complete markdown file with all the resources you need. Currently, the repo supports all popular languages like C, C++, C#, Python, JavaScript/TypeScript, Go, Rust, Java, and more. I plan to support even more languages down the road.
