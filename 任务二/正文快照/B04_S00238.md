## 正文

However, when I try to load VADER using tidytext::get_sentiments() , I get an error: package provides sentiment lexicons such as bing, afinn, nrc, etc., which can be loaded using get_sentiments() . However, I would like to specifically use VADER as well. I installed the vader package successfully. However, when I try to load vader using vader_sentiments <- get_sentiments("vader") , I get an error: Error in match.arg(lexicon) : 'arg' should be one of “bing”, “afinn”, “loughran”, “nrc”. My questions are: What is the correct way to load and apply VADER sentiment analysis in R? How do I use the vader package properly on a vector of text reviews?
