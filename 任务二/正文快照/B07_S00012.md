## 正文
I am looking for a Windows utility or tool capable of remapping or converting stylus hover (proximity) events into an active contact/press event system-wide. Requirement On a Windows 10 touchscreen laptop (Lenovo Yoga with active stylus), I want the system to treat the pen's hover state (when the nib is close to the screen without touching) as if it were a physical pen press or click. Key Criteria Platform: Windows 10 64-bit. Core Feature: Automatically trigger a pen down / touch event as soon as the stylus enters hover range, or allow toggling this behavior. Type of Software: Background utility, input remapper, custom driver filter, or tablet configuration tool. I tried to code it with autohotkey v2 but it can't suppress the native pen and stylus inputs hover mode. So, the stylus pen switched between hover mode and contact mode and it caused instabilities. Is there any other existing software or input remapper or a better code autohotkey v2 that can perform this hover-to-touch transformation for active styluses ?
