# Ask HN: AI Agents for Automated Web E2E Testing

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=43187941
- 发布时间：2025-02-26
- 热度：点赞1

## 正文
Hey HN, together with a friend we realized in our engineering jobs that e2e testing is often broken and not worth the effort. But AI Agents could change this massively. There are a couple of reasons why AI agents could revive the topic: - LLMs can automatically adjust tests to the evolving product by simply looking at the git diff and changes in the UI - It'll become much easier and cheaper to have functioning E2E tests Trends supporting this: - Vibe coding is on the rise and the increasing amount of changes needs to be tested - Software will be interactive, like games, where the task and suggestion comes to the user instead of the user navigating to the workflow Are current tools just not good enough yet, or do people simply not care enough about the problem?
