# How to reply to direct user messages?

- 发布时间：2025-07-23

## 正文
I am developing a Telegram business chatbot using n8n for automating replies to users in private messages. Below is some context and the issue I’m struggling with. Background In May 2024, Telegram introduced a new feature (Telegram Business Premium) that allows business accounts to integrate chatbots which can automatically reply to private (direct) messages official Telegram Business settings. The integration is available for business accounts with a premium subscription. What I’ve done so far Created a Telegram bot . Connected the bot to my business account Telegram app’s business settings. Configured n8n on a DigitalOcean Droplet (nginx + Let’s Encrypt SSL, webhook URL with HTTPS). Set up a webhook in Telegram for incoming messages; messages are successfully received in n8n. Parsed webhook data to get business_connection_id, chat_id, message ID, and text. Generated a reply using an AI agent and passed it to an HTTP Request node in n8n. My goal To automatically send a reply to the user in a private chat, so that the answer appears as coming from the business account, not the bot itself. How I’m sending replies I use an HTTP Request node in n8n with the following parameters: Endpoint: Method: POST Body (JSON): { "chat_id": "<chat_id_from_webhook>", "business_connection_id": "<business_connection_id_from_webhook>", "text": "Test message" } All values (chat_id, business_connection_id, and text) are from the current webhook payload. The problem No matter what I try, I keep getting this error from the Telegram API: 400 Bad Request: message text is empty What I have already checked: The webhook is working and data is received correctly. The text parameter is present and not empty. Tried sending only chat_id and text (without business_connection_id). The user has started a conversation with the bot. I tested the request both through n8n, curl, and Postman—same result. SSL certificate is valid and verified. The bot is not in a group; all testing is done 1:1 (private chat). Questions: Is there any additional setup required on the Telegram side for business bots to reply in private messages? Is there a separate API endpoint or a different token required for Telegram Business bots, or should it work through the standard Bot API? What could be causing the "message text is empty" error if the parameter is present and correct in the request? If anyone has managed to implement this scenario (Telegram Business + direct messages + n8n or similar stack), I would appreciate any advice, tips, or working examples. Thank you in advance for your help! I tried to automate replies using an HTTP Request node in n8n, sending a POST request to the Bot API endpoint: with a JSON body like: { "chat_id": "<chat_id_from_webhook>", "business_connection_id": "<business_connection_id_from_webhook>", "text": "Test message" } I also tried these variations: Sending only chat_id and text, omitting business_connection_id Using different text formats (plain English, no special characters, no variables) Sending the same request directly and Postman (not using n8n) Verifying that the bot and the user both initiated the chat (user sent /start first) Double-checking the webhook integration and SSL certificate validity (Let’s Encrypt, green lock in browser) Ensuring that the chat is a 1:1 private conversation, not a group or channel Expected: The message should be delivered to the user as a reply from the business account (not as a standard bot reply), and no errors should be returned. Actual result: I consistently receive the error: 400 Bad Request: message text is empty even though the text field is clearly included and not empty. If needed, I can add request/response logs or screenshots. Any ideas on what might be wrong, or what is missing in my setup?
