I'm using openAI directly in my Android Kotlin App for chatting feature instead of having a custom server that stores the ApiKey and communicates with openAI , then return the response in an endpoint or API . Im using JNI for storing the key in a .c file and returning it to my Kotlin code. Is this secure? Or what is the better approach to store API Keys . src/main/java/vvv.altug.dreamgpt/NativeLibWrapper package vvv.altug.dreamgpt class NativeLibWrapper { companion object { init { System.loadLibrary("native-lib") } external fun getApiKey(): String } } app/jni/native-lib.c include <jni.h> include <string.h> JNIEXPORT jstring JNICALL Java_vvv_altug_dreamgpt_NativeLibWrapper_getApiKey(JNIEnv *env, jobject obj) { return (*env)->NewStringUTF(env, "[已屏蔽疑似令牌]"); } ViewModel: val apiKey = NativeLibWrapper.getApiKey()
