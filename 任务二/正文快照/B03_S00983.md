An AI assistant for PCs powered by Meta's LLaMA3 using Hugging Face, runs on voice recognition, text-to-speech. Send messages, voice/video calls anyone with one sentence. Automated WhatsApp, YouTube(say "play Faded on youtube")Stores persistent chat history in SQLite. Hotword detection like "Alexa" to start assistant. Type/speak any query to ask it
