## 正文
I have a machine-translation model. In this model, I calculate a vector for a given sentence and I take this vector, aggregate with each generated output of RNN and put it into RNN again for calculating next hidden state and generating next output. Because of this, I use the RNN in a non-batched fashion. I want to utilize GPU as much as I can, as well as I'd like to use multiple GPUs. The model computes first sentence transformation easily, when it comes to RNN it is very slow. For example, if I have a batch size of 100, model computes the transformation with one matrix multiplication for each GPU core (batch size of 50 for each core). So it is fast. But when it comes to RNN computation it takes 1 input at a time, not utilising even 1 core. I think this is also a problem in text generation tasks. What is the best approach for training efficiently when it comes to models that takes their output as input? The important part in the code is in the WHILE loop. I am not sure how to utilize this computation.
