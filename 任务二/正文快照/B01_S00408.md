## 正文
I'm interested in learning about your experiences with using LLMs to enhance your programming workflow. Which tools do you integrate into your local environment, and which LLMs do they interact with? How effective have you found this integration to be? I'm particularly looking for a tool that can seamlessly integrate with an existing project. Ideally, it should allow me to manually select specific files to provide context, or automatically choose them. And then add a prompt that asks to do something using those files as input.
