## Description The `cliff.toml` config exists for git-cliff automated changelogs but the release.yml workflow has not been validated end-to-end. A broken config silently produces an empty CHANGELOG.md on release. ## Acceptance Criteria - [ ] A CI step runs `git-cliff --unreleased --output /dev/null` and fails if the output is empty on a branch with merged commits - [ ] `cliff.toml` groups are aligned with the labels used in the issue templates (bug, enhancement, security, etc.) - [ ] A dry-run of the release workflow is documented in CONTRIBUTING.md - [ ] CHANGELOG.md format matches the expected format documented in docs/RELEASE_CHECKLIST.md # Priority Low Estimated Effort Small # Dependencies None
