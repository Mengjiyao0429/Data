# Ask HN: What SQL tools have you used for agile development?

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=12807121
- 发布时间：2016-10-27
- 热度：点赞2、评论1

## 正文
I am looking for applications around Microsoft's SQL Server. I am trying to gather data on which tools would make a DB team agile by automating a lot of their current manual tasks. Some of those tasks include automatic/promoted deployments, database versioning, source control, and being able to reliably test their scripts without having to muck with the database. Some of the tools I have started to investigate are: - Redgate's technologies - ApexSQL's technologies - SSDT (SQL Server Data Tools) - Navicat for SQL Server Are there others out there that I might be missing out on? What have you used to solve these kinds of problems?
