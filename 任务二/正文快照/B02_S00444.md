## 正文
Hi HN, I'm looking to automate some web workflows. Here's an example of a what the tool would do. 1. Open a new tab, navigate to my builds page. Select the latest successful build, and click on the link. Copy the url to the latest build artifact. 2. Open a new tab, go to my deploy tool. Paste in the artifact link from the earlier step. Fill in some other values in a form, and hit submit. I know the above is possible with something like Selenium web driver, but I'm looking for something with a GUI, that would quickly let me put together such workflows. If something like the above doesn't exist, I would like to build it, but I do want to make sure that I'm not missing anything obvious first. I'm thinking of implementing a chrome extension that would use Web APIs to run the steps above. The GUI for building the workflows would live separately.
