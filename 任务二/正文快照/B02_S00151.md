## 正文
Hi HN, We are building Engram, an AI assistant with persistent memory that actually works across sessions. Unlike ChatGPT/Claude, which forget everything after each chat, Engram extracts and indexes facts, preferences, and context automatically. The core problem: LLMs have great short-term memory but zero long-term recall. If you tell Claude about a project in January, it won't necessarily remember in March unless you paste the whole conversation back in. Our approach: Automatic memory extraction using a 14-factor importance scoring algorithm (goals/commitments ranked higher than casual facts) Semantic retrieval + OpenAI embeddings Cognitive profiling that learns your communication style from writing samples Multi-provider routing (Llama 3 for free tier, Gemini for premium to name a few) Technical stack: React + Supabase (PostgreSQL + pgvector), TypeScript throughout. We built an abstraction layer that handles provider failover and rate limiting. Current status: Beta with ~300 users from UPenn (we won the Wharton Innovation Fund Build award). Day-30 retention is ~60%, which suggests the memory system is actually useful. Try it: engramartificial.com Built this because I was frustrated that my AI "assistant" couldn't remember what I told it yesterday. Would love to hear if this resonates with others or if I'm solving a non-problem.
