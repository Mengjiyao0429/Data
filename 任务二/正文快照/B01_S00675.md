## 正文
Hello HN: I've been looking for a new CRM solution for quite a while. I've tried all the major solutions and even some minor ones. A lot of them are expensive, and most of them don't have all the features I need which are actually quite minimal. Tons of features is actually something I'd rule out, since we just need a super basic solution. Are there any good open source solutions out there? I'm not trying to get out of paying (although it'd be nice) but I would / do like to support the open source community. I'm looking for a new open source community to be active in, and I figure there would be no better software than one I will be using every day. Also - if anyone knows of any "up and coming" CRM's you think I should know about, let me know. Minimum requirements: -about 5 users -must be able to have permissions i.e Jack can't see Jill's clients, but admin can see all -no more than $10/user/month -ability to keep track of open / closed deals -ability to track emails sent -mass export of rows would be nice
