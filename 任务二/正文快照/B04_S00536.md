Below is my POC of a yaml workflow that sends info about failed karate tests off to GPT for analysis and then summarizes and prints the results on the Github job summary page. It finds each failed test, gathers context, sends each summary off to GPT for analysis. Then it aggregates the results into a final report. So far it seems to do a good job identifying why tests fail.
