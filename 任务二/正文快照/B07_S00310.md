# Data Analysts required for beta testing an automated predictive analytics app

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=19006414
- 发布时间：2019-01-26
- 热度：点赞1

## 正文
Hi guys, Over the past few months, we've been working on a tool to automatically build and train, deploy machine learning & deep learning algorithms without writing a single line of code (AutoML & AutoDL) The tool is in early stages and still in initial development so we're looking for beta testers. Before spending too much time on this, getting some initial impressions from the people in this community would be tremendously helpful. Here is a link to the landing page: mltrons.com Our main target market includes data analysts in marketing, finance, supply chain etc that have less expertise in coding but are very familiar with BI (It's value adding). The professional data scientists, on the other hand, help us provide insights on how to improve our performance, more features to add etc.
