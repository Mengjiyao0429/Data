# tkinter events - shift modifier with mouse wheel?

- 发布时间：2025-01-28

## 正文
Is it possible to bind Shift and the mouse wheel? I would have thought so, but I'm doing something wrong. For example, the following code binds Shift , Control , Alt and no-modifier to the left mouse button ( Button-1 ) and the scroll wheel turning up ( Button-4 ). import tkinter as tk root = tk.Tk() label = tk.Label(root) label.grid(row=0, column=0, sticky='nsew') label.config(text='Mouse Wheel with Modifiers') def show_event(event, desc=''): label.config(text=desc + ' ' + str(event)) print(desc + ' ' + str(event)) label.bind('<Shift-Button-1>', lambda event, desc='Shift+Click': show_event(event, desc)) label.bind('<Control-Button-1>', lambda event, desc='Control+Click': show_event(event, desc)) label.bind('<Alt-Button-1>', lambda event, desc='Alt+Click': show_event(event, desc)) label.bind('<Button-1>', lambda event, desc='[]+Click': show_event(event, desc)) label.bind('<Shift-Button-4>', lambda event, desc='Shift+Wheel': show_event(event, desc)) label.bind('<Control-Button-4>', lambda event, desc='Control+Wheel': show_event(event, desc)) label.bind('<Alt-Button-4>', lambda event, desc='Alt+Wheel': show_event(event, desc)) label.bind('<Button-4>', lambda event, desc='[]+Wheel': show_event(event, desc)) root.mainloop() If I run through the actions in order given I get Shift+Click <ButtonPress event state=Shift|Mod2|0x2000 num=1 x=107 y=9> Control+Click <ButtonPress event state=Control|Mod2|0x2000 num=1 x=107 y=9> Alt+Click <ButtonPress event state=Mod1|Mod2|0x2000 num=1 x=107 y=9> []+Click <ButtonPress event state=Mod2|0x2000 num=1 x=107 y=9> ### []+Wheel <ButtonPress event state=Mod2|0x2000 num=4 x=107 y=9> Control+Wheel <ButtonPress event state=Control|Mod2|0x2000 num=4 x=107 y=9> Alt+Wheel <ButtonPress event state=Mod1|Mod2|0x2000 num=4 x=107 y=9> []+Wheel <ButtonPress event state=Mod2|0x2000 num=4 x=107 y=9> where the line prefixed with ### was Shift held down with the wheel turned up. I would have expected to see Shift+Wheel here. This suggests that I'm doing something wrong with the '<Shift-Button-4>' binding, but I can't see it. It's clearly possible to bind a mouse event to Shift , and also to bind other modifiers to the mouse wheel. Update Testing on a different machine (ubuntu 24.04, python 3.12, tkinter 8.6) shows the correct result (that is, <Shift-Button-4> ) is recieved. So, this does work on ubuntu, at least in some configurations. Python 3.13 on the problem machine has the original issue. Using xev on the problem machine shows that Scroll and Control+Scroll are coming through as ButtonPress event s with state 0x2010, button5 and state 0x2014, button 5 respectively. (I was scrolling the other way while testing, sorry). However , Shift+Scroll was coming through as state 0x2011, button 7 . Some more information about the "problem machine": it is ubuntu 20.04, running as a VM (VirtualBox 7.0.6 with guest additions) on a Mac OS host (11.7.1). This starts me wondering if Shift+Scroll (which on a mac would be <Shift-MouseWheel> ) is getting garbled in the translation. Finally, there is a (9-year-old, still open) report that horizontal scrolling doesn't work on a linux guest/mac os host with virtualbox. I cannot bind to <Button-6> or <Button-7> . I can bind to <MouseWheel> and <Shift-MouseWheel> , but these don't catch anything.
