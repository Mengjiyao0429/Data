Specifically, I am looking to evaluate by both precision and recall. I was wondering; say if I run an evaluation function which returns the following array: Numpy array containing precision scores for each user. And now I have an array for all of the precision scores across my dataset. If I take the mean of this array and average across say, 20 different scores: Is this equivalent to Mean Average Precision or MAP or am I understanding this a little too literally?
