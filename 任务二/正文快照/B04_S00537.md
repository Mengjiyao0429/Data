## 正文
I have a Spring AI application for calling the OpenAI chat API. The answer should be JSON, so I use structured output . For cost reasons I want to cache the format information. Research To use OpenAI prompt caching, I have to add format information at the beginning, see Prompt caching : Structuring prompts Cache hits are only possible for exact prefix matches within a prompt. To realize caching benefits, place static content like instructions and examples at the beginning of your prompt, and put variable content, such as user-specific information, at the end. This also applies to images and tools, which must be identical between requests. Unfortunately, Spring AI is adding the format information at the end, see Spring AI - Structured Output Prior to the LLM call, the converter appends format instructions to the prompt, providing explicit guidance to the models on generating the desired output structure. These instructions act as a blueprint, shaping the model's response to conform to the specified format. Question Is there a configuration to add the format information to the beginning of the prompt? Or is there a way to generate this format information from Spring AI but add it manually yourself?
