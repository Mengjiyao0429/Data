# Ask HN: Tool(s) for Organizing Project Ideas

- 发布时间：2020-06-22

## 正文
Hi, I'm interested to know what are the tool(s) you would recommend for collecting information for new project ideas? I have a wage software project idea, and I would like to collect everything I write down or find online in one semi-organized space. This involves saving bookmarks to related projects/tools/articles, writing down notes that are displayed in semi-organized shape/form (maybe mindmaps?). The project is still in idea phase so I don't want to use project management or kanban boards for tasks. It can be an offline tool, but could be also a SaaS application with multi-platform support. Looking forward to see what HN community is using.
