# How do I navigate to a new screen and return data back in Flutter?

## 正文
I'm trying to navigate from one screen to another in my Flutter app and return some data when the second screen pops. I want to do this in a clean, idiomatic way using Flutter's navigation system. Here’s what I want: From ScreenA, navigate to ScreenB. In ScreenB, the user enters some text and taps a button. That text is sent back to ScreenA when ScreenB is popped. What’s the recommended way to achieve this in Flutter? I tried using Navigator.push to go from ScreenA to ScreenB, and then I used Navigator.pop in ScreenB to return some data. However, I wasn't sure how to properly receive the returned data back in ScreenA and update the UI accordingly. Initially, I just tried this: Navigator.push(context, MaterialPageRoute(builder: (_) => ScreenB())); But I didn't know where or how to get the result from ScreenB. I expected ScreenA to somehow automatically receive the returned value when ScreenB pops, but nothing happened. I also tried using a global variable to pass the data back, but that felt like a bad practice. I’m looking for the correct, idiomatic way to do this in Flutter — something that uses futures or callbacks the right way.
