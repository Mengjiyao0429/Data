## 正文
I am using AWS Sagemaker to train a Tensorflow image classification model. During training, I get the following log messages: Cardinality of train dataset: 1492 Number of class examples in train dataset: {'Approved': 36, 'Rejected': 36} Cardinality of validation dataset: 328 Number of class examples in validation dataset: {'Approved': 9, 'Rejected': 9} My understanding is that the number of class examples should sum to give the cardinality. In my case I have 36 'Rejected' and 1456 'Approved' in my training dataset. However the logs seem to imply that only 36 examples of each class exist. Similarly, in the validation set there are 9 'Rejected' and 319 'Approved' but only 9 examples of each can be found. I want to understand why the sum of examples doesn't equal the cardinality. I suspect that Tensorflow is assuming I have a balanced dataset and I need to somehow specify that the classes are unbalanced. Is this the case and if so how can I apply class weightings to my estimator.
