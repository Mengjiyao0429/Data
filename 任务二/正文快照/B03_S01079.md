## 正文
ParseCrate: self-hosted document processing API powered by Docling and docling-serve. Converts PDF, DOCX, PPTX, HTML, and more to Markdown/JSON. Sync/async conversion, RAG chunking, optional web UI, offline mode with cached models, and persistent model caching. Docker deployment on CPU (amd64/arm64) or NVIDIA GPU (CUDA, amd64).
