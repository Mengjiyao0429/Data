## 正文
Someone in my family wants to move into software development and I'm in a position where I could probably get them a job as a junior dev if they were able to get the basics under their belt. We're using React so some experience developing React apps would be a minimum requirement for the role. They know a little HTML, but are overwise they're complete beginners. Can anyone recommend a course (free or paid) which can help introduce the basics of HTML/CSS/JavaScript alongside React? Or would it be better to focus on HTML, CSS & vanilla JavaScript first? I've been doing this so long I'm not sure I appreciate how difficult it might be for sometime to jump straight into React. Has anyone got children or family members who were able to pick up React without first learning HTML, CSS & JavaScript?
