# Ask HN: How do you test your CMS-based website deployments?

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=16887986
- 发布时间：2018-04-20
- 热度：点赞9、评论5

## 正文
Enterprise CMSs have a lot of complexity and my small team is looking for tools to improve the efficiency and coverage of QA. After seeing some unexpected bugs post code deployments, we’ve started looking into testing tools which would automate the task of spot-checking the site functionality. This is despite developing on a test server and slotting time for testing. We have a large number of pages, many of which have content changing over time. A test suite would need to accommodate that. I’d love to hear about your choice of tools and process.
