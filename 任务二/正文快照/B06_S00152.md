## 正文
MCP (Model Context Protocol) is a protocol that makes using external tools by Large Language Models easier. What I mean by an MCP client is an app that acts as a user interface for communication between me and LLMs that at the same time provides an easy way for adding new tools. Features of such app that I'm looking for: ability to talk to LLMs using text as well as voice built-in text to speech (for reading answers) attachments support (interpreting images and PDFs) ability to add MCP servers that agent will use in conversations Ideally: FOSS. My OS is Linux Mint, I prefer Flatpak, but you can recommend any Linux-compatible software.
