## 正文
Im trying to recall the exact issue but I specifically looked for commentary on some pattern on stack overflow recently. I dont recall what it was. I felt like AI was not giving me a good answer. One of those scenarios where it would restate the factors I told it and say "I recommend X because Y" but I wasn't fully following the "because Y" part and when pushing it did not become clearer one way or the other. I wanted to see actual discussion around it. Github is the place to go for issues/errors but a but not higher level, borderline philosophical stuff that's not attached to some specific software. edit: Aha, I see now. I was debating setting configuration from a file at deploy vs at runtime. For some software I was writing that would be shared via "deploy with cloudflare" button (which forks the gh repo and runs against your own cf project). I opted for file-based FWIW. Lose the ability to add tenants at runtime but I liked having everything VC'd and in github. Not a project i'll be frequently interacting with/administering so its nice to just go to the repo and see the state.
