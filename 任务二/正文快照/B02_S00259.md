# Ask HN: An AI tool to instantly turn text into infographics sound interesting?

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=44180867
- 发布时间：2025-06-04
- 热度：点赞1

## 正文
Hey HN, I've been working on an AI-powered tool that takes plain text input and generates visual infographics from it. The goal is to make visual content creation for social media, presentations, or even internal docs significantly faster and easier. I made an MVP as web app to see the results and for me it's very good. The Next Step: A Chrome Extension My main focus for the next iteration is building a Google Chrome extension. The idea is that you'd be able to highlight text directly within your browser – say, on LinkedIn, X, or a blog post composer – and instantly generate an infographic from that selected text, ready to be dropped into your content. My Question to the HN Community: Does this sound like a problem worth solving to you? Would you or your team find a tool like this, especially the Chrome extension feature, useful for your content creation or communication workflows? Any feedback, thoughts on potential use cases, or "must-have" features would be incredibly valuable. Thanks!
