# Ask HN: Would you use an AI tool to generate and deploy your back end?

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=44318471
- 发布时间：2025-06-19
- 热度：点赞2、评论1

## 正文
I’ve been working on a tool called BackendIM( ), it takes a natural language prompt like “a leaderboard API with player login” and generates a full FastAPI backend, deploys it, sets up a test UI, handles logs, and lets you export everything to GitHub or ZIP. The goal is to automate repetitive backend setup auth, CRUD, DB, env vars, deploy, so developers (especially frontend/mobile devs) can go from idea to live backend in minutes.
