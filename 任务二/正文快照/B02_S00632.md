# Ask HN: Recommend a software release process for a small, agile team?

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=19607980
- 发布时间：2019-04-08
- 热度：点赞1

## 正文
Hi everyone, We are discussing a complete rewrite of company's medium-sized legacy system - a web app used by a relatively small number of customers - in new technologies (Java BE + Vue or React FE). Let's say we will have around a year to do so, while the old system will still be working, so we're initially talking about mostly internal releases of the new system. Current assumption is that features will be copied 1:1, so the domain is well known. We will have a dedicated tester or two as well. I'm looking for a lightweight process to run this project with around 3-4 other developers. Specifically I want to use existing tools: Atlassian JIRA, Stash and Bamboo. I'm interested about different options and approaches to organize the releases with help of the mentioned tools and how to build a CI/CID pipeline to facilitate these releases. Thanks in advance!
