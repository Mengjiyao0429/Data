# Ask HN: Looking for an open license, but not for AI model training

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=32259827
- 发布时间：2022-07-28
- 热度：点赞2、评论1

## 正文
Hello HN! I, like probably most of you, put a lot of code up on GitHub. With the advent of copilot, I have been growing a little bit uneasy about the software that I write being used for AI training purposes. I generally like releasing my code under an open license, but I would rather the consumer of my software be humans rather than an algorithm. Is there a variant of the GPL or the MIT license that prohibits using code as part of a big corporate training set? With that said, I am planning on moving most of my code over to SourceHut, as I like the overall philosophy a lot.
