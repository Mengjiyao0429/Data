# Ask HN: Shop Software for an indy OS X Developer

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=220511
- 发布时间：2008-06-18
- 热度：点赞1、评论1

## 正文
Can anyone recommend shop software for an OS X developer who wants to sell his software online? The software is freely downloadable but will contain a link to a shop where the software can be registered. The payment can be made through for example PayPal. Suggestions for PayPal alternatives are also more than welcome. The shop needs to be able to generate a serial number. Or have hooks to easily add such functionality. Both hosted and glue-it-together-yourself solutions are welcome. Only requirement: needs to run on Linux. Can be in Ruby, Perl, Python or Java.
