# Ask HN: Simple tool to schedule cloud resource scale up/down?

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=18587308
- 发布时间：2018-12-03
- 热度：点赞4、评论3

## 正文
I'm looking for something which can allow setup/automation of cloud resource scaling schedules or rules. Ideally, it'd be cross-provider and allow something like: - At 6am, if service tier of resource X is less than Y, increase it to Y - From 8am-1pm, unless usage % of resource X is greater than 25%, decrease service tier to Z - Override rule 2 if it's the weekend.. I guess, some system for evaluating and executing scaling rules, based on some criteria, scheduling, and priority. I've done some digging and can't find such a thing. It's obviously possible with scripts and jobs, but I'd like the advantages of some kind of web UI. Anyone using (or built) anything like this?
