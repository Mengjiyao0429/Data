# Ask HN: How do you give a local AI model long-term memory?

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=46252809
- 发布时间：2025-12-13
- 热度：点赞2、评论4

## 正文
I’m running local LLMs using Ollama and hitting the usual wall: small context windows + no persistent memory = hard to solve multi-step or long-horizon tasks. For those who have built serious local setups: How do you give your model persistent memory? Vector DBs? RAG? Fine-tuned adapters? Some kind of external state management loop? Or a custom “memory module” you wrote yourself? I’m looking for practical approaches that let a local model remember past steps, keep working on long tasks, and behave more like an agent with continuity.
