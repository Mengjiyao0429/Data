# Windows 11 is collecting data on which coding agents and developer tools you use

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=50527266
- 发布时间：2026-11-17
- 热度：所在帖点赞717 · 所在帖评论596

## 正文
Windows has been very slow to make a sandbox for AI agents - they launched MXC just a month ago (Oct 7) and Claude Code doesn't even support it yet. So we have people running un-sandboxed agents on Windows, or they use WSL instead. All of this to say, yes I hope they have some non-invasive telemetry to know what to prioritize, because the platform needs features like this pretty urgently.
