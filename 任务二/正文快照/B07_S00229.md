## 正文
I am building software that allows developers to build AI apps without fussing with databases or server side code. Through a website developers would be able to automatically generate API endpoints so that they can begin programming interactive applications powered by AI from day one without needing to build the infra for databases, authentication, authorization, data ingestion, model training and serving, and scalability. Got an MVP and looking for early adopters to try this very early version and give constructive feedback. An example tool build with Graxle can be found here: . It's an AI tool that helps job seekers craft resumes and cover letters personalized for each job they're applying to. All backend tasks for Hirepath, from user sign-up to content creation, run on Graxle.
