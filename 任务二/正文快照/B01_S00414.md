## 正文
This video makes the argugment that code is no longer needed. If you want to create a game the AI itself IS the game. This is similar to the transition from version 11 (code) to version 12 (NN) in Tesla self-driving. There is no code, only the network. This is probably the biggest transition in computer science ever. 53 years of programming becomes the wrong way to use computers. The next generation needs to know how to express ideas using NNs. Karpathy's "Neural Networks: Zero to Hero" is probably the core of the next generation of computer science teaching. The openinterpreter project finally lets me automate computer tasks quickly. I can train a sequence using voice. Emacs has had key-sequence recording for years but now I can sequence anything and do it by voice. LMStudio is probably the fastest way to set up locally running versions of LLMs. We seem to transitioning from "GOTOs considered harmful" to "Code considered harmful"
