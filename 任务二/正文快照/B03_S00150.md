## 正文
I have around 4000 low/medium quality photos I need to upscale and also enhance as much as possible, while keeping details in tact. I tried popular Upscayl , it's ok, but: its models other than Remacri butchered some details, e.g. blurry text on a logo, I think ILoveIMG does usually a better job, but ofc the results are mixed and no batch processing opportunities there its batch feature is as basic as it can get, it'd be great if there was some filtering with e.g. regex So, my requirements are: the app or its model(s) should be able to deblur/denoise the images while upscaling details should be kept as accurately as possible there has to be at least minimal batch processing - but the more options there are for it, the better also, optionally, would be nice if there was a app-only preview mode - Upscayl has a comparison funcitonality, but it needs to save the file to preview, which is a little bit of a flaw Does anyone have a better alternative?
