# Airtable needs improvement, opinion asked

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=26088212
- 发布时间：2021-02-10
- 热度：点赞1

## 正文
I really enjoy working with Airtable. Lately automated some internal processes for staff planning. It became the default tool to kick off projects requiring an underlying database that can be accessed intuitive table UI. However, the more I am building with Airtable I am missing two critical features: More advanced user rights management Real world example: Record A contains work schedule information for employee A. Record B contains this type of information for employee B. Employee A is able to see and change information in record A only. Employee B is able to see but not change information in record B only. Git like version control Right now I am thinking about building an alternative that solves these problems. What are your thoughts on this idea? Looking forward to exchanging thoughts.
