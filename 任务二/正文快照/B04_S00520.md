## 正文
I am working on a project to use the custom configuration with ChatGroq and Spring AI. I am following the steps given here . I configured the application.properties with- spring.ai.chat.client.enabled=false groq.api-key=<api-key> groq.base-url= My code is- public class ChatClientConfig { ("${groq.api-key}") private String GROQ_API_KEY; ("${groq.base-url}") private String GROQ_API_URL; public OpenAiChatModel customGroqChatClient() { OpenAiApi groqOpenAiApi = new OpenAiApi.Builder() .apiKey(GROQ_API_KEY) .baseUrl(GROQ_API_URL) .build(); return OpenAiChatModel.builder() .openAiApi(groqOpenAiApi) .build(); } } When I run the project, I get the error- org.springframework.beans.factory.BeanCreationException: Error creating bean with name 'openAiAudioSpeechModel' defined in class path resource [org/springframework/ai/model/openai/autoconfigure/OpenAiAudioSpeechAutoConfiguration.class]: Failed to instantiate [org.springframework.ai.openai.OpenAiAudioSpeechModel]: Factory method 'openAiAudioSpeechModel' threw exception with message: OpenAI API key must be set. Use the connection property: spring.ai.openai.api-key or spring.ai.openai.speech.api-key property. Follow up- I followed the steps given in the official docs - But, the constructor- var openAiApi = new OpenAiApi(" System.getenv("GROQ_API_KEY")); accepts more params than specified here. constructor OpenAiApi in class OpenAiApi cannot be applied to given types; required: String,ApiKey,MultiValueMap<String,String>,String,String,org.springframework.web.client.RestClient.Builder,org.springframework.web.reactive.function.client.WebClient.Builder,ResponseErrorHandler found: String,String reason: actual and formal argument lists differ in length(errors(1): 19:9-19:101) The constructor OpenAiApi(String, String) is undefined I am unable to understand the issue here, and most websites (and even Chatbots) provide similar code but actually, it does not work.
