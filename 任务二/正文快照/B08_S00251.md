# Ask HN: How do you manage a startups entire monitoring and marketing layer?

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=36785032
- 发布时间：2023-07-19
- 热度：点赞4、评论3

## 正文
Highlight.io was released recently and I'm looking to use it as an alternative to tracking debug sessions on free tiers that can easily be exceeded (e.g. one user has 5k console.errors? you might have no more error logs that month). But it's yet one more thing in the todo list to set up. It lead me to think more about other software like posthog, software for AB tests, marketing, setting pricing, testimonials and perhaps payments API. Now for payments, auth and other things there are a range of starterkits, some specific, like SaaS starterkits. But not the analytics layer, really. Yet I have found for startups showing flames of life, that this layer is vital. Setting these up for each sideproject/startup can be a real drag. The practical usage of these tools often seems superficial - lets' say 80% of projects never making significant amounts of requests or using RAM - the sort of things you could pool together? Is there any company aiming to pull together services from all the above and host an 'all-in-one' solution? They could form partnerships with the likes of Highlight.io and other players to keep the usage amicable and updated without issue. It'd be much nicer to just deal with one company and API for the stack, similar to the days of Google Analytics in the 10s.
