# Ask HN: Would you be interested in an open-source Amazon Echo?

- 来源：Hacker News

- 发布时间：2016-05-16
- 热度：点赞15、评论7

## 正文
Hey HN, A recent Amazon Echo question got a lot of attention here. I've considered developing Alexa Skills, but I don't like that Amazon needs to approve your Skill in order to add it into the Alexa platform for general consumption. One of the blockers here is that if you try to build an integration with a device without that brand's permission, it could be an infringement issue. I was thinking I'd use Wit.ai to build open integrations for all or most home automation devices with open APIs. Users could then use the software in DIY projects with something like a Raspberry Pi and their own server. How much interest is there for this?
