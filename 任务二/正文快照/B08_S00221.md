# Ask HN: Will AI slow down progression?

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=39754994
- 发布时间：2024-03-19
- 热度：点赞2、评论1

## 正文
I keep hearing about how AI is going to replace developers, I can’t see it but if it did would it stop progress? This is my little theory, I work with data so this is data tooling focused but could equally apply to any new technology like rust vs c! If we had the LLM’s ten years ago and startups created to replace software devs with low code solutions then the AI tools would have been automating Hadoop and Map Reduce and there would have been no reason to invent Spark. My reasoning being that new AI can learn how to use our existing tools but I don’t believe they will create new tools? Will AI create new tools or will we be stuck with the current generation of tools forever?
