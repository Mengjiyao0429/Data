# Ask HN: How do you aggregate thought and content snippets?

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=7716110
- 发布时间：2014-05-08
- 热度：点赞1、评论2

## 正文
During the day I find various interesting things (urls, thoughts, quotes) with various level of interest (read now, read later, follow-up if similar topic comes up). I'd like to organize them, but keeping tabs open and putting the URLs and text selection into docs is not really scalable. It kind of works, but now I have 40+ topics, and I'd like to automate parts of it. I'm looking for a solution that would allow me to post these in a non-public way (e.g. e-mail, social network post, custom hosted app) with a limited metadata (url, title, tags, description) and query it periodically (few times a day max) to get all the metadata in a format that I can later reuse (JSON, XML). Of course the easiest would be to create an e-mail account, fetchmail and text processing tool for this, but before doing it, I'd be interested in how others may be doing the same thing. Any thoughts?
