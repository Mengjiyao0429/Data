# A free web-based AI chat tool leveraging Puter

- 发布时间：2025-10-26

## 正文
I've set up a free web-based AI chat tool leveraging Puter. It supports all popular models including Claude, Gemini, GPT, OpenAI series, Deepseek, and Qwen. In theory, it can be used permanently for free—ideal for light users! Key features: Multiple free models: Claude (Sonnet/Opus), Gemini (2.5 Pro/Flash/Lite), GPT, Deepseek, Qwen, etc. Real-time streaming responses. Multi-turn conversation history. Markdown & code block support. Image understanding (where supported). No account or API key required—just open and use. Links: Claude: Gemini: OpenAI: Deepseek: Qwen: Notes: Powered by Puter.js for free API access; your conversational data isn’t collected/stored by the site. If you encounter rate limits or timeouts, just retry later or switch models. Best for everyday Q&A, content writing, code help, data analysis. Happy to welcome casual/light users to try it!
