# Is there a tool out there that extracts the main text in an email?

- 来源：Software Recommendations
- 链接：https://softwarerecs.stackexchange.com/questions/7653/is-there-a-tool-out-there-that-extracts-the-main-text-in-an-email
- 发布时间：2014-07-09
- 热度：浏览62、点赞3

## 正文
What I'm looking for is a tool that detects salutations/greetings, signature, quotation of another email, legal notices and separates all of this "noise" from the main content of the email. For example, given an email: Hi John, Please send me the report on insect repellents you have prepared last week. Best regards, Bob It would extract "Please send me the report on insect repellents you have prepared last week.". Of course it would get more complex if the email is long and contains a lot of quoted text from the previous emails in the same thread. I imagine there must be a tool similar to BoilerPipe, but for emails instead of webpages. Any ideas?
