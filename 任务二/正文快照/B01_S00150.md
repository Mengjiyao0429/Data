## 正文
I’m working on an academic project exploring how a Project Manager could collaborate with AI tools as a kind of “hybrid team” to develop software end‑to‑end. The idea is to start from a very simple input (e.g., a .txt file with a list of requirements) and use AI tools to generate the main deliverables of the software lifecycle: requirements analysis, architecture, frontend/backend code, database, testing, and documentation. I’m looking for AI tools that can cover one or several of these phases, or even a tool that automates most of the process. I plan to try Cursor, but I’d love to hear about other options and real‑world experiences. If you’ve used any AI tools, workflows, or pipelines that helped automate parts of software development, I’d really appreciate your recommendations. Thanks!
