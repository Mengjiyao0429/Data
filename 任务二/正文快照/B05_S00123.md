## 正文
Is there a modern, open-source OCR library with higher accuracy than Tesseract or PaddlePaddle? We have already tried those libraries and found them to be too inaccurate for our purposes (automated software testing). I'm sure there are experimental AI-based tools, but which ones are considered state-of-the-art? Is PaddlePaddle really the best? This is going to be incorporated into a proprietary C# project, so a permissively licensed C# or C(++) library would be best, but something like a command that can be easily run from code or a server program would also work. The language being recognized will primarily be English, and the font will primarily be a DOS-style VGA font .
