# 任务二：AI 应用机会判别与归类（待开展）

## 目标
对任务一同一批次的 329 条清洗记录，逐条判断是否构成“AI 应用机会”（1/0）并输出
0~1 机会置信度；对判为机会的记录，依据附件1标签体系各标注一个功能类别与一个所属行业。

## 判别规则（赛题）
1. 有真实需求：明确终端用户/业务场景，存在寻解、吐槽等需求信号。
2. AI 是核心：AI 能力是解决问题的核心手段。
3. 技术可落地：现有成熟 AI 能力即可实现，无需自研模型或海量标注。
4. 排除情形：纯科普/教程、广告、仅以 AI 为营销噱头的内容直接判 0。

## 计划方法
规则打分（需求/AI核心/可落地信号 + 排除一票否决）为主，关键词字典完成功能/行业归类；
阈值经人工抽标校准；可选 TF-IDF + 逻辑回归做对比实验。

## 交付
result2.csv（采集批次号,记录编号,是否构成机会,机会置信度,功能类别,所属行业）。
