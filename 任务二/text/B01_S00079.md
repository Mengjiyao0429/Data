# Using a SQL worksheet to retrieve information from an XML file

I have a question regarding using a SQL worksheet to retrieve information from an XML file.
 The source system contains a recommendation id and record 123 can have the following recommendation ids:
 123.1
123.2
..
123.10
123.11
 The problem is 123.10 is being saved as 123.1
Any value that ends with a '0' is loosing the '0'. All the rest are saved correctly.
 I'm using XMLGET to retrieve the value and then convert it to a VARCHAR value. This is the SQL script and the line is highlighted:
 SELECT 
 IFNULL(XMLGET(`rcafile.value`, 'PK'):"$"::NUMBER,0) AS RRTID,
 IFNULL(XMLGET(`actionplans.value`, 'PK'):"$"::NUMBER,0) AS SIAR_ID,
 IFNULL(XMLGET(`actionplans.value`, 'RcaID'):"$"::NUMBER,0),
IFNULL(XMLGET(`actionplans.value`, 'RRTRECRecommendationIDUDF'):"$"::VARCHAR,''), <---
FROM {database].{schema}.{table},
 LATERAL FLATTEN(XMLGET({database}.{schema}.{Table}.xmldata,'CASES'):"$") rcafile, 
 LATERAL FLATTEN(rcafile.value:"$") rcacase,
 LATERAL FLATTEN(rcacase.value:"$", RECURSIVE => TRUE) actionplans,
 WHERE 
 GET(rcafile.value,'@') = 'RCAFile' AND
 GET(rcacase.value,'@') = 'RCACase' AND
 GET(actionplans.value,'@') = 'RCAActionPlans'
 The system appears to be converting the value to a number and dropping the last '0' before I can convert it to VARCHAR.
 What can I try next?
