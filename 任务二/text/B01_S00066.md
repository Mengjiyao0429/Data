# Azure Speech recognition not working with Angular + .NET Core

We are trying to implement Azure speech recognition in realtime using its PushStream . The audio is recorded at angular app using navigator.mediaDevices.getUserMedia() . The recorded audio when sent to backend application( .net core ) using socket.io, the audio is not recognized by azure. We are using .NET 8.0, Angular 17, Node.js 18.
 Below combination works, record audio at react/angular and send it to nodejs backend using socket.io package. The received audio stream at nodejs when sent to Azure Speech to text recognition , works seamlessly.
 However, when sent via .NET Core, it is not working. There is no maintained socket.io library available for .NET Core. We've used SignalR in .NET Core which receives audio data in base64Encoded and converted into byte[] to be sent to Azure. But this doesn't work.
 Also tried with web sockets in .NET Core, that didn't work either.
 Basically, we need to know how to make it work by sending recorded audio from Angular, send it to .NET Core, which will use PushStream to send to Azure in realtime. We are not using JS based support from Azure for following reasons:
 Tech expertise for backend available at .NET not on .nodeJS
 Hardcoding Azure speech config at Angular or react is not an option for security reasons.

 disconnect() {
 this.socket.disconnect();
 }
 sendAudioData(audioData: Float32Array) {
 this.socket.emit('send_audio_data', { audio: audioData });
 }
 onReceiveMessage(callback: (data: any) => void) {
 this.socket.on('receive_message', callback);
 }
 onReceiveAudioText(callback: (data: any) => void) {
 this.socket.on('receive_audio_text', callback);
 }
 onReceiveAzureAudioInterimText(callback: (text: any) => void) {
 this.socket.on('interim_result', callback);
 }
 onReceiveAzureAudioFinalText(callback: (text: any) => void) {
 this.socket.on('final_result', callback);
 }
}

 import * as signalR from "@microsoft/signalr";
import { Injectable } from '@angular/core';
@Injectable({
 providedIn: 'root'
 })
 export class SignalrService {
 private hubConnection: signalR.HubConnection;
 constructor() {
 this.hubConnection = new signalR.HubConnectionBuilder()
 .withUrl("http://localhost:8081/hub", {
 withCredentials: true, // Ensure credentials are included in the request
 transport: signalR.HttpTransportType.WebSockets
 })
 .build();
 }
 startConnection() {
 this.hubConnection
 .start()
 .then(() => {
 console.log("Connection started");
 })
 .catch(err => {
 console.log("Error while starting connection: " + err)
 });
 }
 sendMessage(message: string) {
 this.hubConnection.invoke("SendMessage", message)
 .catch(err => {
 console.error(err)
 });
 }
 receiveMessage() {
 this.hubConnection.on("ReceiveMessage", (data: string) => {
 console.log("Received message: " + data);
 });
 }
 sendAudioData(audioData: Float32Array) {
 const plainArray = Array.from(audioData);
 const byteArray = new Uint8Array(audioData);
 var base64String = btoa(String.fromCharCode(...byteArray));
 this.hubConnection.invoke('SendAudioMessage', base64String)
 .catch(err => {
 console.error(err)
 });
 }
}

 {
 var config = SpeechConfig.FromSubscription("xxx", "xxx");
 _pushStream = AudioInputStream.CreatePushStream();
 var audioInput = AudioConfig.FromStreamInput(_pushStream);
 _recognizer = new SpeechRecognizer(config, audioInput);
 _recognizer.Recognizing += async (s, e) =>
 {
 if (!string.IsNullOrEmpty(e.Result.Text))
 {
 Console.WriteLine("Recognized : " + e.Result.Text);
 await Clients.Caller.SendAsync("ReceiveText", e.Result.Text);

 _recognizer.Recognized += async (s, e) =>
 {
 if (e.Result.Reason == ResultReason.RecognizedSpeech)

 Console.WriteLine("Recognized : " + e.Result.Text);
