# 任务四：机会价值评估与优先级排序

第三届甘肃省大学生数据挖掘挑战赛（本科组）赛题《AI 应用场景的智能挖掘与机会评估系统》。

> 输入：任务三的 **30 个主题簇**（`result3.csv`，簇内机会记录为 `Bxx-Sxxxxx` 批号限定）。
> 输出：`result4.csv`（官方 7 列，14 行），按「机会价值分」降序给出优先级。

## 一、任务目标

对任务三每个主题簇做量化评估：从多源指向度、记录规模及补充维度三维度各打 0~100 分，
加权合成「机会价值分」，排序输出优先级（1 最高）。对应官方列：

`采集批次号, 主题簇编号, 主题簇名称, 功能类别, 所属行业, 机会价值分, 优先级`

## 二、方法

### 1. 三维度评分（各 0~100）

| 维度 | 定义 | 归一化（0~100） | 权重 |
|---|---|---|---|
| ① 多源指向度 | 簇内机会记录覆盖的来源网站种类数 | `100 × 来源种类数 / 8`（观测最大 = 8） | 0.35 |
| ② 记录规模 | 簇内机会记录条数 | `100 × 记录条数 / 141`（观测最大 = 141） | 0.35 |
| ③ 商业信号（复合补充维度） | 见下 | 见下 | 0.30 |

**商业信号** = `0.6 × 互动热度分 + 0.4 × 跨批次持续性分`
- 互动热度分 = `100 × log1p(簇内互动热度之和) / log1p(全数据集单条最大热度)`；
  互动热度 = 星标数 + 浏览数 + 点赞数 + 评论数 + 收藏数（任务一真实采集字段），log1p 压缩抑制极端离群。
- 跨批次持续性分 = `100 × 簇覆盖批次数 / 8`（B01–B08 中出现的批次数，反映该机会在 8 个采集批次中反复出现、非偶发）。

> 为什么把补充维度做成复合指标：单纯热度会被个别数万星标的 GitHub 仓库主导；引入「跨批次持续性」后，
> 既看**被真实关注的程度**，也看**在多次采集轮次中是否稳定复现**，更贴近“可持续的商业机会”。

### 2. 价值合成

`机会价值分 = 0.35 × 多源指向度 + 0.35 × 记录规模 + 0.30 × 商业信号`，保留 1 位小数。

**权重依据**：多源指向度与记录规模直接反映“该机会被多来源、多记录共同指向”的交叉验证可信度，二者并重各 0.35；
商业信号反映真实关注度与时间稳定性，信息量略次，占 0.30，避免单一高热帖主导整簇价值。

### 3. 优先级

按机会价值分降序（1 最高）；同分按记录规模降序。

### 4. 敏感性分析（权重稳健性）

在三组替代权重下重算排名，与基础权重比较 Spearman 秩相关与 Top-5 集合重合：

| 替代方案 | 权重（多源/规模/商业信号） | Spearman | Top-5 重合 |
|---|---|---|---|
| 偏记录规模 | 0.30 / 0.40 / 0.30 | 0.982 | 5/5 |
| 偏多源指向 | 0.40 / 0.30 / 0.30 | 0.996 | 4/5 |
| 偏商业信号 | 0.30 / 0.30 / 0.40 | 1.000 | 5/5 |

结论：排序对权重不敏感（Spearman ≥ 0.98，Top-5 稳定），说明优先级结果稳健、非调参产物。
