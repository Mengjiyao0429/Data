## 正文
An AI-powered tool by DeepSeek API for summarizing documents, supporting PDFs, DOCX, images, etc. Features OCR for scanned files, bilingual (Chinese/English) output, multiple summary types, smart caching, and real-time progress tracking, with easy setup .
