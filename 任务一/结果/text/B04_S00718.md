## 正文
I'm trying to set up Node.js using fnm on my Windows machine (using the Command Prompt). I installed fnm and then installed Node.js version 22 with the following commands: winget install Schniz.fnm fnm install 22 When I run fnm use 22 to switch to the installed Node.js version, I receive this error: error: We can't find the necessary environment variables to replace the Node version. You should setup your shell profile to evaluate `fnm env`, see on how to do this Check out our documentation for more information: I tried to set up the environment using the recommended command for CMD: fnm env --shell cmd | call However, this command results in the error below: thread 'main' panicked at library\std\src\io\stdio.rs:1118:9: failed printing to stdout: The pipe is being closed. (os error 232) note: run with `RUST_BACKTRACE=1` environment variable to display a backtrace Additional details: Running fnm list confirms that Node.js v22.14.0 is installed and marked as default: * v22.14.0 default * system Restarting the terminal did not resolve the issue. Using PowerShell instead of CMD appears to work correctly. I'm running this on a Windows system (Windows 10/11). Has anyone encountered this issue or knows why the CMD shell is causing fnm env --shell cmd to fail with this error? Any suggestions for correctly configuring the environment for fnm in CMD would be greatly appreciated.
