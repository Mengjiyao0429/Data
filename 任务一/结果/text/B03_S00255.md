## 正文
I'm trying to be more open-minded and going all-in on using Windows for development for a month. For a lot of the projects I'm working on, devcontainers ( + VSCode) let me pretty much use my native *nix tools. That said, I'm curious - are there any Windows native tools that y'all like to use and that I might want to know about? For example, I've only recently learned of scoop and winget and have since started using them to basically install manage as much of the tools that I need. In addition: - dbeaver for SQL - Insomnia for HTTP testing - stream deck + python for a bunch of automation What other notable Windows native tools do you use?
