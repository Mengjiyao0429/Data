# Is there a workflow builder for AI

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=41182237
- 发布时间：2024-08-07
- 热度：点赞2

## 正文
I am building a tool that anyone can use to try-on new things, and save them to the wardrobe, and then search where saved clothes can be bought online, also I want to add AI-powered assistant/stylist. The workflow is: 1. Upload person image 2. Use SAM to get the segmentation mask for specific clothing 3. Use Stable Diffusion-like models with created mask to generate new clothing on the same person. Question is - what can you use to easily host such workflow to be available API that I can use on my tool's frontend. I know that it is possible with ComfyUI but I want some alternatives that don't rely only on Stable Diffusion, so that instead I can use something like Dalle. Is there a "workflow builder" that can create production-ready APIs, not just a local tool?
