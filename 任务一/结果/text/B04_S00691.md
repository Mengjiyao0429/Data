## 正文
cudaq.kernels.uccsd fails for odd electron counts for some active-space sizes. I am using CUDA-Q 0.14.2 with Python 3.11 for a VQE calculation. Even-electron active spaces work, but when I use the built-in UCCSD ansatz with odd active-electron cases, both qpp-cpu and nvidia fail. For example, the minimal case num_qubits = 10 , num_electrons = 5 fails on qpp-cpu with a subsystem/control-target mismatch error. The corresponding molecular VQE run also fails on the nvidia target inside the cusvsim backend. Steps to reproduce the bug Run the following minimal reproducer: import numpy as np import cudaq cudaq.set_target("qpp-cpu") # also test with "nvidia" num_qubits = 10 num_electrons = 5 n_params = cudaq.kernels.uccsd_num_parameters(num_electrons, num_qubits) theta = np.full(n_params, 0.01, dtype=float).tolist() print("CUDA-Q version:", cudaq.__version__) print("Target:", cudaq.get_target().name) try: print("Precision:", cudaq.get_target().get_precision()) except Exception as e: print("Precision check failed:", e) print("num_qubits =", num_qubits) print("num_electrons =", num_electrons) print("n_params =", n_params) .kernel def test_uccsd(qn: int, ne: int, thetas: list[float]): q = cudaq.qvector(qn) filled = 0 orb = 0 while filled < ne: x(q[2 * orb]) filled += 1 if filled < ne: x(q[2 * orb + 1]) filled += 1 orb += 1 cudaq.kernels.uccsd(q, thetas, ne, qn) ham = cudaq.spin.z(0) print("Calling cudaq.observe...") result = cudaq.observe(test_uccsd, ham, num_qubits, num_electrons, theta) print("Expectation value:", result.expectation()) For qpp-cpu , this gives: CUDA-Q version: CUDA-Q Version 0.14.2 ( 91ab3092e76dab8887d1fdf0c99a2478ca90581c) Target: qpp-cpu Precision: SimulationPrecision.fp64 num_qubits = 10 num_electrons = 5 n_params = 54 Calling cudaq.observe...
