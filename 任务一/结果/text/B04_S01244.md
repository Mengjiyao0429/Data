## 正文
I'm a Computer Science student building a project-based learning path to transition from Deep Learning to Generative AI / LLM Engineering. My learning approach is: Learn concepts only when required by a project Start with classical DL → NLP → Transformers → GenAI → MLOps Use a Fake News Detection system as a long-running project that evolves with each phase This is a high-level overview of my roadmap (details omitted for brevity): Phase 1 – Deep Learning Core Linear algebra, gradients, backprop intuition Dense neural networks, activation & loss functions Optimizers (Adam/AdamW), regularization Project: Basic Fake News Classifier (TF-IDF / NN) Phase 2 – NLP Foundations TF-IDF vs embeddings (Word2Vec, GloVe) RNNs, LSTMs, sequence modeling Project upgrade: Bi-LSTM-based fake news detection Phase 3 – Transformers Self-attention, positional encoding, multi-head attention BERT fine-tuning for classification Tokenization (BPE, WordPiece) Project upgrade: Transformer-based classifier Phase 4 – Computer Vision & Multimodality CNNs, transfer learning Vision Transformers, CLIP Fake image/news consistency checks Phase 5 – Generative AI & LLM Engineering LLM fine-tuning (LoRA / QLoRA) Retrieval-Augmented Generation (RAG) Vector databases Agent-based workflows Project extension: News verification chatbot with explanations Phase 6 – System Design & MLOps FastAPI inference Docker, Kubernetes Model monitoring & optimization Scalable GenAI system design Questions Is this roadmap technically sound for transitioning from Deep Learning into GenAI / LLM engineering roles? Are there critical gaps (e.g., evaluation, inference optimization, data-centric AI) that I should add? Any ordering changes you would recommend based on real-world industry practice? I'm especially interested in feedback from people working with LLMs, production ML systems, or applied GenAI. Thanks in advance
