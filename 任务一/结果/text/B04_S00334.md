# Any recommendations for an AI/LLM assisted shift scheduler application?

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=37462110
- 发布时间：2023-09-11
- 热度：点赞1

## 正文
My workplace has roughly 80 people distributed across the country in smaller units and every unit can have very different working schedules. Currently, our managers spend a considerable amount of time planning the coming shifts, taking employee preferences, vacations etc. into consideration. I'm between options at the moment. I'd prefer to go with some type of SaaS or local app that could make this as painless as possible for us or develop some sort of custom tool for ourselves. So, as I don't really know much about shift planning software offerings, I'm asking you all. Any suggestions? If I were to build it myself, I'd need some platform with an easy way to add all of employees and managers with different roles and the ability to group them into their own units. Then write some algorithms or functions to keep track of what shifts the workers have done and distribute the shifts evenly. It should be possible that every unit had it's own rules. Do you know of any low code platform that could work for cases like this?
