# Show HN: Waifu2x.live – Free AI image upscaler (2x/4x) & video generation

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=46730932
- 发布时间：2026-01-23

## 正文
Hi HN, I built waifu2x.live, a free AI-powered tool for image upscaling and video generation. Features: - Upscale images 2x/4x using Waifu2x AI (great for anime, illustrations, photos) - Text-to-video generation powered by Kling AI, Veo 3, and Sora - No signup required for basic features - Client-side processing for privacy Tech stack: Next.js 14, TypeScript, Tailwind CSS, Supabase, Stripe I've been working on this as a side project. Would love to hear your feedback on the UX and what features you'd like to see next.
