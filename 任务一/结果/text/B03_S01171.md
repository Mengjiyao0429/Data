## 正文
A web-based platform for managing college events and resource booking. It provides role-based access, event scheduling, and real-time resource allocation. Built on the MERN stack with AI-powered recommendations and chatbot support. Includes analytics, feedback systems, and an interactive calendar for efficient event management.
