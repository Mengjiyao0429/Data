# Ask HN: What open-source tool can I use to organize my life/identity?

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=18984796
- 发布时间：2019-01-24
- 热度：点赞3、评论1

## 正文
I'm looking for a self-hosted solution that can manage my personal identity by aggregating data from various sources. It would preferably track the shows I've watched, websites I've visited, my exercise routine, my books, my location, etc... Basically I'm seeking a secure and nonsocial Facebook. I'm currently just using text files with a little automation, but I've realized that this method is both limiting and tedious. I'm hoping that I can find something better to organize my data before all my knowledge becomes fragmented. If I don't find anything that fully meets my criteria, I'll probably just create a personalized dashboard or integrate my data with something like Grafana. Has anyone had any luck with this method? If so, are there any tips you'd like to share?
