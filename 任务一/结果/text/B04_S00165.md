# What is actually sent to the LLM when invoke is called on messages?

## 正文
An AIMessage has "content" and "tool_calls." Is "tool_calls" also sent to the LLM in future calls? The reason I'm asking this is because I want to trim messages down before calling the LLM. In particular, I'm wary of a write_file tool call, which may potentially have a really long input or argument (the content of what's to be written). And this really long input is in in the tool_calls dict, which may get sent to the LLM I did a test and it seems like the "tool_calls" dict in AIMessage is sent to the LLM (I determined this by looking at the number of input_tokens before and after the change). However, if the "content" list in AIMessage contains a block of type "tool_use", the inputs in the "tool_use" block are not sent to the LLM. This is confusing
