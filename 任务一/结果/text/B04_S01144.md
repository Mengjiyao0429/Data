So, I've been working on a segmentation project for about a year now. I've got a few methods which I'm applyiing to segment these images. Using saturation or luminance channels have been working fine for about 40-60% of the images. The big problem are the low contrast images. Clothing on a white mannequin, white background. I need to remove both the mannequin and background. Example Image For the low contrast images, I've been experimenting with machine learning models for segmentation. I trained a custom model based on YoloV8 a few months ago, but I ran into a resolution problem. Yolo will do a fairly good segmentation of the images but in a 1024x1024px image. When I try to translate it to a full-res image (approximately 4000x6000px) it (obviously) get very pixelated. So, it's kind of a more open question. I'm looking for strategies to segment this images. My most recent almost-got-there idea was to use the segmentation from yolo for get a "ring" around the clothing and try segmenting only that area so that I can get the edges of the clothing, and with the help of OpenCV, find the contours and translate it to a binary mask.
