## 正文
P-ADONIS (Prior-enhanced Attention Document OCR Network for Image-to-Structure): This project integrates the Prior-Enhanced Attention text image super-resolution model (ours-PADNet) with an OCR pipeline to significantly improve text recognition quality for noisy or low-resolution PDFs.
