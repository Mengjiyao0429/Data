# Can Postman manage mTLS negotiation using client cert from Windows keystore?

## 正文
I'm trying work out a plan for managing access to mTLS secured endpoints (a.k.a 'client certificates') for developers and testers who generally prefer to use Postman. Ideally, we would use non-exportable client certificates stored in the native windows keystore. The PKI infrastructure for that is existing and known to be working. After a bit of searching an experimentation, I found that Postman will trust CAs based on the native windows keystore. That is, on a fresh install of Postman, I can connect to an HTTPS endpoint with a (server) certificate signed by a (non-public) internal corporate CA. It 'just works', which is fairly promising. However, when attempting to connect to an mTLS endpoint, I am only getting 403 errors. I am able to connect successfully to these endpoints using a browser after being prompted to select an acceptable cert from the windows keystore. I haven't found any Postman documentation about how it uses the windows keystore and whether can use client certificates from the Windows keystore. There are two Github issues that reference this directly: [Feature Request] Use Windows certificate store as a source for client certificate [Feature Request] Native App - Read Client Certificate from Cert Store These two issues were merged. The first was closed as completed in 2022 but the second one shows as open. I haven't found any other information about these features, though. Aside: I have asked the chatbot that comes integrated with Postman about this. Initially it told me that Postman doesn't support the Windows keystore at all (which is definitely wrong.) I then pointed it the first url above (issue 9483) and then it told me that it is actually supported and that I would be prompted for which cert I would like to use (like what happens when using a browser.) Neither of these answers align with what I am seeing. My confidence in this chatbot is very low. Has anyone successfully connected to an mTLS endpoint using a non-exportable client key Windows keystore using Postman?
