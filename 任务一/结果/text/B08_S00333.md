## 正文
I was in college about 10 years ago, neural networks and all that sounded like magic but the theory was already there and the books quite old. I was surprised no one had taken ample advantage of this science to make machines smarter...yet. (It was the lack of good hardware/scaling) Specifically In the API ecosystem there has been lots of API tools to make our lives better: - Doc builders - IDEs (all-in-ones like Stoplight and Postman) - Validators - Scaffolding & testing - OpenAPI spec designers - API Gateways/Reverse proxies ....and much more you can find listed on API tooling sites [1] (yes it's hard to keep track of all the efforts being put out there in the open source world!) From a developer + AI perspective I am a huge fan of what companies like Kite [2] are building towards and I know there must be other companies (like PullRequest [3] who are trying to solve bad code practices) are also thinkering with the idea of leveraging some parts of AI to help developers be more efficient. These two above projects/companies are focusing on programming specifically, taking different approaches. I am interested in the API space, I thought asking the HN hive-mind for a hint: Do you know of upcoming "tools for API devs " or companies that are trying to move into the A.I. territory? I know there are a few companies out there trying to create AI-powered agents to help onboard customers: - Is anyone out there trying to improve Developer Experience programmatically through the usage of intelligent agents? There are also some companies [4] that are working in the API Security/threat detection space using AI (specifically Machine Learning) on large data sets of access logs, training models to detect intrusions and leaks Is anyone working on AI-powered tools for developers and specifically in the API space?
