## 正文
I've been making a simple website which runs an image classification model using keras on an image captured from the users webcam. At the moment, my model is saved in the static folder of my flask app. The problem is in the actual loading of the model. When I try to load the model (in the python file, app.py, which contains my flask app). .route('/') def init(): model = load_model('/static/model/model.keras') return render_template('index.html') it throws an error that the file could not be found. I've tried using requests to load it and write it from github, which resulted in the same error. I've also tried doing .route('/cdn/<path:filename>') def custom_static(filename): return send_from_directory('/static', filename) and loading it from that, but the same error persists.
