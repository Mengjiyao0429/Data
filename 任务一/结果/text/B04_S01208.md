## 正文
I am building a local speech analytics / call quality monitoring system for Russian phone conversations. Current pipeline: Whisper large-v3 for speech-to-text Speaker diarization LLM-based checklist evaluation Local inference only (no cloud APIs) Hardware: RTX 6000 Ada (48GB VRAM) Current model: DeepSeek-R1-Distill-Qwen-32B (4-bit quantized) The task is NOT generic chat. The model needs to: analyze noisy ASR transcripts of phone calls follow strict business checklist rules perform multi-step reasoning handle temporal logic ("did the client provide their name before the operator asked?") detect checklist violations in conversations output deterministic JSON Example checklist items: Did the operator introduce themselves correctly? Did the operator ask the client's name? Did the operator address the client by name later? Did every question contain a polite bridge phrase? Did the operator explain the next action? The biggest issue is reasoning consistency: sometimes the model gives different answers for very similar dialogues. I already improved: transcript formatting prompts ASR normalization checklist decomposition Now I am trying to understand whether I should: stay with DeepSeek-R1-Distill-Qwen-32B move to a larger model (70B) switch to another reasoning-focused local model Important constraints: Russian language support is critical reasoning quality is more important than creativity model must fit into 48GB VRAM (quantized is OK) fully local inference only What models would you recommend for this type of production speech QA / checklist reasoning task?
