## 正文
I’m looking for an AI-based tool that can help with software testing and development automation. My requirements are: I should be able to write test cases in plain English (natural language). The tool should convert those English test cases into executable test code (for example in JavaScript, Java, Python, etc.). It should help with debugging failed test cases or suggest fixes when tests fail. Ideally, it should also help with maintaining or refactoring test code when the application changes. Preferably free or open-source, or at least usable without a heavy enterprise license.
