UPDATE Thanks to the library recommended in the comments (I did not come across that library somehow) I was able to somewhat confirm that my memory driver and little-fs config should be ok. I also wrote some functional tests that use CRC implementation used in little-fs to confirm if my read and write functions work correctly and it seems that they do. I did the following: I generated an array of some random uint8_t values and calculated CRC for it.
