# How to force Eclipse to stay at 100% scaling on Windows 11 with 200% system scaling? (all attempts failed)

## 正文
Environment Windows 11 Pro (24H2) System scaling: 200% (recommended) Eclipse IDE for Java Developers (2025-03 or latest) Display: 4K, 15.6" Problem description I want Eclipse to ignore Windows 11’s 200% scaling and always run at 100% size (no scaling at all). Currently, after applying many suggested fixes, the splash screen starts at 100% but the workspace chooser dialog and the entire IDE (menus, views, editors) are still rendered at 200% scaling. What I have already tried (following common advice) eclipse.ini settings Added the following lines after -vmargs (verified correct placement): text -Dswt.enable.autoScale=false -Dswt.autoScale=100 -Dswt.autoScale.method=nearest -Dswt.autoScale.mode=size -Dsun.java2d.dpiaware=false Windows compatibility settings for eclipse.exe Right-click eclipse.exe → Properties → Compatibility → Change high DPI settings Checked “Override high DPI scaling behavior” Scaling performed by: Application Also tried “System” and “System (Enhanced)” – no change Reinstalled Eclipse (clean install, removed old configuration) Observed behavior The splash screen is small (correct 100% size). The workspace launcher dialog appears at 200% (much larger). After Eclipse starts, all UI elements (toolbar, tree views, editors) are scaled to 200% – still too large. Expected behavior Everything (splash → workspace dialog → main IDE) should be exactly 100% , no scaling applied, even if Windows system scaling is 200%. Additional information The issue is persistent across multiple Eclipse versions (2024-12, 2025-03). Other Java/SWT applications (like a simple custom SWT app) respect the -Dswt.enable.autoScale=false setting correctly on the same system. I do not want any workaround that keeps 200% but makes it “clearer” – I need strict 100% scaling.
