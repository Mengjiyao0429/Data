## 正文
神色语音 (sensevox) 是一款 Windows 开源离线语音输入应用, 配备简洁的图形界面, 采用 SenseVoice-Small 模型, 实现高效精准的语音识别输入. SenseVox is an open-source offline voice input app for Windows with a simple GUI, using the SenseVoice-Small model for efficient and accurate speech recognition.
