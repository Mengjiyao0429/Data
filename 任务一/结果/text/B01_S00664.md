## 正文
I'd like to create a shiny web-based admin/interface/gui for a software that is lacking it as a side project. Is there something that you use or have to use that makes you wish it had a web UI available? I'm thinking along the lines of developer-oriented or DevOps-related pieces of software that sit in the background and work nicely but lack something to let you be more proactive and explore things around rather than running a specific command on the command line and so on. For example a GUI for Redis or Beanstalkd can be highlighted as examples (I know they exist). My aim is to do this nicely for a niche software and hopefully make a little side income with a basic commercial licensing. Interested to hear your thoughts.
