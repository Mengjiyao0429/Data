I want to know that voltage at any given point in time, but I also want to maintain some history so I can draw a graph showing the voltage fluctuation. My thinking is that I can intercept the query results in the RTK Query api slice, and use a normal reducer action to put the data into the store. However, since the RTK query isn't a component I can't use a reducer hook in there. I still think there's got to be a way from the RTK Query API slice to directly interact with the store, but I haven't found any docs on this.
