# Need feedback for AI tool that lets non-technical users query Postgres

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=46911337
- 发布时间：2026-02-06
- 热度：点赞2

## 正文
Hello, I’m part of a small team building TalkBI, an AI-powered BI tool that's currently in public Beta. TalkBI connects to PostgreSQL and lets users query data using natural language instead of writing SQL. It can also visualizate data to make the results easier to understand (for reporting). We’re building this primarily for smaller teams and startups (marketers, product managers, sales, or ops folks) who need access to data but don't know SQL. We’re planning to go live in March and I’d really appreciate honest feedback from the community here — especially around usefulness, limitations, and whether this actually solves a real problem versus existing BI tools. Demo dataset for testing is here if you’d like to try it: Happy to answer questions and open to critical feedback.
