# Ask HN: Is there a list of handy terminal programs that have Docker containers?

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=22848381
- 发布时间：2020-04-12
- 热度：点赞1

## 正文
I recently found a little script called [1] "enhance" that uses AI to enhance an input image. Anyway it conveniently runs as a docker script and you can set use it bash alias. alias enhance='function ne() { docker run --rm -v "$(pwd)/`dirname ${@:$#}`":/ne/input -it alexjc/neural-enhance ${@:1:$-1} "input/`basename ${@:$}`"; }; ne' Sp when I run "$ enhance 'my_image.png' " in my terminal, it downloads the image (if they're not there) and executes the program seamlessly. I thought this was pretty cool as the only dependency your system needs is Docker and all your aliases will resolve when/if they're used. Of course this is not super efficient and may only be useful for certain situations but I think it's a nice way to work. So I'm looking for a list of useful CLI apps that run with docker images, so I can build a list of aliases. Anyone know of any? [1]
