## 正文
We are a team of 5devs and looking for a PM tool for our deliverables. Each project has a list of modules and tasks assigned to each developer. At the beginning of project we estimate the man days required for each task and get an ETA for final delivery. This is currently done in Google sheets. Issues start once the Dev starts, effort increases, there will be delays, people fall sick and don’t work. Now is there a simple tool you suggest where on a daily basis we log work done and pending tasks and the end date automatically gets adjusted? We kind built this also using Google sheets. I am looking for a better tool than sheets for this. Thanks
