## 正文
I recently upgraded my Docusaurus documentation website ( Algo ) to v3.5.2 and shifted my local development environment over to Node.js 20. However, every time I attempt to run a production build using npm run build , the process runs for a couple of minutes and then crashes completely during the webpack client bundle optimization phase.Here is the exact terminal error traceback I am getting: ✘ Client Compiled with some errors in 3.53m ✔ Server Compiled successfully in 2.51m [ERROR] Client bundle compiled with errors therefore further build is impossible. assets/css/styles.38566bb2.css from Css Minimizer plugin Error: Call retries were exceeded -------------------------- assets/css/styles.759f2d8b.css from Css Minimizer plugin Error: Call retries were exceeded I suspect this is a dependency issue because I am running some older packages in this project. Specifically, my package.json includes react-simple-chatbot and an older version of styled-components ( ^4.4.1 ). I tried to update styled-components to the latest version to see if that would play nicer with Node 20, but npm install just blows up with a massive dependency tree conflict: npm error code ERESOLVE npm error ERESOLVE unable to resolve dependency tree npm error npm error While resolving: algo .0.0 npm error Found: styled-components .4.2 npm error npm error Could not resolve dependency: npm error peer styled-components@"^4.0.0" from react-simple-chatbot .5.3 It seems like react-simple-chatbot is locking down the older version of styled-components , but that older version seems to be crashing the webpack CSS minifier workers under Node 20. How can I get around this peer dependency roadblock and fix the Call retries were exceeded crash without entirely ripping out my chatbot component? Any clean workarounds or configuration tweaks to fix the CSS minification process here?
