## 正文
I am looking for a cloud based file storage solution that comes with automated virus scan, scanning everything that gets uploaded. The use case is, a storage space where users can upload their own files securely without being able to view/edit each other's files and once uploaded they are able to generate a public share link the file can be accessed. It would be ideal if the file type and size could be restricted to prevent ridiiculously sized uploads and high risk file types like exes and scripts. An upload limit per user would also help. Lastly, as users would be able to upload files at any given time, the automated virus scan would prevent users from generating share links to potentially mailicious files. Based on my research I am struggling to find this combination of features. Amazon S3 for example doesn't have any built in antivirus system but there appear to be third party providers offering antivirus addons. Is there a single software solution available or will it require multiple tools that work together?
