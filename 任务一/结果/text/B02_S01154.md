## 正文
A production-ready conversational AI app powered by Chainlit and Ollama, with multi-modal document processing, MCP tool integration, and persistent chat sessions. Handles voice input, file analysis (PDF, DOCX, images), and dynamic LLM switching chat profiles. Easily deployable on Railway for fast, scalable cloud hosting
