# Animotion.dev – Updates

## 正文
UPDATES — Dec 6, 2023 Multiple Easings — Now you can specify a particular movement style, known as easing or timing function, for a specific transition area, in addition to the global one. — Dec 3, 2023 WYSIWYG (Under Testing) — What You See Is What You Get. Previously, Animotion relied on the Native Animation Web API for the preview mode. Now, the preview mode uses the exact generated CSS code to preview the animation, relying on the browser's CSS engine. This provides accurate results, offers better and more precise feedback, and allows for the addition of new features, such as the possibility of using multiple easings and more. — Dec 2, 2023 Tooltips Help — Hover over buttons to find out what they do. You can turn tooltips on or off whenever you like. — Nov 29, 2023 Cleaner Code — Percentage steps with the same values are now grouped together for a concise generated code. — Nov 28, 2023 Transform Snapping — Added snapping and guidelines to the transform tool. Keyboard Shortcuts — You can now use Ctrl+Z for undo, Ctrl+Shift+Z or Ctrl+Y for redo, left/right keys to navigate between keyframes, Ctrl+X to cut, Ctrl+C to copy, Ctrl+V to paste, and backspace/del/delete to delete. For Mac users, use the ⌘ Command key instead of Ctrl. — Nov 26, 2023 New domain name — Now you can access Animotion by visiting animotion.dev or Added Undo/Redo — Better experience and more control, now you can easily undo or redo actions. — Nov 25, 2023 GitHub Dark Theme — Now, the code editor has a GitHub dark theme, giving it a fresh look with new colors and better syntax highlighting. — Nov 21, 2023 Keyframe Automation — Keyframes are now automatically created as you edit, based on the playhead's location. — Nov 18, 2023 Dark Mode — New dark theme added. Now, night owl developers can reduce eye strain by switching between light and dark with a simple click. — Nov 14, 2023 Motions Gallery — A new tab with a collection of ready-to-use animations. You can simply choose one, copy the CSS code, and use it without changing anything, or customize it to fit your needs. Edit Animation Button — Previously, the STOP button on the player was used to stop the animation and automatically trigger the editing mode. Now, there's a separate button specifically for manual animation editing, offering a stronger sense of control and less confusion. — Nov 12, 2023 First Beta Release — This is the very first version of the app, like a test. It includes the basic features we've built so far.
