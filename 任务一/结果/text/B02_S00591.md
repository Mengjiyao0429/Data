## 正文
OpenCodeRAG is a RAG (Retrieval-Augmented Generation) plugin for semantic code search powered by locally-hosted embedding models. It features a seamless integration with OpenCode and other AI tools and offers a CLI interface for external usage. It offers hybrid search, image description, persistent memory and local decision model usage.
