## 正文
Most powerful LLMs these days (ChatGPT, Bard) cannot generate images as output, only textual output. Is there an AI tool that generates textual output (or code) that can be put into another app that then generates GUI drafts (wireframes) from that text? I have had success with generating PlantUML code in Bard-AI. But that was not for Wireframes but for sequence diagrams. I gave it this prompt: USER: you are a software architect and visualisation professional. generate a declarative diagram in the d2 language that shows the workflow Dockerfile to DockerRegistry. Draw about 5 steps, from Dockerfile -> Build image -> tag image -> register -> download Bard AI: Sure, here is the declarative diagram in D2 language that shows the workflow Dockerfile to DockerRegistry: title Dockerfile to DockerRegistry workflow actor Developer participant Dockerfile participant BuildImage participant TagImage participant RegisterImage participant DownloadImage Developer -> Dockerfile: Create Dockerfile Dockerfile -> BuildImage: Build image BuildImage -> TagImage: Tag image TagImage -> RegisterImage: Register image RegisterImage -> DownloadImage: Download image This can be pasted into a PlantUML tool which then creates a simple sequence diagram. However I want a prompt/tool combination for GUI wireframes, and that is not a "diagram type" that PlantUML supports (well).
