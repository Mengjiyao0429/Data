## 正文
We built Ravix, an autonomous AI agent you can set up in 60 seconds with a single command. It comes with a dedicated email address for the agent and starts listening for work from your gmail address out of the box. Instead of requiring API keys and per-token billing, it runs on top of your existing Claude Code subscription. If you're already paying for Claude Code, there's nothing else to set up or pay for. You email your agent, it does what you asked, and replies back. Same thread = same session, so context carries across messages. We built this because we wanted something like OpenClaw but kept getting frustrated by the setup: API keys, token budgets, config files, telegram bot creating. If OpenClaw was the windows of agents, this is MacOS. Feedback welcome.
