## 正文
Hi I'm looking for a simple orchestration tool that can help with the following. I have projects in git repos A, B and C each with their own version numbers in configuration file(s). Each configuration file could be json or xml. When creating a new release (using git-flow), I need to: - Syncronise their version numbers - Commit this to each repo - Merge the branches (using `git flow finish`) - Push the master and develop branches (+ tag) to github (this triggers an automated build so at this point I'm done) I've been rolling my own but surely there is a tool that can do this for me?
