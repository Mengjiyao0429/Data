Before I start with all details, I'll like to say that this is project from fun, not expecting too much from it, actually expecting nothing from it, but I wanna see how it would play out. Honestly, from age I became aware of myself, I wanted to do this, so finally took courage and some ca$h to start it. Please don't be too rude and too judgy :P. Just give me some pointers and/or tips. I've created my own VPS hosting provider app from very start. It took me some time to develop this and make it fully functional. I wanted it to be as simple as possible on design, but on functionality, fully advanced. (Little background on me) I'm developer, making simple web apps (mostly to control bots I create), automation bots and scrapers. Honestly, I love Linux so much that I feel like I might explode with from one, and always admire how servers are sold, how they are managed and how one VPS can be created and sold at same time LOL. I spent too much time learning about this (proxmox, python API, dedicated server) and finally decided to take a step in and start with it. Took bigger and powerful dedicated server which can handle lot of VMs at same time (if you wish to know about specs, I can share them), rented IPv4 /24 subnet from some provider (not yet on own ASN, but soon when I get one :D). (Now something about app itself) Like said, design is as simple as possible, bootstrap 5.3, some icons, anime logo and... well that's it. Backend is a bit more advance from frontend. System is automated (fully made by me), so when order is placed, it would check if its paid, if so it would provision VPS and email to user, put data in DB, show in frontend and thats it. Also created fully functional ticket system, to create ticket (admin and user), reply, close and delete (actions for admin only). Cloudflare turnstile implemented for registration and tickets itself. Praying to be good enough for bots and *** LOL. There is referal system which would automatically track and display every single user signed with url code, count % of sale to that user. It's automated and tested, it works!!!! Payments are done (BTC only) with some crypto payment processor, which offers API to automate it. (All in all) It's not much and as said I don't expect too much from it. But it's my own first bigger project on something I always wanted to start. I know there is lot of handle, still I own dedicated server which can handle lot of VMs at same time as said, but IPs are rental. TODO is to get own ASN and buy own IPs.
