I trained Whisper model through LoRA. But there's a problem. The original model directory I trained has a capacity of 2.7G. However, the size of the model directory learned through LoRA is 57M. From this, I found that only additional weighting information was save to the LoRA directory. (That is, the original weighting information is not included.) Therefore, this is a question. How can I combine the existing Whisper model with a model trained with LoRA for Inference?
