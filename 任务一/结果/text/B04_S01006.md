## 正文
I am working on a binary image classification task using TensorFlow/Keras ( TensorFlow version: 2.19.0 ). My model architecture is a multimodal setup with two input branches (CT and PET scans), and its final layer is a Dense layer with softmax activation and num_classes=2 . I am compiling the model with sparse_categorical_crossentropy for the loss function. My data is fed into the model using a custom tf.keras.utils.Sequence data generator. This generator is designed to return sparse integer labels (0 or 1) for each sample in a batch, which aligns with the sparse_categorical_crossentropy loss. The Problem: When I compile and train the model, I encounter an InvalidArgumentError during the model.fit() call, specifically within the tf.keras.metrics.AUC calculation. The traceback consistently points to an internal tensor shape mismatch: InvalidArgumentError: Graph execution error: Detected at node UnsortedSegmentSum_1 defined at ... data.shape = [4] does not start with segment_ids.shape = [8] [[{{node UnsortedSegmentSum_1}}]] [Op:__inference_multi_step_on_iterator_XXXXX] What I've Tried: Direct tf.keras.metrics.AUC : Initially, I used tf.keras.metrics.AUC directly. This caused the InvalidArgumentError . sparse_labels=True (Attempted): I tried passing sparse_labels=True to tf.keras.metrics.AUC , but this resulted in a TypeError: AUC.__init__() got an unexpected keyword argument 'sparse_labels' , indicating this argument is either deprecated or not supported in my TF version. Custom AUC Metric: To explicitly handle the sparse labels and softmax output, I implemented a CustomAUC class. This custom metric inherits from tf.keras.metrics.AUC and, in its update_state method, it extracts the probability of the positive class (index 1) from the model's softmax output ( y_pred ) before passing it to the parent AUC class's update_state . Despite using this CustomAUC metric, the InvalidArgumentError persists during training, suggesting there might be a deeper issue with how tf.keras.metrics.AUC interacts with the Sequence output and sparse labels in this context.
