## 正文
This project is a user-friendly web application that allows you to upload PDFs, DOCX files, or images, automatically extracts text using advanced OCR techniques, and generates concise summaries using Google Gemini 2.5 Flash . Built with Streamlit, it provides a seamless experience for document understanding and quick insight extraction
