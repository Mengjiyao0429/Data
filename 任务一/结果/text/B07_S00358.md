# Ask HN: What platform should I use to create an online bookstore?

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=6543569
- 发布时间：2013-10-13
- 热度：点赞1、评论1

## 正文
I sure hope you guys can help. I have been tasked with creating an online bookstore and was wondering if anyone could recommend which shopping cart software I should start customizing with. The last I worked on shopping card software was about 10 years ago with OSCommerce. I am happy to use it again, but was just wondering if there were better alternatives today based on new technologies and design concepts. I am considering options like Magento, Zen Cart, Open Cart, etc... There are so many now. Preference would be for something: - open sourced - built on PHP + MySQL - has many free responsive templates - has a one-click feature to install modules/add-ons/extensions - has features like voucher and rebate/loyalty management systems I am also open to recommendations on SAAS systems, especially if you created it. Many thanks in advance.
