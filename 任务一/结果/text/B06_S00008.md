## 正文
I built an MCP server for Altium that lets us do automated PCB design review and AI assisted PCB design, that cost a good $1500 in tokens. I experimented with using Astra and the OnShape API to take one of our robot component designs and make a new version of a different size by finding components from the same families of a different size and building a new scaled design against it. That cost about $120. I continued with that and explored two additional design variants. That session cost $2000. This work is a capabilities check not production intent hardware, but I need to be able to explain to the mechanical engineers what is possible. I took a robot simulator that runs in Gazebo and had it rewritten in rust and WASM to run on any machine in the browser. At home I’ve been building an AI first PCB design suite along with a fast autorouter. There is a corpus of 1300 PCBs I have it route. I am building a mechanical CAD system as well, and am working on combining the PCB design program and the mechanical CAD program in to one MIT licensed electromechanical design suite you can use with AI tools to build complete products. I am using AI to design a POE powered studio monitor speaker, and I’m doing a lot of work with LED pendant designs. I have a few video game projects I am working on. I have two MAX 20x plans and I run them both out of credits every week. Again this part is at home, the earlier examples were at work. When agentic coding popped off in January, I wanted to see what the new world would be like. I’ve become very comfortable with these tools and one thing I’ve learned is that when the tool only needs you once every 15 minutes, it’s helpful to have multiple things going at once.
