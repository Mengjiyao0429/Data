## 正文
I am trying to develop an AI Agent using LangChain4J Quarkus plugin, in Kotlin. I have created this class: package prova.langchainkotlin.test import io.quarkiverse.langchain4j.RegisterAiService import jakarta.enterprise.context.SessionScoped (modelName = "test-agent") interface TestAgent { } But I keep on getting this compile errors: Managed bean must be a concrete class or Managed bean declaring a passivating scope must be java.io.Serializable It seems to be a general problem of Kotlin interfaces with SessionScoped. However, I am following the Java version of "Step 01 - Introduction to Quarkus LangChain4j" In which the service is declared as a Java Interface. I tried to remove the " " to make it compile, and it does, but in this way the Agent does not work as expected since it seems to lose the conversation context (And this is somehow expected, because
