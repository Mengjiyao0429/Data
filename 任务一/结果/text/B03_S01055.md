## 正文
Code repository for Semantic Layering in Room Segmentation (SeLRoS). This repository includes 2D Map generation code and Room Information Interpreter code, and a data set containing ground truth, object information file, top view image, and room segmentation results for each environment for an experiment in 30 environments.
