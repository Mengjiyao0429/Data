# How do I use Powershell to test a fileshare has been created?

## 正文
I'm trying to run an installer from another Windows system. The remote Windows system runs a process and in the end a fileshare will be created. From my local machine, I want to test the fileshare path in a loop, and jump out of the loop when the fileshare becomes available. This fileshare requires credentials to access, so when I run: Test-Path \\server\fileshare\ , I always get False even though the fileshare is there. I tried: Test-Path \\server\fileshare\ -Credential $mycreds ($mycreds was setup correctly) But I'm getting: Test-Path: Cannot retrieve the dynamic parameters for the cmdlet. The FileSystem provider supports credentials only on the New-PSDrive cmdlet. Perform the operation again without specifying credentials. I tried New-PSDrive directly, it works when the fileshare is there. But it throws exception when the fileshare is not there yet. I guess I could do try...catch and go back to the loop when fileshare is not found? That feels hacky so I'm wondering if there are better ways... Is there any recommended/established way to achieve this?
