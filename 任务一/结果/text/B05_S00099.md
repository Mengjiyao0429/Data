## 正文
I’m trying to automate sending messages on WhatsApp Web using Selenium (Python) , and I need to attach a PDF file. This is the code I’m using: from selenium import webdriver from selenium.webdriver.common.by import By import os chrome = webdriver.Chrome() # ... code to open WhatsApp Web and enter the chat ... attach = chrome.find_element(By.CSS_SELECTOR, "input[type='file']") attach.send_keys(os.path.abspath("default/archive.pdf")) The file archive.pdf exists and the absolute path is correct. However, when Selenium tries to upload it, WhatsApp Web shows this error message: 1 file you tried to add is not supported. So WhatsApp detects that I tried to attach a file, but says the file type is not supported — even though it’s a regular PDF (and if I attach it manually, it works normally). My questions are: Does WhatsApp Web have any limitations on attaching files through automation (Selenium)? Am I using the correct selector for the file input? Do I need to click the paperclip icon before sending the file path? Is there another recommended way to upload PDF files to WhatsApp Web using Selenium?
