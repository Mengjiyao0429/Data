For a project I have to read the Automatic Servo Tuning (AST) data and display the tuning data graphs for reporting on the machine. The XML is auto generated by the system and I am simply trying to decode the raw CDATA tag into an array of doubles. The XML says it is base85 encoded and I have tried online tools as well as nuget packages to decode the text. So far I have only managed to translate into gibbrish. The forced binary to double BitConverter.ToDouble() method yields wildly fluctuating values which I know are not exactly correct. How can I decode this data into a list of doubles?
