## 正文
Forge DevKit scans your repo (stack, layers, conventions) and generates .claude/ artifacts that AI coding agents read automatically. Then you can uninstall Forge - the generated files work standalone. The core problem: AI agents rationalize skipping work. "The type system covers this test" - sounds reasonable, wrong 50+ times. Forge detects these patterns and blocks them. Also ships an intent router: describe what you want ("add payments") and it resolves prerequisites automatically (specs -> tests -> code). Works with Claude Code, Cursor, any agent that reads project files. Pricing: EUR 29/79/149 (Starter/Pro/Complete). One-time, not subscription. 14-day refund. Generated artifacts work forever.
