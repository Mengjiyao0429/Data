## 正文
I am currently working on an edge computing project. enter image description here The system analyzes both facial micro-expressions ( camera) and Electrodermal Activity (EDA) signals. Hardware Context: Nuvoton NuMicro M55M1 MCU(based on Arm Cortex-M55) Accelerator: Arm Ethos-U55 NPU Toolchain: NuML Studio / TensorFlow Lite for Microcontrollers (TFLM) Technical Challenge: My current model architecture includes a combination of 1D-CNN and LSTM for EDA signal processing and a YOLO-based face detection model followed by a lightweight classifier. While the initial models work well on a PC, I am facing memory and latency constraints when deploying them to the edge device. I am looking to compress a ~2GB model (FP32) down to a manageable size for this MCU while maintaining high accuracy for "repressed" and "anxiety" emotion labels. Specifically, I am considering the following approaches: Quantization: I’ve tried basic INT8 quantization , but I noticed a significant drop in the sensitivity of the EDA signal quality analysis (LSTM-1D CNN hybrid model). Is there a way to apply mixed-precision quantization specifically for time-series data on Ethos-U55? Pruning: Since my classification head has several Dense/Fully Connected (FC) layers, I plan to use L1-unstructured pruning to remove about 25% of the weights. Does the Ethos-U55 NPU effectively speed up inference for sparse matrices, or should I stick to structured pruning? Knowledge Distillation: Would distilling the LSTM-CNN model into a smaller GRU-based architecture be more efficient for this specific hardware's pipeline? What I have tried: I have already experimented with FP16 quantization, which halved the model size, but I need further reduction to fit within the system's SRAM/Flash constraints while ensuring real-time response. Any insights on balancing compression ratio and inference speed for multi-modal sensors on the M55M1 platform would be greatly appreciated.
