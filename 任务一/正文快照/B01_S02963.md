## 正文
This project leverages Apple's Vision person segmentation to replace the background in real-time on iOS devices. An on-device deep learning model segments the human figure, and the mask is refined along the edges using the camera image, so the outline follows the person closely. Built with Metal for smooth, efficient processing on mobile devices.
