## 正文
I have a similar problem to that reported here . In my application I present a TreeView of "health" status items for a system with a number of components. The requirement is to flash a "BAD" health component in the tree for a limited time in response to the health becoming "BAD" - ie to bring attention to the issue. As recommended on other posts, I have used the JavaFX FadeTransition class to accomplish this, however, what I sometimes see is the following: Neighbouring tree nodes sometimes start to flash as well as the target node. This is exacerbated if the TreeView is scrolled. When the number of cycles completes, the flashing node could be left in a partly faded state. Here is the code snippet used: /** * Flash a health tree node using the FadeTransition animation * * item The TreeCell item * rate Flashing rate per second * mins Number of mins to flash */ private void flash(HealthItem item, int rate, int mins) { FadeTransition fadeTransition = new FadeTransition(Duration.seconds(1.0 / rate), this); fadeTransition.setFromValue(1.0); fadeTransition.setToValue(0.0); fadeTransition.setCycleCount(mins * rate * 60); fadeTransition.setAutoReverse(true); fadeTransition.setOnFinished(event -> { item.stopFlash(); }); item.setFlash(fadeTransition); // This method will call the fadeTransition.play() } I will investigate alternate methods for achieving the goal given my observations with FadeTransition. Any suggestions welcome? I have also tried using a similar code but with a TimeLine: /** * Flash a health tree node using the Timeline animation * * item The TreeCell item * rate Flashing rate per second * mins Number of mins to flash */ private void flash(HealthItem item, int rate, int mins) { KeyFrame keyFrame = new KeyFrame(Duration.seconds(1.0 / rate), new KeyValue(this.textFillProperty(), Color.PINK)); Timeline flasher = new Timeline(); flasher.getKeyFrames().add(keyFrame); flasher.setCycleCount(mins * rate * 60); flasher.setAutoReverse(true); flasher.setOnFinished(event -> { item.stopFlash(); }); item.setFlash(flasher); // This method will call the .play() method } This also has the same odd behaviour where adjacent nodes to the flashing node also flash.
