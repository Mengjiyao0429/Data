## 正文
I am building a RAG application using Node.js, Sequelize, and PostgreSQL with the pgvector extension. I have successfully enabled the vector extension in my database. I am now trying to create a Sequelize model for my knowledge_base table, but I'm getting a TypeScript error when I try to use DataTypes.VECTOR . What I'm trying to do : I want to define a KnowledgeBase model that includes an embedding field of type vector(768) . What I have done I have followed the pgvector/sequelize documentation: Installed pgvector : npm install pgvector I am registering the types in my main database connection file before any models are defined. This is my db.config.ts file : const sequelize = new Sequelize(process.env.DATABASE_URL as string, { dialect: "postgres", logging: false, dialectOptions: { ssl: getSslConfig(), }, }); const initialize = async () => { try { // Create vector extension if it doesn't exist await sequelize.query("CREATE EXTENSION IF NOT EXISTS vector"); pgvector.registerTypes(Sequelize); console.log("Vector extension and type registered successfully"); } catch (error) { console.error("Error initializing vector support:", error); } }; // Initialize vector support initialize(); export default sequelize; This is my KnowledgeBase.model.ts file : KnowledgeBase.init( { id: { type: DataTypes.UUID, defaultValue: DataTypes.UUIDV4, primaryKey: true, }, courseId: { type: DataTypes.UUID, allowNull: false, references: { model: Course, key: "id", }, }, embedding: { type: DataTypes.VECTOR(786), allowNull: false, }, content: { type: DataTypes.TEXT, allowNull: false, },.... When I define the embedding field, TypeScript gives me the following error: Property 'VECTOR' does not exist on type 'typeof import("sequelize/types/data-types")'. ts(2551) It seems like TypeScript doesn't know about the VECTOR type, even though I've called pgvector.registerTypes(sequelize) . Thanks in Advance !
