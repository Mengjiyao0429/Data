I was trying to build a RAG LLM in LangChain using open source models. I use 2 approaches here, Conversational Retrieval Chain and RetrievalQAChain. But while generating the response the LLM is attaching the entire prompt and context at the output. Can anyone please tell me how can I remove the prompt and the context section and get only the answer in response ? This problem occurs in the text generation models, mistralai/Mixtral-8x7B-Instruct-v0.1 and bigscience/bloom so that the results of the answer are also truncated, not reaching the end. When I tried to use the text2textgeneration model, such as Flan-t5, this problem did not arise, it's just that the resulting answer was not as good as the text generation model.
