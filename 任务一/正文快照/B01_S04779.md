## 正文
I am using the Vertex AI BatchPredictionJob API ( reference ) to run asynchronous inference jobs. I need to notify an external system as soon as a job reaches a terminal state (either JOB_STATE_SUCCEEDED or JOB_STATE_FAILED ). I would like the payload to ideally include the jobId , the final state , and the output location. Current blockers: I have explored the Google Cloud Console but haven't found a native "webhook" field in the Batch Prediction configuration. I've looked into Cloud Logging sinks and Pub/Sub triggers, but I am struggling to identify the specific event pattern or service integration required to bridge Vertex AI to an external HTTP endpoint. Specifically, I am looking for: Is there a built-in notification configuration within the Vertex AI API? If not, what is the recommended event-driven pattern (e.g., Eventarc or Log Sinks) to trigger a Cloud Function that can then execute the webhook POST request? Is it possible to do this without manual polling of the job status?
