## 正文
I've been working on a project recently, where the goal is to extract the main topic mentioned multiple times in a given text. To achieve this, I've been using a consistent prompt with the same set of parameters in two environments: the Azure OpenAI Chat Playground and directly within a .NET application using the GetChatCompletions() function. Here's where it gets interesting: with one example text, when using the Chat Playground, the output reliably identifies one main topic as expected. However, running the exact same prompt and parameters through my .NET code results in the identification of two or even three topics within the output. Notably, some of these topics are mentioned only once in the text, diverging from my project's objective. This discrepancy has left me puzzled. Could there be additional parameters or settings applied by the Chat Playground that aren't visible or accessible to us users? I'm reaching out to see if anyone else has encountered a similar situation or if there's any insight into why this might be happening. Your expertise and any advice on how to achieve consistent results across both platforms would be greatly appreciated. Could it be a hidden parameter or a difference in how the environments process the prompts? Looking forward to your thoughts and suggestions! Parameters that I am using: Temperature: 0.2, MaxTokens: 800, NucleusSamplingFactor: 0.95, FrequencyPenalty: 0, PresencePenalty: 0, ChoiceCount: 1 In Chat playground, Past messages included: 1. My .NET code also only includes one past message from user. Both of them are using the same model deployment.
