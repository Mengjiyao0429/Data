## 正文
I'm building a proof of concept that displays an existing Fusion design in Autodesk Viewer. My APS application can complete OAuth authorization, but retrieving the design's manifest fails. Configuration - Application type: Desktop, Mobile, Single-Page Appenter image description here - Authentication: Three-legged OAuth with PKCE - Requested scopes: `data:read viewables:read` - Subscription: Active APS Free - The developer hub and APS Free subscription belong to the same Autodesk team. - The Autodesk account used for authorization is also the account used in Fusion. Failing request GET Authorization: Bearer <access_token> The URN represents the saved Fusion version published to my application. I am retrieving an existing viewable, not submitting a translation job. The response is HTTP 403 with: { "errorCode": "AUTH-001", "developerMessage": "The client_id specified does not have access to the api product" } API Access discrepancy Under App Settings → API Access, the portal offers 19 APIs, but Model Derivative API is not listed. However, Model Derivative API does appear in the application's **API Usage** dropdown. The APS rate sheet also lists a Free-tier allowance for Model Derivative. What I tried 1. Enabled Data Management API. 2. Confirmed that the APS Free subscription is active and belongs to the developer hub's team. 3. Temporarily selected and saved all 19 available APIs. 4. Disconnected and repeated OAuth authorization, then retried the manifest request. The same HTTP 403 / AUTH-001 response occurs. Question How should Model Derivative API access be enabled when it is missing from the application's API Access list? The only options to select from are: AEC Data Model Application Management BIM 360 BuildingConnected Business Success Plan Reporting Content Catalog Data Exchange Data Management Forma (formerly ACC) Fusion Operations Informed Design M&E Data Model Machine Translation Manufacturing Data Model Parameters Tandem Data Token Flex Usage Data User Profile Webhooks
