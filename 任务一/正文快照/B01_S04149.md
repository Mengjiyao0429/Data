Initial analysis / hypotheses The crash originates in ICU (International Components for Unicode), part of Android’s system libraries (libicui18n.so). Stack traces point to RegexPattern and RegexMatcher, which Android’s own APIs (regex, date/time formatting, ICU4J bridges) rely on. Likely triggers: We suspect the issue could be coming from "implementation 'org.webkit:android-jsc-intl:+'" Certain regex patterns combined with locale-specific operations. Samsung’s customized ICU build (Samsung often ships patched or slightly different ICU versions). Memory corruption or reference counting bug in Samsung’s vendor libraries.
