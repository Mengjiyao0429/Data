# Identifying Talk Back usage on non-Google and non-Samsung devices

## 正文
We are using OS accessibility service APIs to track the number of screen reader users we have on both iOS and Android. But we are seeing some smelly results and this had made me wonder if our implementation needs adjusting. Our Android user base is on Google and Samsung devices at a rate of 75%. However, when we measure the number of Talk Back users within our overall Android user base, only 30% are reporting in our analytics system as being on Google and Samsung devices. In particular, Motorola is overrepresented for Talk Back unique users being reported. In general, as an org we are seeing more Android Talk Back users than we are iOS Voice Over users, which we're certain is nigh impossible given our overall user base strongly favoring iOS and general trends within the accessibility community. (Screen reader users strongly favor iOS/ VoiceOver.) I am aware that Google and Samsung use different package names for Talk Back: Google: com.google.android.marvin.talkback/com.google.android.marvin.talkback.TalkBackService Samsung: com.samsung.android.accessibility.talkback/com.samsung.android.marvin.talkback.TalkBackService As such we have avoided using specific package names to ID screen reader users. Is it possible that other manufacturers might be over-reporting Talk Back users/ screen views because "talkback" as an identifier might include users who are not strictly speaking using a screen reader? And are there any better recommended approaches for gathering this kind of data on Android? See snippet for example of how we are gathering this data on Android. class MyUseCase( context: Context, ) { private val accessibilityManager = context.getSystemService(Context.ACCESSIBILITY_SERVICE) as AccessibilityManager? operator fun invoke(): Map<String, String> { val enabledFeatures = getAllAccessibilityServicesEnabled().joinToString(separator = "|") return mapOf(ACCESSIBILITY_KEY to enabledFeatures) } private fun getAllAccessibilityServicesEnabled(): List<String> { val accessibilityServiceInfoList = accessibilityManager?.getEnabledAccessibilityServiceList( AccessibilityServiceInfo.FEEDBACK_ALL_MASK, ) return accessibilityServiceInfoList?.map { when { it.id.contains(TALK_BACK) -> "Talk Back" it.id.contains(SWITCH_ACCESS) -> "Switch Access" it.id.contains(UNIVERSAL_SWITCH) -> "Universal Switch" it.id.contains(VOICE_ACCESS) -> "Voice Access" it.id.contains(SELECT_TO_SPEAK) -> "Select to Speak" it.id.contains(BRAILLE_BACK) -> "Braille Back" else -> "Unknown" } } ?: emptyList() } companion object { private const val ACCESSIBILITY_KEY = "accessibility" private const val TALK_BACK = "talkback" private const val SWITCH_ACCESS = "switchaccess" private const val UNIVERSAL_SWITCH = "universalswitch" private const val VOICE_ACCESS = "voiceaccess" private const val SELECT_TO_SPEAK = "selecttospeak" private const val BRAILLE_BACK = "brailleback" } }
