## 正文
I'm developing a Home Screen Widget for iOS 26 and trying to apply the new Liquid Glass design system to the widget's background. Currently, my widget has a solid black background instead of the transparent/blurred glass effect that native Apple widgets have (like Shortcuts, Weather, etc.). My widget displays action buttons in a grid layout and works perfectly, but I cannot get the Liquid Glass transparency working for the widget container itself. The buttons should stay as they are (solid colors) - only the widget background needs to be transparent with the glass blur effect. Current behavior: Widget has a solid black backgroundExpected behavior: Widget should have a transparent Liquid Glass background like native iOS 26 widgets Widget Configuration: iOS 26.0+ SwiftUI WidgetKit Widget Families: .systemSmall, .systemMedium Layout: Custom grid with action buttons Current implementation (not working): struct DomioControlWidgetEntryView: View { (\.widgetFamily) var widgetFamily var entry: Provider.Entry var body: some View { Group { if entry.actions.isEmpty { emptyStateView } else { actionGridView .padding(-10) } } .glassEffect() // Does not work, still black background } } The action buttons themselves are colored and should remain solid - only the widget container needs the glass effect. I've tried multiple approaches based on iOS 26 documentation: Attempt 1: .containerBackground(.ultraThinMaterial, for: .widget) Result: Solid black background (no transparency) Attempt 2: .glassEffect() (recommended by iOS 26 Liquid Glass documentation) Result: Still solid black background (no transparency) What I'm expecting: The widget background should be transparent with a blurred glass effect Similar to how native iOS widgets (Shortcuts, Weather) look The action buttons inside should remain their solid colors Only the container/background needs the glass effect Questions: Is .glassEffect() supposed to work in Widget Extensions, or are there restrictions? Do I need special entitlements for Liquid Glass in widgets? Am I missing something in the implementation? Is there a different API for widget backgrounds vs. regular SwiftUI views? I've already successfully implemented the layout with help from the community, but the Liquid Glass background remains unsolved.
