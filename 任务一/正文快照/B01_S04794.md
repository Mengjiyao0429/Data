# Does GridDB Cloud support triggers or callbacks for real-time data processing?

## 正文
I'm building a data ingestion pipeline with GridDB Cloud where IoT devices send temperature data every few seconds. Once data is inserted into the container, I want to immediately trigger a function or notification to process or forward this data (e.g., send to another service, apply a rule, etc.). In traditional RDBMS systems, this is usually done using triggers or stored procedures. In some NoSQL setups, change streams or pub/sub models are used. Question : Does GridDB Cloud support any kind of real-time trigger, webhook, or callback mechanism when a new row is inserted into a container? If not directly supported, is there a recommended design pattern for listening to insert events in GridDB (e.g., polling, external message queue integration)? I’ve reviewed the documentation but couldn’t find a clear answer regarding event-based automation or data stream hooks.
