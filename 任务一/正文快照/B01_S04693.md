I am developing a Telegram bot in Python 3.12 using AIogram 3.x and Pyrogram 2.0.106 frameworks. I have a problem with user authorisation. The code I'm using is running erratically: sometimes the code fails to submit, and sometimes other errors occur. However, the main problem, after which the code never goes farther, is the [400 CODE_EXPIRED] error. Although after receiving the code before sending it to my chatbot it takes maximum 10 seconds. And by idea, the code should be valid.
