# How to implement direct memory mapping between guest and host in VM?

## 正文
I'm working on my process virtual machine that runs as a process of the host system. The goal is to emulate target ISA of the guest software and provide seamless environment for the guest to run. I am planning to implement two schemes of memory image mapping: Indirect - table that associate each guest virtual address with specific host virtual address and std::allocator. Direct - without the table and lookup overhead. My idea was to allocate contiguous memory block using, for instance, calloc. Find address of the first instruction of guest data segment, determine difference between data segment and allocated block. Every guest address + difference = corresponding host address. I'm not sure if it is a correct approach and if so can you please provide the effective and safe method of contiguous memory allocation? EDIT: Host: AMD64, Windows 11 >21H2; Guest: ARM >v8, Windows 11 >21H2/Arbitrary Linux distro (later as a separate module implementing Linux specific features); Two basic emulation techniques are direct/indirect interpretation (for profiling) and binary translation (for optimization).
