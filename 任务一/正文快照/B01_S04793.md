# How to resolve a security-scoped bookmark in a File Provider Extension (from a main app)?

## 正文
I'm working on a macOS app that includes a main app and a File Provider Extension. In the main app, I ask the user to grant access to a directory (ideally on a cloud drive) . Once the user selects the folder, I save the resulting URL as a security-scoped bookmark in the shared App Group container. Later, in the File Provider Extension, I try to resolve this bookmark to mount a virtual file system inside the user-selected location. However, the bookmark cannot be resolved successfully in the extension. I’m using an App Group to share data between the main app and the extension. I’ve verified the bookmark data is saved and but not getting resolved in the extension although the data is getting retrieved as 648 bytes. I understand that security-scoped bookmarks are tied to the app's sandbox identity , and Apple recommends different bundle identifiers for the main app and extension . This seems to prevent the extension from resolving the bookmark created by the main app. Here’s the code I use for saving and resolving the bookmark: import Foundation class BookmarkManager { static let appGroupID = "group.4V5EJ36UMX.myProduct" static let bookmarkFilename = "bookmark.data" static var sharedContainerURL: URL? { return FileManager.default.containerURL(forSecurityApplicationGroupIdentifier: appGroupID) } static var bookmarkFileURL: URL? { return sharedContainerURL?.appendingPathComponent(bookmarkFilename) } // Save bookmark data to App Group container static func saveBookmark(for url: URL) throws { let bookmarkData = try url.bookmarkData( options: [.withSecurityScope], includingResourceValuesForKeys: nil, relativeTo: nil ) guard let bookmarkFileURL = bookmarkFileURL else { throw NSError( domain: "BookmarkManager", code: 1, userInfo: [NSLocalizedDescriptionKey: "Shared container not found"] ) } if bookmarkData.isEmpty { throw NSError( domain: "BookmarkManager", code: 4, userInfo: [NSLocalizedDescriptionKey: "Generated bookmark data is empty"] ) } do { try bookmarkData.write(to: bookmarkFileURL) print("✅ Bookmark saved to: \(bookmarkFileURL.path)") let fileSize = try FileManager.default.attributesOfItem(atPath: bookmarkFileURL.path)[.size] as? Int ?? -1 print("📦 Bookmark file size: \(fileSize) bytes") } catch { print("❌ Failed to write bookmark to file: \(error)") throw error } } // Resolve bookmark data from App Group container static func resolveBookmark() throws -> URL? { guard let bookmarkFileURL = bookmarkFileURL else { throw NSError(domain: "BookmarkManager", code: 2, userInfo: [NSLocalizedDescriptionKey: "Shared container not found"]) } let bookmarkData = try Data(contentsOf: bookmarkFileURL) var isStale = false let resolvedURL = try URL(resolvingBookmarkData: bookmarkData, options: [.withSecurityScope], relativeTo: nil, bookmarkDataIsStale: &isStale) if isStale { // Re-save to update the bookmark try saveBookmark(for: resolvedURL) } // Start access if required if !resolvedURL.startAccessingSecurityScopedResource() { throw NSError(domain: "BookmarkManager", code: 3, userInfo: [NSLocalizedDescriptionKey: "Failed to access security-scoped resource"]) } return resolvedURL } }
