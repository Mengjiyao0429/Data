I've made a script for helping me to automatically open some softwares I use for defined kinds of work, which name is Profile Chooser. For example, I have a profile on Firefox and one in Brave for studying translation and other two for studying programming, among other apps, and want to open all of them at once when I log in in Xubuntu, my OS. Observation 1: I've written such script so I don't want to let everything open all the time nor hibernation (I refer to the option similiar the hibernation of Windows, in which one can turn the machine completely off) works on my Aspire E5-571, even though it works on my Windows 10 installation. Observation 2: I don't want to create one more user profile in the OS. This is the output of the screen of the script. -------------------- | Profile Chooser | -------------------- Hello! What do you want to work with today? 1. Programming 2. Translation Type the number of the profile you want to choose or something else for quitting: > The directory of the script have these structure: The very script: profile_chooser.sh ; The icon: profile-chooser.png ; The directory profile , which have the very profiles, which actually initializes the programs and are read by profile_chooser.sh . Below is profile_chooser.sh : !/bin/bash Determine the directory of the script SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)" # Set the profiles directory relative to the script directory PROFILES_DIR="$SCRIPT_DIR/profiles" # Check if profiles directory exists if [ ! -d "$PROFILES_DIR" ]; then echo "Profiles directory not found!" exit 1 fi # Function to extract the slug from a script get_slug() { local script=$1 grep '^# slug:' "$script" | cut -d'"' -f2 } # List all scripts in the profiles directory and get their slugs profiles=() for script in "$PROFILES_DIR"/*.sh; do slug=$(get_slug "$script") if [ -n "$slug" ]; then profiles+=("$slug:$script") fi done # Sort profiles alphabetically by slug IFS=$'\n' sorted_profiles=($(sort <<<"${profiles[*]}")) unset IFS # Display the menu echo -e "--------------------\n| Profile Chooser |\n--------------------\n\nHello! What do you want to work with today?\n" for i in "${!sorted_profiles[@]}"; do slug=$(echo "${sorted_profiles[$i]}" | cut -d':' -f1) echo " $((i+1)). $slug" done # Prompt user for input read -p $'\nType the number of the profile you want to choose or something else for quitting:\n> ' choice # Validate input and run the selected profile if [[ "$choice" =~ ^[0-9]+$ ]] && [ "$choice" -ge 1 ] && [ "$choice" -le "${#sorted_profiles[@]}" ]; then selected_profile=$(echo "${sorted_profiles[$((choice-1))]}" | cut -d':' -f2) echo "Starting profile: $(get_slug "$selected_profile")" # Make the terminal full screen (Linux specific, may vary based on terminal) printf '\e[9;1t' # Run the selected profile script bash "$selected_profile" else echo -e "\nQuitting..." sleep 1 exit 0 fi Below is an example of profile. Note it has a slug, which appears in the main menu of the Profile Chooser. !/bin/bash slug: "Translation" # Open Firefox browser with the Translation profile nohup firefox -P "Translation" & # Open the translation project directory with VS Code nohup code ~/Repos/Volunteering/MDN/pt-BR/translated-content/ & # Open Brave browser with the Profile 1 profile nohup brave-browser --profile-directory="Profile 1" & I've made an alias: alias profile-chooser="/home/user/Shell\ Scripts/profile-chooser/profile_chooser.sh && exit" .
