## 正文
I'm developing a video game in C++ and Vulkan with modding support, I would really like the modding to be done through C++ (the game is optimized quite well, so I would really like the modding to be optimized as well). Mods are distributed as .cpp files, so they are compiles on the users' machines. So ideally there are some compiler options that I can use. I've already got all of it set up, except for the security aspect, currently all of mod's functions just reference the game's functions. The mod's are only allowed a single supplied header file, which contains a few basic classes like arrays, matrices, strings, etc, not including any standard c++ headers prevents functions like system from being called, but because the main application includes the system function, doesn't that mean there is a pointer to the function somewhere in memory, so could a mod do something like: ((void (*)(const char*))(damage_enemy_function + 0x2b6316b1))("rm -rf /"); Or: ((void (*)(const char*))(nullptr + 0x000016b1))("rm -rf /"); In these scenarios damage_enemy + 0x2b6316b1 and nullptr + 0x000016b1 point to the system function, which someone could find. So the problem is mods accessing the games functions or variables, and interfering with them, or the user's computer. I have tried running mods as different applications, and using pipes to communicate, but pipes are just too slow. The ideal situation is disabling pointers for mods, in which case modders will have to use the supplied array and string classes for memory management. I'm not sure how to fix this, or if this needs fixing. Ideally there would be a compiler option to disable pointers, but that seems like a very niche thing, I've looked through the GCC compiler options and can't find anything like it. Now the best option looks like using GCC's -E flag, which generates C++ code with all of the preprocessor directives complete ( define , include , ect...), then parsing through it and make sure no pointers are used, but that seems extremely difficult. If there isn't a way to do this, any recommendations for fast modding languages are much appreciated. Thank you for reading!!
