## 正文
I am trying to save the genre of a song by using at most 1 byte in C++ (it is just for academic purposes, not for production or something like that). The possible genres are rock, pop, hip-hop, electronic music and jaz (so 5), but as well as their combinations (for example a song can be pop and rock at the same time). What came to my mind at first, is to save the genre as a char (as chars are 1 byte). Then we know that a byte is 8 bits, so we can actually turn the bits that we need. For example, if the first bit is activated, we would know that the song is rock, if the second bit is activated, the song would be of pop genre and so on. Is this a good approach, taking into consideration the situation? So a string like this 11100000 would mean that the song is rock, pop and hip-hop (keeping the order I wrote in the beginning). I am not sure that's the best possible solution, though. The problems I've stumbed upon for now: if someone gives us the string "rp" (the first letters of the genres), we would want to set the first and second bits of the char variable. Something like this: struct Song { char Genre; } void readSongGenre(Song& s, const char* genre) { int i = 0; while (genre[i] != '\0') { if (genre[i] == 'r') { toggleKthBit(s.Genre, 1); } else if (genre[i] == 'p') { toggleKthBit(s.Genre, 2); } else if (genre[i] == 'h') { toggleKthBit(s.Genre, 3); } else if (genre[i] == 'e') { toggleKthBit(s.Genre, 4); } else if (genre[i] == 'j') { toggleKthBit(s.Genre, 5); } i++; } } Isn't this kind of problematic, though, as on some machines the way of storing data-types is different (little-endian, big-endian). Next thing that I wanted to have as functionaly is to be able to easily convert the bit sequence to a string: so for example 11100000 would be translated to Rock&Pop&Hip-hop , which I did in the following way: void printGenre(char genre) { int countOfSetBits = 0; for (int i = 1; i <= 5; i++) { if (isKthBitSet(genre, i)) { countOfSetBits++; } } int printed = 0; if (isKthBitSet(genre, 1)) { printed++; if (countOfSetBits != printed) { std::cout << "Rock&"; } else { std::cout << "Rock"; } } if (isKthBitSet(genre, 2)) { printed++; if (countOfSetBits != printed) { std::cout << "Pop&"; } else { std::cout << "Pop"; } } if (isKthBitSet(genre, 3)) { printed++; if (countOfSetBits != printed) { std::cout << "Hip-Hop&"; } else { std::cout << "Hip-Hop"; } } if (isKthBitSet(genre, 4)) { printed++; if (countOfSetBits != printed) { std::cout << "Electronic&"; } else { std::cout << "Electronic"; } } if (isKthBitSet(genre, 5)) { printed++; if (countOfSetBits != printed) { std::cout << "Jaz&"; } else { std::cout << "Jaz"; } } } I realise that's not really smart. Another functionality I would want my application to have is to be able to find in a collection of songs which of them have a particular combinations (or just one) genre. So for example I would want given the string "pr", to find all songs that are either pop, either rock.
