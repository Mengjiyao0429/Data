## 正文
I am using /datetimepicker in a React Native application. I want to use the spinner style time picker with a light theme. My goal is to keep the UI clean, minimal, and consistent with a light theme. However, even after setting themeVariant="light" and textColor="#000", the spinner still follows the system dark theme on Android. Here is my code: { showTimePicker && ( <DateTimePicker value={timeValue || new Date()} mode="time" display="spinner" onChange={onPickTime} accentColor={ACCENT} themeVariant="light" textColor="#000" /> ) } Is it possible to force the light theme for DateTimePicker spinner on Android? I know that it is possible to change the theme by modifying native Android files (for example through styles.xml ), but that approach forces the entire app theme to be light. Because of that, the app will not adapt properly when the device switches to dark mode. What I want is: The app should continue supporting both light and dark mode. But the DateTimePicker spinner should always appear in light theme regardless of the system theme. Is there any way to force the spinner DateTimePicker to use a light theme on Android without modifying the global app theme in XML? Or is there any recommended workaround/library to control the spinner theme dynamically in React Native?
