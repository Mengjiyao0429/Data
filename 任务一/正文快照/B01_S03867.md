## 正文
I am trying to localize a bootstrapper that I am building with Wix v5. I need my bootstrapper to detect the system language and display the UI strings in the appropriate language. I found a solution here that works how I want it to. I have added my translations to the WXL files, and then added those files as payloads like so: <BootstrapperApplication> <bal:WixStandardBootstrapperApplication Theme="rtfLicense"/> <Payload Name="2058\thm.wxl" SourceFile="2058\thm.wxl"/> <Payload Name="3084\thm.wxl" SourceFile="3084\thm.wxl"/> </BootstrapperApplication> This method works when I compile the .exe and run the bootstrapper on my machine with the display language set to one of the two supported languages. However, when I try to uninstall or modify the package from the Apps & Features or Programs in the Control Panel, the UI reverts to English. Am I doing something wrong, or is this a bug? How do I get the uninstall dialogs to translate properly?
