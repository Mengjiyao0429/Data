I'm building a NuxtJS application using Vercel's AI SDK to interact with OpenAI's Assistants API. When the assistant references files in its responses, it generates citations in this format: 【4:2†Source】. I need to replace these random citation markers (e.g. 4:2†) with sequential footnote references (e.g. 1 , [2], etc.) so users can easily map citations to references. The budget information in 【7:1†Source】 shows... Desired output: According to the document [1], the deadline is tomorrow. The budget information in [2] shows...
