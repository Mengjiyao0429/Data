# 任务一：多源数据采集与清洗

第三届甘肃省大学生数据挖掘挑战赛（本科组）赛题《AI 应用场景的智能挖掘与机会评估系统》。
本文件夹完整保存任务一的目标、方法、原始数据、正文快照、结果与全部源码。

## 一、任务目标

围绕“AI 应用场景”主题，实现多源公开渠道的数据采集、整理、清洗与去重，形成统一规范、
可直接用于后续分析的记录，并保证每条结果可溯源至原始采集记录。对应赛题三项要求：

1. **多源采集与整理**：从多个公开渠道采集近期热门内容，对齐为统一字段
   （采集批次号、记录编号、来源网站名称、来源链接、内容、发布时间、热度指标），
   以“采集批次号-记录编号”唯一标识。
2. **文本清洗**：去除 URL 与渠道噪声、解码 HTML 实体、规范化空白与标点、处理缺失值，
   清洗后正文以快照形式留存。
3. **重复记录处理**：通过精确 MD5 与字符 shingle Jaccard 相似度自动识别并去除重复，
   输出去重后记录及保留数量。

## 二、完成结果

- 最终保留 **329 条**真实记录，分三个采集批次，全部发布于 **2024-01-02 ~ 2026-11-16**。

| 批次 | 含义 | 条数 | 构成 |
|---|---|---|---|
| B01 | 首次 API 采集 | 248 | Stack Overflow 热度前 100 + GitHub 148 |
| B02 | 第二次国内浏览器采集 | 31 | 36氪 10、阿里云 10、腾讯新闻 6、医药促进会 5 |
| B03 | CSDN 专项采集 | 50 | CSDN 按浏览量排序前 50 |

- 来源分布：GitHub 148、Stack Overflow 100、CSDN 50、36氪 10、阿里云 10、
  腾讯新闻 6、中国医药创新促进会 5。
- 中文正文记录 90 条（占 27.4%），其中 B02、B03 共 81 条，另有 9 条 GitHub 含中文。

## 四、如何验证真实性

1. 用浏览器打开 result1 中任意“来源链接”，页面真实存在，标题/正文与“正文快照”一致。
2. 热度指标（星标、点赞、收藏、评论、浏览量）均为接口或页面返回的真实数值，未人工编造。
3. result1“内容”列的相对路径在本文件夹内可直接定位到对应快照文件。
4. 反爬说明：Stack Overflow、CSDN 对脚本直接请求分别返回 403 / 521（站点防护），
   真实浏览器可正常访问，属反爬拦截而非链接失效，验证时请用浏览器打开。

## 五、采集合规

仅采集公开信息并注明出处；优先使用官方公开 API/RSS，浏览器渲染仅做正常浏览式访问，
不破解反爬、不高频、不采集个人信息，请求间设置延迟，不对目标站点造成异常访问压力。
