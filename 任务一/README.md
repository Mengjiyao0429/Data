# 任务一：多源数据采集与清洗

第三届甘肃省大学生数据挖掘挑战赛（本科组）赛题《AI 应用场景的智能挖掘与机会评估系统》。
本文件夹完整保存任务一的目标、方法、原始数据、正文快照、结果与全部源码。

## 一、任务目标

围绕“AI 应用场景”主题，实现多源公开渠道的数据采集、整理、清洗与去重，形成统一规范、
可直接用于后续分析的记录，并保证每条结果可溯源至原始采集记录。对应赛题三项要求：

1. **多源采集与整理**：从多个公开渠道采集近期热门内容，对齐为统一字段
   （采集批次号、记录编号、来源网站名称、来源链接、内容、发布时间、热度指标），
   以“采集批次号-记录编号”唯一标识。
2. **文本清洗**：去除 URL 与渠道噪声、解码 HTML 实体、规范化空白与标点、处理缺失值，
   清洗后正文以快照形式留存。
3. **重复记录处理**：链接精确去重 + 正文 MD5 精确去重 + SimHash 近似去重，
   输出去重后记录及保留数量。

## 二、完成结果

- 最终保留 **5517 条**真实有效记录，分四个采集批次，全部发布于 **2024-01-01 ~ 2026-11-17**。
- 正文长度中位数 148 字、均值 623 字，最短 21 字；含中文记录 694 条（占 12.6%）。

| 批次 | 含义 | 条数 | 构成 |
|---|---|---|---|
| B01 | 技术社区 API 采集 | 4954 | Stack Overflow 1256（含正文）+ GitHub 3698 |
| B02 | 国内站点浏览器采集 | 44 | 36氪 10、阿里云 10、腾讯新闻 8、新浪科技 7、医药促进会 5、互联网协会 4 |
| B03 | CSDN 专项采集 | 477 | CSDN 搜索接口，12 个中文关键词，2024 年后，含真实浏览/点赞/评论 |
| B04 | 科技媒体 RSS 采集 | 42 | IT之家 30、InfoQ 中国 9、量子位 3 |

- 来源分布：GitHub 3698、Stack Overflow 1256、CSDN 477、IT之家 30、36氪 10、
  阿里云开发者社区 10、InfoQ 中国 9、腾讯新闻 8、新浪科技 7、
  中国医药创新促进会 5、中国互联网协会 4、量子位 3。
- 数据量扩容量（相对首版 329 条）：GitHub 单页上限由 30 提升到 100 并翻 4 页，
  Stack Overflow 由 30 提升到 100 且使用 `withbody` 取真实正文，CSDN 改走搜索接口翻页，
  新增科技媒体 RSS 批次。

## 四、如何验证真实性

1. 用浏览器打开 result1 中任意“来源链接”，页面真实存在，标题/正文与“正文快照”一致。
2. 热度指标（星标、点赞、收藏、评论、浏览量）均为接口或页面返回的真实数值，未人工编造。
3. result1“内容”列的相对路径在本文件夹内可直接定位到对应快照文件（5517/5517 全部可点）。
4. 链接有效性抽检：36氪、阿里云、腾讯新闻、新浪科技、医药促进会、互联网协会、IT之家、
   InfoQ、量子位均返回 HTTP 200；GitHub 可在浏览器或 `api.github.com/repos/<full_name>`
   直接核对仓库存在。
5. 反爬说明：Stack Overflow、CSDN 对脚本直接请求分别返回 403 / 521（站点防护），
   真实浏览器可正常访问，属反爬拦截而非链接失效，验证时请用浏览器打开。

## 五、采集合规

仅采集公开信息并注明出处；优先使用官方公开 API/RSS，浏览器渲染仅做正常浏览式访问，
不破解反爬、不高频、不采集个人信息，请求间设置延迟，不对目标站点造成异常访问压力。
