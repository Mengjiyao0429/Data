## 正文
With the advent of all the new AI coding tools (e.g. Claude Code, Codex, Vercel etc.) could coding become an obsolete practice like programming in assembly became obsolete once high-level programming languages came along? I was thinking recently that all apps/programs/software can be described as state diagrams. (click on this button and the app goes to that state). I understand that natural language isn't enough to describe an app you need to describe things visually also to be exact but let's say such a tool is created where I can just create a state diagram of an app visually and with natural language and it generates the complete app. is such a tool feasible and could it replace coding by hand?
