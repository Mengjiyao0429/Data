## 正文
With the rise of AI agents, I've been looking for an agent that can use a combination of local models or models that are hosted on servers I control. For the local models, the agent must be able to run completely offline. When using remote models, it must only send network traffic to my servers. No checking for "updates" or pulling any type of dependencies from elsewhere. When trying Opencode, it was a failure. See: "This is the offline fork of OpenCode. Upstream OpenCode requires internet access for several core functions: the web UI proxies all requests to app.opencode.ai, ripgrep and LSP servers (TypeScript, Python, C++, Rust) are downloaded on first use, and model metadata is fetched from models.dev. In air-gapped or restricted network environments, this means no web interface (HTTP 500 on every request), no file search, no code intelligence, and no model definitions." The problem is this project isn't maintained to standards and still uses Opencodes base. Thanks for any suggestions.
