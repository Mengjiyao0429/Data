# Ask HN: stop ocsp.apple.com yet keep the appstore working?

- 链接：https://news.ycombinator.com/item?id=25692494
- 发布时间：2021-01-08
- 热度：点赞2、评论2

## 正文
I'm on a mac obviously... Still Mojave (need some 32 bit glory) In my /etc/hosts file I've got this line 0.0.0.0 ocsp.apple.com It works a charm, apps on MacOS start nearly instantly, even cold. Mostly noticeable with my own cocoa apps. So I'd like to keep it that way. That said, it also seems to break the appstore. If I load the appstore app, it complains about "We could not complete your purchase. Cancelled", which works fine if I don't block ocsp. Has anyone got a solution for this? My first thought is running a proxy that would make the difference and allow or deny... for god sakes let advanced users turn off this security feature.
