# Ask HN: Do you think my clients idea has any worth in project management?

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=19664705
- 发布时间：2019-04-15
- 热度：点赞2、评论1

## 正文
A client came to me a while back with an idea to build a tool. I originally built it for the guy to use with his clients, however, he then decided to make the tool available for everyone - but feedback hasn't been favourable, most people say there is no value for the tool. To start, my client is a business coach in the UK. He goes into companies that know what they want to do but don't know how to achieve it. Usually, this results in him producing an Object Tree (example here built using the tool I made: ). My client approached me to build a tool that allows you to drag and drop boxes into place, assign boxes to team members, set dates etc. You can export PDF's and print them out and you can also generate a Gantt chart. The system also sends you reminders when an object is due. My business doesn't plan projects in this way, we usually load everything into productive.io. But, is there anyone out there that prefers to work in this more visual way? Due to budgets when we start, we built a very basic tool (more of a prototype). Our team is willing to put the time and effort into re-developing ths tool if there are people that think there is a worth for this. For a start with a rebuild we could consider adding AI. Also, is there anything we can add to increase it's worth? Feel free to ask questions if you need more information. All options are on the table, including putting this to bed so please be honest.
