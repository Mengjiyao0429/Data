## 正文
When searching for a C library for machine learning, I encounter many results of 'C/C++' libraries. However, C and C++ are obviously different languages, and these libraries seem to be exclusively written in C++. A quick google search of "C machine learning library" will yield examples of this. I was wondering if there were any machine learning libraries strictly for C? I am often told that although C is difficult, it is backed by a vast number of libraries. As such, I find it confusing as to why I haven't been able to find any machine learning libraries? Any suggestions of good machine learning libraries for C? Thank you.
