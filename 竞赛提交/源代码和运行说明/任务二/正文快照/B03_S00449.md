## 正文
I have implemented a recommender system based upon matrix factorization techniques. I want to evaluate it. I want to use 10-fold-cross validation with All-but-one protocol ( ). My data set has the following structure: user_id,item_id,rating 1,1,2 1,2,5 1,3,0 2,1,5 ... It's confusing for me to think how the data is going to be splitted, because I can't put some triples (user,item,rating) in the testing set. For example, if I select the triple (2,1,5) to the testing set and this is the only rating user 2 has made, there won't be any other information about this user and the trained model won't predict any values for him. Considering this scenario, how should I do the splitting?
