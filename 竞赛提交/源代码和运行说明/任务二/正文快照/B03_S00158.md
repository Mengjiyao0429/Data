## 正文
Hi HN, I built a site to solve my problem as well as other n8n non-technical users problem by curating 16,223 n8n workflows so people don’t have to get stress up when automating tasks. If you haven’t used n8n , it’s an open-source alternative to Zapier/Make that lets you connect APIs, services, and logic visually. The problem is: while n8n is powerful, there isn’t a simple central place to discover ready-to-use workflows beyond scattered forum posts, gumroard, youtube, and GitHub gists. That’s what I wanted to fix. On my site, you can: Browse workflows by category (SaaS, finance, productivity, dev tools, marketing). Copy workflows in JSON format directly into your n8n instance. See real-world use cases (e.g., auto-generate reports, sync Airtable with Notion, send Slack alerts). Submit your own workflows (community-driven). I’ve been testing it with some friends in the no-code/automation space, and the biggest feedback was that it saves time and gives inspiration for what’s possible with n8n. The site is still early, so I’d love your feedback. Thanks!
