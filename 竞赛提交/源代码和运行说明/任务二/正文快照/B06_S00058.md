## 正文
I massively prefer inline code completion to agentic workflows (mostly due to security, reliability and auditability). Unfortunately almost every AI coding plugin is moving towards agentic workflows, abandoning simple code complete. Github Copilot even started messing with peoples commit messages completely unprompted and they haven't updated their openAI model for almost 2 years now, still on 4.1. I cannot find a single plugin focused simply on inline code completion. for example it's extremely convenient for if(articles.length==0) throw new Error("articles cannot be empty!") Continue.dev, Tabnine, Tabby and GH Copilot all seem to either move toward agentic, abandoning the plugin entirely or are rapidly becoming user hostile (in the case of Copilot). So is there something that checks the following boxes? no chat, no agent, no CLI (and definetly no curl | bash) simple inline code complete just like copilot used to be ideally open source ideally compatible with multiple models or self hosted models, ideally on a server (dedicated AI server) ideally not at risk of becoming user hostile in the future
