# Thoughts about AI/LLMs: imagining 1, 5 years from now

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=40927889
- 发布时间：2024-07-10
- 热度：点赞2

## 正文
Beyond what can be done right now with AI (or LLMs), I like to imagine what will happen in 1, 5 years from now... Some "imaginings": - It's going to be ubiquitous, it's going to be everywhere and accessing it won't be a concern: just like now we take it for granted that we have electricity and internet connection at any time and almost anywhere at a negligible cost, the same will happen with AI. This is already happening in part because accessing the APIs is very cheap and effective, but it's going to go much further. - It's going to be invisible: we're going to have models embedded in software and devices (it's already happening: Chrome will embed a model in the browser itself and there will be a native API to use it). If this extends, many software functions will be using AI without us having to deal with it. - It's going to be private: being local, we won't have to worry about it working on confidential data - the data won't have to go to an external API where we don't know what happens to it. - It's going to be immediate: the generation speed will continue to increase. There will come a time where generations will just be there. - Chatbots in vertical applications will be an anecdote: many of us are implementing them because it's easy (to implement and to think, or not to think, because we've seen the success of ChatGPT and we've followed it). But for many use cases it's not the best interface. - End users won't use AI: in the sense of using prompts, configuring agents, etc. Only power users will do. - Devs will use/"program" a lot of AI: to make it invisible by integrating it into existing software so that end users don't have to deal with using prompts etc. - No/low-code will grow by x10/explode: what we've seen so far will be a joke compared to hooking up agents. And some uncertainties I can't imagine how they'll evolve: - Generative interfaces: AI will build for us in real time the interface we need. - Integration of agents: the theory about agents is clear and there is already a lot of software, but I can't see how it will spread.
