# AI Code Reviewer alpha release

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=42817395
- 发布时间：2025-01-24

## 正文
I am pleased to announce the alpha release of AI Code Reviewer, which uses gemma2, qwen2.5, and falcon3 LLMs to review source code and recommend improvements. This is designed to be run locally using Ollama and can provide engineers with a review of their source code before committing code to git. This project provides an AI-powered tool for reviewing code files and providing actionable feedback to fix bugs, improve application speed, and fix security problems.
