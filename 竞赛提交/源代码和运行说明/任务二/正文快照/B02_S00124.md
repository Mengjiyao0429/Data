# AI dev team that plans and ships, not just generates code

- 来源：Hacker News

- 发布时间：2026-02-17

## 正文
I’m building Zrost because every AI coding tool I tried was great at generating code and terrible at finishing projects. The last 20% always killed us. Instead of one AI assistant, Zrost gives you a coordinated team. You talk to an AI PM, describe what you want, it breaks the project into tasks with dependencies. Then specialized agents (frontend, backend, QA, DevOps) execute together through visual task graphs and GitHub integration. The key difference: agents are aware of each other’s work. The backend agent knows what the frontend agent built. QA knows what changed. No conflicts, no duplicated work. Stack: task dependency graphs, Kanban boards, GitHub sync, pay-per-usage pricing ($20 free credits to start). Small team building from Ukraine. Been in production for a few months, looking for honest feedback on what’s working and what’s not.
