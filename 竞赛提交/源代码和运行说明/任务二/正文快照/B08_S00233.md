ChatGPT and generative AIs have been in a lot of uses lately. With Github's copilot being as closely integrated into the development experience as it can get. Or is it? Is there a whole programming language that's actually based on generative AI? Like this: const dinner = promptAI('What would you like for dinner today?') if (evalAI(`Is ${dinner} non-veg?`)) { promptAI('Sorry, veg only') } else { const missingIngredients = evalAI(`Find out from the list "inventory.txt" if there are any missing ingredients for ${dinner}`) promptAI(`Great choice! Can you get ${missingIngredients}? while you're out?`) } Notice the functions promptAI & evalAI they allow the programmer to code in the logic using simple english statements. Is there a programming language, or a library for any existing programming language that allows you to code like this?
