# Is there a project oriented website that teaches bookkeeping for small business?

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=12463754
- 发布时间：2016-09-09
- 热度：点赞2

## 正文
I am looking for a good project oriented bookkeeping tutorial. It would be great if the tutorial is based on real life example (i.e., books for grocery store) and utilizes SAAS accounting software like Xero/Wave and various utility tools such as invoice/receipt OCR for auto data entry. I know it doesn't cost much to hire a bookkeeper to handle the books. However, i still want to learn the basics of bookkeeping and understand how it's being done.
