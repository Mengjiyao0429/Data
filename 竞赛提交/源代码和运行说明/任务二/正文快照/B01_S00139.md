# Show HN: Taracode – Open-source DevOps AI assistant that runs 100% locally

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=46847082
- 发布时间：2026-02-01

## 正文
Hi HN, I built taracode because I wanted an AI coding assistant for DevOps work that doesn't send my infrastructure code, credentials, or prompts to third parties. It runs entirely on your machine (I recommend gemma3:27b) and has 58 built-in tools for the stuff I deal with daily: - Kubernetes: kubectl, helm - Terraform: plan, apply, state management - Docker: build, compose, logs - Cloud CLIs: AWS, Azure, GCP - Security: trivy, gitleaks, tfsec, kubesec No account required. No usage limits. MIT licensed. Some features I'm proud of: - Multi-agent system with specialized agents (Planner, Coder, Reviewer, DevOps, Security) - Project memory that persists context across sessions - Screen monitoring that watches for errors and suggests fixes (macOS) - MCP support for connecting external tools Written in Go, single binary install or curl. I'd love feedback, especially from folks working with K8s/Terraform daily. What tools or workflows would make this more useful for your setup?
