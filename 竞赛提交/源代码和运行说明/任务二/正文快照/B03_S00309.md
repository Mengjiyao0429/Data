# Ask HN: Experiences using text to diagram tools in projects?

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=38696301
- 发布时间：2023-12-19
- 热度：点赞1

## 正文
I was wondering about project/team use of text-to-diagram generation tools like d2, Mermaid, PlantUML, Structurizr, etc. Do you have any automation set up to generate diagrams during development or CI/CD? What pitfalls and triumphs did you encounter? Does everyone on the team author diagrams or has it fallen to mostly one person to maintain? Do you find that it helps comprehension of the project for new people? Have you found that people still draw diagrams in other software? How does this split work in practice? What do you wish you knew before creating the diagrams? What do you like/dislike about the tool you chose? Would you pick the same tool if starting over? Thank you for reading!
