# Ask HN: Which tech to use for real time data processing? Kafka or Kinesis?

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=17465380
- 发布时间：2018-07-05
- 热度：点赞1

## 正文
Hi hackers, We have a requirement in our organisation where a continuous stream of balance info events for users are being generated(Essentially an event has information of user's current balance after this event, balance type - debit/credit/coupon etc). Our goal is to process this continuous stream of data and get below information out of it: 1. balance snapshot at the end of each day for each user (starting and ending balance for each user). 2. invoice for each user (starting balance, ending balance, coupons applied etc) at the end of the month. I'm confused as to which data stream processing tool would fit our use case better. Kafka or Amazon Kinesis. Since I'm new to designing systems, any thoughts on which tool to use and how to achieve it (high level design, database design) would be really helpful. Thanks.
