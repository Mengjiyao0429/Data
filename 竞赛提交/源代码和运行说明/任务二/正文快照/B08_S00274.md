# Ask HN: Is web design still worth learning in the age of no-code tools and AI?

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=35023234
- 发布时间：2023-03-04
- 热度：点赞4、评论5

## 正文
I've been considering learning web design for some time now, but with the rise of no-code tools, templates, and AI-powered website builders, I'm starting to wonder if it's still worth it. I understand that having a strong understanding of design principles can give me more flexibility and customization when it comes to building websites. However, it seems like more and more people are using no-code tools and templates to quickly create websites without the need for any specialized knowledge. So, is learning web design still worth it in 2023?
