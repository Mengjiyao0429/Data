# Ask HN: Have you used an AI tax assistant?

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=39539078
- 发布时间：2024-02-28
- 热度：点赞1、评论3

## 正文
I have reasonably complex personal taxes (AMT, foreign tax credits, K-1, rental, etc.). I've gone through four CPAs in 10 years, every time moving on because of the number of errors they're making, and the back and forth just takes more time. If I'm going to be scouring IRS pubs anyway, I'll just file my own taxes. And I do... But it is undoubtedly complex and error-prone, and I'd like an independent review for diversity. That is, if I'm generating my return using HR Block's software, I'd love to be able to shovel the draft return and source docs into an AI and get an accuracy check, recommendations, etc. There seems to be no shortage of services purporting to do stuff like this, but they're hard to evaluate since doing so means sending your sensitive data to them, something I'm hesitant to do without more knowledge of the service and company. Has anyone here used a service like what I'm describing?
