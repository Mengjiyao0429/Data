## 正文
Advising a founder to use AI to code, I introduced him to replit.com Our initial understanding was that if humans will cost $100 we can code this in $1 and faster. After prototyping I have realised that it has a somewhat shallow model at backend and keeps reverting to what it wants to do. If there is a challenge with react native it is not being able to fix but reverts to "a simpler htmlcss" approach after few attempts. I wanted to zoom out a little and ask if there is an equally simple, but better coding assistant than this. Ideally I hope there is something that makes this mobile first and encourages me to not write any code and move really fast. Asking because I now realise we might have to spend not $1 but $10 with replit. Just hoping this isn't a yak shaving journey I've embarked on. Could this be salvaged by a good mother prompt that programmers use? Wondering because most of these frontends must be finally connected to similar deepseek/gemini/chatgpt apis no? Any other suggestions that worked for you are also welcome.
