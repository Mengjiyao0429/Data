# Remove Cloud Image Recognition and cloud image target management support

- 来源：GitHub
- 链接：https://github.com/VWS-Python/vws-python/issues/3328
- 发布时间：2026-10-29

## 正文
PTC has notified customers that Vuforia Engine Cloud Image Recognition retires effective **May 2, 2027**. Existing services remain operational during the notice period; after the end-of-life date, Cloud Image Recognition databases and associated services will no longer be available. Source: the PTC Vuforia Team customer email supplied by the maintainer. Remove support for the retiring cloud image service, including cloud image target management as well as recognition queries. Model Target and VuMark support remain in scope for the project; the email does not announce their retirement. Scope: - Remove the synchronous and asynchronous cloud APIs: `VWS`, `AsyncVWS`, `CloudRecoService`, and `AsyncCloudRecoService`, including their public exports. - Remove cloud image target CRUD, processing/duplicate checks, recognition queries, database/target summaries, recognition-count reports, and cloud-only request/result models, exceptions, and image helpers. - Remove the corresponding tests, fixtures, live cloud database credentials/setup, documentation examples, and CI entries. - Retain `ModelTargetService`, `AsyncModelTargetService`, `VuMarkService`, and `AsyncVuMarkService`, with their authentication, transports, errors, and tests. Extract any shared request/error helpers they still need before deleting cloud-specific modules. - Update the README, API reference, package description, dependency set, and release notes to describe the remaining supported services and the breaking API removals. Coordinate the library release with `vws-cli`, `vws-python-mock`, `vws-test-fixtures`, `vws-auth-tools`, and `vws-web-tools`. Remove only credentials and dependencies that are exclusive to the retired service. Done when the supported public API and CI no longer depend on cloud image databases or `cloudreco.vuforia.com`, and the remaining Model Target and VuMark tests and documentation checks pass.
