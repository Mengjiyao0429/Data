## Title: US-75 AI Chatbot · 面板与对话呈现 **Parent:** US-59 AI Chatbot 智能行程规划（Epic）· **Size:** M · **Change:** add-trip-planning-agent ## Story **As a** 已登录的携宠旅行者 **I want** 在任意页面从豆包伙伴入口打开规划 Agent 面板，看到流式回复与可见的规划过程 **So that** 我不离开当前页面就能与 Agent 对话，并清楚它正在做什么 ## Business Background US-59 拆分第 1 片（Workflow 起点）：先交付可用的对话外壳与呈现，后续切片在其上叠加创建 / 编辑 / 地点能力。 ## Enhancement & Solution - 入口并入豆包伙伴（US-52，PO 2026-11-17 已决）；参考分支为独立右下角 FAB，实现时做入口层适配。 - 面板内完成全部 Agent 操作；开关与对话状态仅存内存，刷新丢失。 - 活动状态：处理中仅一条「正在思考」，空闲隐藏；中间说明小号浅色文本、工具调用浅色标签同层、相邻重复调用合并计数；本轮结束折叠为「已完成思考」（箭头图标与地点浏览筛选下拉一致）。 - 消息呈现：最终回复 TanStack Markdown 流式直渲（无自研渐显动画）；用户消息靠右浅绿气泡、Agent 消息无气泡背景；均无头像 / 身份标签；HTML 转义、危险 URL 不渲染为链接。 ## Acceptance Criteria **AC-1 入口与可用性**：任意登录后页面可见入口，不依赖激活行程；无激活行程可开始规划；有激活行程时可用且不自动修改。 **AC-2 面板内闭环**：对话、方案预览、确认 / 拒绝均在面板内，不离开当前页面。 **AC-3 活动状态**：处理中仅一条「正在思考」；空闲不显示、不保留计数。 **AC-4 过程可见**：中间说明浅色小字 + 工具标签同层；相邻重复调用合并为带次数标签（隔着说明文字的不合并）。 **AC-5 过程折叠**：本轮结束折叠为「已完成思考」可展开块，箭头图标折叠朝右 / 展开朝下，最终回复保持可见。 **AC-6 消息渲染**：Markdown 语义渲染、流式直渲；用户 / Agent 消息按角色区分呈现；不安全 HTML / URL 失效。 **AC-7 不持久化**：刷新后面板收起，对话与待审核方案丢失。 **场景归属（15）**：spec trip-planning-agent R1–R3（No active trip / Active trip exists / Entry available / Actions inside panel / Thinking status / Status hides idle / Intermediate narration / Tool tags / Repeated merge / Process collapses / Panel not persisted / Markdown render / Streaming direct / Role presentation / Unsafe markdown inert）。 ## Priority: Should
