# Apple: Switch to Safari (From Chrome)

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=50085574
- 发布时间：2026-10-14

## 正文
Everyone should avoid Google Chrome, and as such this campaign is welcome. But my major gripe with Safari is: 1. It is not multi-platform. A browser that isn't available for Windows, Linux, xBSD is not a browser I would use or recommend to others. 2. I don't want "Intelligent Tracking Prevention" or some limited Apple curated lists of content blockers - uBlock Origin should be fully functional in it. 3. No requirement of an "App Store" to install browser extensions. 4. No built-in AI bullshit. Rather make certain browser APIs open so that any other AI tools can use and manipulate it as the user wants. 5. Fully open source (in Safari, only Webkit is open source).
