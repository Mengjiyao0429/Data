## 正文
I'm currently working to build the infrastructure for my local agentic executors. I use the cursor and "skills" really heavily. As you all know, the quality of the output depends on the prompt you use and the quality of the context. When I ask the model to create the skill, it tunes the skill to the existing context of the project (usually technology-related) I'm currently working on, which forces me to rewrite (partially or fully) the skill for the next project. So, the question is: is there a smart way to separate "technology-specific things" from the prompt itself to make it more generic and reusable? I've reviewed existing recommendations on popular platforms, but I haven't found an answer to this question.
