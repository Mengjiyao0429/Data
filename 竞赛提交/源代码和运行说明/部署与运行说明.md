## 二、运行环境准备

### 1. Python 版本
- 推荐 **Python 3.10 ~ 3.12**（3.13 亦可，个别依赖为源码构建，稍慢）。
- 检查：`python --version`

### 2. 创建虚拟环境（强烈建议，避免污染系统环境）
```bash
# Windows（在项目根目录执行）
python -m venv .venv
.venv\Scripts\activate

# macOS / Linux
python3 -m venv .venv
source .venv/bin/activate
```

### 3. 安装依赖
```bash
cd 任务五
pip install -r requirements.txt
```
依赖清单（任务五系统运行所需）：
```
Flask>=3.0
python-docx>=1.1
numpy>=1.24
scikit-learn>=1.3
jieba>=0.42
matplotlib>=3.7
joblib>=1.3
```
> 任务二/三/四的复算另需 `openpyxl`（读取 result1.xlsx）；任务一的重新采集需要 `requests`。如只运行任务五系统，上面的 requirements 已足够，随附的结果 CSV 可直接读取，无需联网采集。

## 三、最快上手：直接运行任务五系统（推荐）

系统开箱即用，**不配 API 也能完整运行**（策划案与问答走离线模板，零成本、无需联网）。

### 启动方式（任选其一）
- **方式 A（Windows 最简）**：双击 `任务五/启动服务.bat`
- **方式 B（命令行）**：
  ```bash
  cd 任务五
  python start_app.py
  ```

### 首次启动会自动初始化
系统启动时自动创建 `任务五/instance/` 目录及三个文件：
- `users.db`：内置两个演示账号（见下表）
- `app.db`：系统设置、选取、策划案、审计日志
- `secret.key`：会话签名密钥

> 出于安全，本交付包**不包含 instance 目录**（其中会存放 API 密钥）。首次启动时自动生成，无需手工创建。

### 访问
浏览器打开：**http://127.0.0.1:5000**

### 演示账号
| 角色 | 用户名 | 口令 | 权限 |
|------|--------|------|------|
| 需求发起者 | `analyst` | `analyst@123` | 看板、数据分析、需求发起、机会选取、生成策划案、智能问答 |
| 决策者 | `decision` | `decision@123` | 以上全部 + 系统设置（配置 API）、策划案导出 |

### 换端口（可选）
```bash
set T5_PORT=5099 && python start_app.py       # Windows CMD
T5_PORT=5099 python start_app.py              # macOS / Linux
```

### 停止服务
在运行窗口按 `Ctrl + C`，或直接关闭窗口。

## 四、任务五各功能说明

| 导航页 | 作用 | 数据来源 |
|--------|------|----------|
| 概览看板 | KPI、价值排序、三维度贡献、热力图 | 本地基线 result1~4（4322/1728/55） |
| 数据分析 | 彩色桑基流向图、环形占比、各批次机会率 | 本地基线 |
| 需求发起 | 填关键词、勾来源、设目标条数 → 发起采集分析 | 实时公开接口 / 本地语料回放 |
| 批次分析 | 查看每次需求生成的独立批次（顶部先选批次 B09–B13） | 批次目录 |
| 机会选取 | 按价值分筛选、勾选主题簇、生成策划案 | result4 |
| 策划案库 | 在线查看、导出 Word / Markdown | SQLite 持久化 |
| 智能问答 | 提问，检索真实簇与证据记录作答（带依据编号） | 本地基线 + 可选大模型 |
| 系统设置 | 配置大模型 API（仅决策者可见） | SQLite 配置库 |

**关于 API 配置（可选）**：
- 不配：默认 `离线模板` 模式，所有功能可用，策划案/问答由内置模板基于真实数据生成。
- 要配：用 `decision` 登录 → 系统设置 → 服务模式选「OpenAI 兼容接口」，填写：
  - `base_url`：如 `https://open.bigmodel.cn/api/paas/v4`（智谱）
  - `model`：如 `glm-4-flash`（智谱免费模型）
  - `api_key`：你自己的密钥（界面掩码显示，仅存本地 `instance/app.db`，不进源码、不进交付包）
  - `timeout`：**建议 ≥180 秒**（策划案正文较长，60 秒易超时回退模板）
- 内置一键「测试连通性」按钮，显示「连通正常」即成功。

## 七、常见问题

**Q：双击 bat 一闪而过？**
A：说明 python 未加入 PATH 或缺依赖。改用命令行进入 `任务五` 目录执行 `python start_app.py`，可看到报错信息。

**Q：访问 5000 端口被拒？**
A：确认服务窗口仍在运行（首次启动加载数据约需 20 秒）；若端口被占用，用 `T5_PORT=5099` 换端口。

**Q：策划案显示"已回退离线模板"？**
A：说明模型调用超时或密钥无效。检查系统设置的连通性测试；把 timeout 调到 180 秒以上；或直接使用离线模板（功能完整，不影响交付）。

**Q：任务三/四 README 里写的 986 条 / 30 簇 / 14 行是旧数据？**
A：是历史说明未同步。当前交付口径以 `结果/` 目录下的实际 CSV 为准：1728 条机会、55 簇、result4 共 55 行。本说明已按当前口径修订。
