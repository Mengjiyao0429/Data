## 三、产出文件与字段

- `../结果/result1.csv`（utf-8-sig，Excel 可直接打开，4322 条），11 列：
  `采集批次号 | 记录编号 | 来源网站名称 | 来源链接 | 内容 | 发布时间 | 星标数 | 浏览数 | 点赞数 | 评论数 | 收藏数`
- `../结果/result1.xlsx`：同内容 Excel 版，与 csv 逐行零差异。
- `../结果/text/`：4322 个清洗后正文快照，文件名按 `批次_编号.md` 与“内容”列一一对应，
  靠“采集批次号 + 记录编号”联合唯一，保证可溯源。

## 四、如何复现

```bash
pip install -r requirements.txt
python collect_demand_oriented.py   # 需求导向多源采集（当前口径主流程）
python build_dataset.py             # 清洗、三级去重、编号与导出 result1 及快照
python sync_task1_outputs.py        # 同步下游（任务二）所需的任务一输出
```

核心模块：`app/pipeline/collector.py`（采集）、`app/pipeline/cleaner.py`（清洗）、
`app/pipeline/dedup.py`（精确 MD5 + 字符 shingle Jaccard / SimHash 近似去重）。

## 五、如何自行验证真实性

1. 用浏览器打开 result1 中任意“来源链接”，页面真实存在且标题/正文与快照一致。
2. 每条记录的星标、点赞、收藏、评论、浏览量均为接口或页面返回的真实数值，未人工编造。
3. “内容”列的 `./text/...` 路径 4322/4322 全部可定位；csv 与 xlsx 零差异。
4. 反爬说明：部分站点对脚本直接 GET 有防护，**真实浏览器可正常访问**，这是反爬拦截，不是链接失效。

## 六、采集合规说明

仅采集公开信息并注明出处；优先使用官方公开 API/RSS，浏览器渲染仅做正常浏览式访问
（不破解反爬、不高频、不采集个人信息、不规避访问控制），请求间设置延迟，
不对目标站点造成异常访问压力。
