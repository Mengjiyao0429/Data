# Remove Cloud Image Recognition database provisioning and credential retrieval

- 来源：GitHub
- 链接：https://github.com/VWS-Python/vws-web-tools/issues/1681
- 发布时间：2026-10-29

## 正文
PTC has notified customers that Vuforia Engine Cloud Image Recognition retires effective **May 2, 2027**. Existing services remain operational during the notice period; after the end-of-life date, Cloud Image Recognition databases and associated services will no longer be available. Source: the PTC Vuforia Team customer email supplied by the maintainer. Remove support for the retiring cloud image service, including cloud image target management as well as recognition queries. Model Target and VuMark support remain in scope for the project; the email does not announce their retirement. Scope: - Remove `create_cloud_database` and the `create-vws-cloud-database` command, including cloud-specific portal selectors, license selection, waits, options, and help snapshots. - Remove cloud database detail/key retrieval (`get_database_details`, the cloud `DatabaseDict`, and `show-database-details`) and any cloud-only navigation helpers. - Preserve portal login, shared license management/navigation, VuMark database creation/details and template operations, and Model Target OAuth2 credential creation/deletion/details. Split shared helpers where necessary rather than removing functionality these APIs still require. - Remove cloud-only browser tests, live setup/cleanup, credentials, examples, and dependencies; retain tests for the supported portal operations. - Update README/CLI/API documentation and release notes, and coordinate changes with downstream CI provisioning that currently uses this package to create cloud databases. Related library removal: Done when the public API, CLI, and CI no longer provision or retrieve credentials for cloud image databases, and Model Target/VuMark portal operations remain usable.
