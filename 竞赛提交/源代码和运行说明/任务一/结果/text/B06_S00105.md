## 正文
I am using MLflow (3.7.0) with PyTorch (2.5.1 + CUDA). How can I get model(NO REGISTERED) names from MLflow? I have a function that saves a model whenever it improves compared to the previous epoch. I log the models like this: mlflow.pytorch.log_model( model_cpu, name=name, step=epoch, signature=self._create_mlflow_signature(model_cpu), await_registration_for=0 ) Now I want to retrieve the models I need (I don’t need to register them) and use them to make predictions. To do this, I need to know their name and run_id. At the moment, I load the models I need like this: import mlflow mlflow.set_tracking_uri(" ) run_id = 'c1fc86256ed64b6ea1c71ea4122f07be' model_name = 'checkpoint_epoch_2' model_a = mlflow.pytorch.load_model( f"runs:/{run_id}/{model_name}" ) However, I want to programmatically list all the models logged in a run. I want to get all the names of my models not through the UI, but through python code. I tried: from mlflow.tracking import MlflowClient mlflow.set_tracking_uri(" ) # MLflow tracking server client = MlflowClient() experiment_id = "1" artifacts = [] runs = client.search_runs( experiment_ids=[experiment_id], filter_string="", order_by=["attributes.start_time DESC"] ) for run in runs: run_id = run.info.run_id artifacts_from_run = client.list_artifacts(run_id) artifacts.append({ 'run_id': run_id, 'artifacts': artifacts_from_run }) print(artifacts) But the output is always: [ {'run_id': 'd16f236965d34806836b25d2035111b4', 'artifacts': []}, {'run_id': '7e677dbf1c1d4e3cbaaee6cd0377424e', 'artifacts': []}, {'run_id': 'c1fc86256ed64b6ea1c71ea4122f07be', 'artifacts': []} ]
