# Need a good alternative for Atlassian JIRA

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=11203592
- 发布时间：2016-03-01
- 热度：点赞2、评论5

## 正文
I've been using Atlassian JIRA for project management for months now, both in my personal projects and at work. I'm forced to still use it at work but I really want to minimise the need to use it as much as possible. This is why I'm looking for an alternative to JIRA. Main features I use : - Scrum/Agile basics (boards, estimates, sprints) - The ability to create epics (I really like this) - Timetracking (timesheets) I've been using Confluence for wiki pages but seriously I will not miss it one bit. I think any wiki tool is better. Why I don't like JIRA anymore: I just think this product is a joke. I mean sure the core features are very good, which is probably why I signed up in the first place but, loading time is still slow. People complained about this few years ago I don't see that anything has changed. I'm on a cloud instance and seriously pages take 8-9 seconds to load. I was trying to restore my account on a new instance and it doesn't work. I cannot backup again because there is one backup per user every 50 hours. Atlassian wants to be a solution for all your problems. This is why they have few other products besides JIRA, all of which are horrible. They should really focus only on performance which is making their main product impossible to use. rant over. If you have suggestions for products that have basic scrum/agile stuff and time tracking I would love to hear about them :) thank you
