# Automating breakout rooms on zoom by user type?

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=25500427
- 发布时间：2020-12-21
- 热度：点赞2

## 正文
Hi all, I run a non-profit project that provides free math tutoring to K12 students impacted by school closures. We've found that the best way to avoid scheduling conflicts is to let kids drop in anytime in a big zoom room and then assign them to breakout rooms with tutors for 1-1 support. The way masteryhour.org works is that students drop in to our zoom room at 10am or 3pm and we assign them to a tutor and send them to a breakout room. Currently, we've been assigning tutors to students manually, but in order for this to scale, we need to be able to automate the process. We are growing really fast and we need a solution for this problem as soon as possible! The basic tags we need to assign breakout rooms are "student" and "tutor", However, if possible, we'd like to add more specific categories like "can tutor high level math" "prefers to tutor elementary math" "speaks Spanish," as well as recency so we can establish some type of continuity. I'm not sure what the best approach to do this might be - if zoom already has a tagging system or if we want to build a bot to do this project. Would love your thoughts on the easiest way to do this in the short-term. Or if anyone wants to volunteer to set this up for us, we'd love help:)
