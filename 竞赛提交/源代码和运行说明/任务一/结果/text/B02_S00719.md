## 正文
I find it strange that haven't read a lot about GeneXus ( ) in English-speaking forums since it looks like the ultimate solution for software development projects. It is basically a huge code generator targeting different platforms and languages based on a knowledge base. The main philosophy of the tool is that one should spend time to describe program functionality instead of actually coding it. Has anyone used it? What do you think about it?
