## 正文
I recently came across a Telegram channel ( ) with a lot of different software for Telegram coin farming apps. I saw that there were a lot of people using them and a generally active community, which made me trust them. I decided to explore their TG channel in more detail and came across their other software and found a lot of interesting things there. For example, Kozel software is a software that allows you to automate a lot of monotonous operations with a nice and clear interface. For example, I have a farm of Solana wallets (150+) where recently there was airdrop of Pengu token, with the help of this software I sent drops from all wallets to OKX exchange to different addresses, which is very important not to be a sybil! Fast and convenient. By the way, you can see their documentation here - What else I have managed to use: 1. Creating a large number of wallets in various networks. 2. Connecting API exchanges for deposit/withdrawal of cryptocurrencies to a large number of wallets. 3. Transferring tokens from wallet to wallet(s) and back. 4. Using personal RPC, connection of notifications in Telegram after each action (for example, you are withdrawing a token from the exchange and set a random delay after each withdrawal and you need to know whether the token was withdrawn or the exchange API rejected the withdrawal - sometimes it happens). 5. Swaps on popular DEXs. 6. You can bridge tokens from one network to another using their app. I'm sure I haven't described everything as I haven't fully mastered the app yet. Next, I plan to import my EVM wallets..... oh, yes! I forgot to mention about importing and exporting wallets - if you, like me, still have a farm of EVM wallets on which you make activities for drops (e.g. in Base network), you can easily import wallets into the application and make tasks to warm up wallets, as I plan to do now. This is a beta version of the app, I talked to the developers and they said that they have been working on the app for half a year and they are not going to stop. According to them they use the app every day and in the future they plan to develop a whole ecosystem around Kozel. To be more precise, they have already started, there are two other software of their production, which they use together in Kozel. If anyone is interested, you can find out which software they are talking about. I'm thinking of following their example and doing the same. All in all, a very useful software for crypto enthusiasts who want to save their time and automate everything they used to do by hand. I will write here about useful things for crypto!
