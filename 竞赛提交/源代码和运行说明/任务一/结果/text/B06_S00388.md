# Ask HN: What should my job title be?

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=10448697
- 发布时间：2015-10-25
- 热度：点赞1

## 正文
Hi, I'm working as a senior tech writer in the software industry. In particular, over the last year or so I've been working in a project owner capacity for my current company's REST API development projects. Right now the scope of my responsibilities far exceed what was stated in my original job description, to the point that it's effectively become a hybrid role. I should point out here that although I enjoy my job very much, it's more intense due to the REST projects, and I have to work longer hours a lot more frequently compared to before. I didn't really get a pay raise either; I haven't asked for it yet, because I'm still relatively new at this job (1.5 years; the REST stuff started around 8 months ago). Here's a list of my key responsibilities: * Write and manage all technical writing content (2 client-facing developer portals + Confluence), mostly aimed at advanced admins and devs * Write sales/marketing documentation (not so much these days - the company wants me focused on REST) * Write detailed product specs (use cases, edge cases and error cases) for REST APIs and the new developer portal * Break down product specs into Jira tickets * Investigate how related system tiers behave (there is usually no existing specs or docs, and I have to talk to a zillion people and test the product before finally arriving at knowledge which not even the REST devs have) * Advise REST devs on development strategies throughout the sprint (e.g. add so and so columns to store data, return this or that error code, etc) * Guide and assist QA in writing test cases for unit tests, and perform exploratory testing * Sign off on REST APIs and developer portal features On paper I'm still just a Technical Writer. I'm planning to talk to management to get an updated title (partly because some higher-ups don't seem to have any clue about my present role). However, I don't know what it should be. Any suggestions would be very helpful.
