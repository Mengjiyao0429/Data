# Ask HN: Best Options to Start Internal Security Team(s)?

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=20385385
- 发布时间：2019-07-08
- 热度：点赞1、评论1

## 正文
Here's the situation; I work for a company and within the last month we got informed that the product I work on will no longer get exemptions for de from the security policy. So now my manager and their manager are canvasing for ideas on how to address this, with the end result of putting together a team to start ensuring strict adherence to the security policy. Management wants to start doing pen testing, code analysis, threat modeling, etc. I advocated to hire an outside firm because obviously that'd be their specialty but that fell on deaf ears, because money. It'd be "cheaper" to do it in-house instead of out-sourcing it. I responded that sure in the short-term that's true, but a thrown together internal team will have nowhere near the skills an outside firm does and it'll only be cheaper until a security flaw is exploited. But alas, I don't sign the checks so an internal team it is then. I'm under no illusion that I have these skills and I'm aware that other engineers get degrees in this field, so there isn't going to be a "here you go, this is everything you need!" answer. I'm mostly looking for enough information for it to be "good enough" (I know not the best philosophy when it comes to security, but you can only do so much right?). #1 - Are there any tools that we can use to help automate some of this? I've used WireShark in my work to do packet traces for debugging and I've played around with Kali Linux awhile a go in my free time. #2 - What resources would you suggest we investigate to help this internal team learn the concepts and methodologies? I'm trying to get as much of a head start on this as possible, even it it amounts to hey we should check out these technologies. I want our platform to be as secure as possible for our end users.
