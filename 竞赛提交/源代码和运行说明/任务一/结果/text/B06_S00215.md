# AI Coding Assistant for Swift

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=41446224
- 发布时间：2024-09-04
- 热度：点赞1

## 正文
Most of the AI coding assistants don't help developers working on iOS projects as they're IDE based but don't integrate with XCode. Fine (fine.dev) gets around this as it's cloud based. It integrates with GitHub and builds a knowledge graph of your code which the LLM uses to fulfil your coding tasks. Although it's more aimed at backend developers, for iOS developers this is probably the most useful AI dev tool publicly available at the moment.
