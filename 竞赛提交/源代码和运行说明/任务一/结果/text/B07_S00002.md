# Verify Muse text-to-video and text-to-speech artifact delivery

- 来源：GitHub
- 链接：https://github.com/markhuangai/AaA-muse-ai/issues/50
- 发布时间：2026-11-18

## 正文
## What Verify which text prompts Muse can turn into downloadable media and which verified artifacts the worker can deliver. Probe short video and spoken audio separately. For audio, request the plain-text transcript of the spoken line. ## Why Client Chat Completions and Responses currently reject media. A product endpoint needs evidence that Muse can produce a file and a supported way to deliver its bytes to the requesting client. ## Where Start in an owner-authorized Muse chat with synthetic prompts. Follow up in the installed TypeScript worker and the broker's assignment flow after approval for worker validation. [Native API and assignment lifecycle]( ) ## How 1. Ask Muse for a short silent MP4 showing a blue circle cross a light background. Ask separately for a short WAV or MP3 speaking “The blue lantern rests beside the window,” plus the transcript. Begin with available tools and local runtime capabilities. 2. Record time to completion, actual tool or renderer, permission requests, failures, and whether each file can be downloaded and played. Verify format, stream type, duration, byte count and SHA-256 from the received artifact. Compare the spoken sentence with the requested transcript. 3. For each verified format, prove that an enrolled worker can deliver the same bytes over the broker origin for the exact assigned job. Verify that the client can fetch those bytes under its own authority and that a stale or foreign assignment cannot publish a result. Record missing delivery capability as a blocker. 4. Record which capabilities came from a native Muse tool, local rendering or synthesis, or a separate service. Use the verified end-to-end formats to scope the downstream API issue. ## Risk - A tool report can describe a file that exists only in the Muse runtime. Count browser download and worker-to-client delivery as separate checks, each with verifiable artifact bytes. - Media links can expose account data or expire before delivery. Keep test files private and retain sanitized evidence. Verify a bounded, assignment-scoped transfer through the broker origin before the endpoint relies on it. ## Live spike results On November 18, 2026, the owner signed into Muse and authorized the interactive probe and scoped network approvals. The tests used synthetic prompts in one new chat.
