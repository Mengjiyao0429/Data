# I build a WordPress plugin using ChatGPT

- 来源：Hacker News

- 发布时间：2023-03-19
- 热度：点赞2

## 正文
I recently received a request to add a WordPress plugin that would allow users to install Notificationpro's pixel code on their WordPress website. Notificationpro ( ) is a comprehensive tool that enables you to create different widgets for lead collection and showcase social proof to build trust and increase sales. To use Notificationpro, the user needs to load a pixel script on their website. For the first version of the plugin, I decided to add only one function, which is an input field to fill the script that will load in every page's head tag. Although I have never developed any WordPress plugins before, I used ChatGPT for test purposes to see if it could guide me and generate some code for it. To my surprise, it was successful. In addition, I plan to add more functionality to the plugin. While we don't know what the future holds for AI, one thing we can say for sure is that it will help us reduce the hours of work.
