# Remove fixtures and assets specific to Cloud Image Recognition

- 来源：GitHub
- 链接：https://github.com/VWS-Python/vws-test-fixtures/issues/2024
- 发布时间：2026-10-29

## 正文
PTC has notified customers that Vuforia Engine Cloud Image Recognition retires effective **May 2, 2027**. Existing services remain operational during the notice period; after the end-of-life date, Cloud Image Recognition databases and associated services will no longer be available. Source: the PTC Vuforia Team customer email supplied by the maintainer. Remove support for the retiring cloud image service, including cloud image target management as well as recognition queries. Model Target and VuMark support remain in scope for the project; the email does not announce their retirement. Scope: - Audit `src/vws_test_fixtures/images.py`, `metadata.py`, and the pytest plugin for fixtures whose purpose is cloud image target upload, matching, ratings, processing states, recognition queries, or cloud metadata limits. - Remove those cloud-only fixtures, constants, packaged assets, exports, tests, and documentation. This includes cloud image/query size-limit and pixel-limit cases, success/failed-state/rating images, matching-image pairs, and application metadata fixtures where they have no remaining supported consumer. - Check downstream usage in `vws-python`, `vws-cli`, and `vws-python-mock` before removing shared assets. Preserve any fixtures still needed for Model Targets, VuMark generation/output, or the remaining APIs. - Update pytest plugin registration, package data/manifests, dependencies, README examples, and release notes to match the remaining fixture set. - If no supported fixtures remain, explicitly document that outcome and coordinate package retirement with downstream dependency removal instead of retaining an empty pytest plugin. Coordinate with and the cloud-removal issues in the CLI and mock projects. Done when downstream supported suites no longer require cloud-only fixtures, removed assets are absent from the built distribution, and remaining fixtures still work through the installed pytest plugin.
