## 正文
I would like to use a LLM Encoder model to create vector embeddings for certain texts in my dataset. The texts are written as technical problem descriptions by experts who are trying to repair a hardware. The embeddings should then be used as an input for another machine learning model for classification. My problem is that the texts tend to be quite long. They do not follow a structure and contain a lot of protocol information not needed for the technical understanding of the problem (names, emails...). For further use, I would like to extract the technical information from these texts (hardware, changed components etc.) and "keep" only that information in the embeddings. For this, I have thought of the following pipeline: 1. Transformer Encoder-Encoder model for abstracted summarization: Creates a summary of the text that focusses only on the technical information. For instance facebook/bart-large-CNN. 2. Sentence Transformer model to create embeddings of the summarized texts. 3. Use embeddings as input for a classification task. As I am a beginner in "practical" use of machine learning and NLP, I would be very glad if you could give me any heads up on how to perform this task best. Does my recommended approach make any sense, or should the creation of the embeddings be done differently? Does it make sense to finetune the summarization model to the domain-specific task that I have? I hope that my question meets the Stackoverflow standards. I would be very glad for any help.
