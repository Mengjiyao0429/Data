# Ask HN: Is anyone still programming the old-fashioned way (without LLMs)?

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=44230859
- 发布时间：2025-06-09

## 正文
I don't use any AI code editor. Not because it isn't useful, but the user experience of using it is so bad. I typically already have the solution at hand - I don't need an AI to give me an answer, I need it to implement the solution I have. But not using AI is also idiotic right now, at the very least you should be using it for autocomplete, in the _vast_ majority of cases any current leading LLM will return _far more_ than not using it (in the scope of autocomplete).
