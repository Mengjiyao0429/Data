## 正文
Hey, As in the title - how do you find contributors to your open source projects? I enjoy starting projects and making them to the point they just work (think MVP), but they need polishing to become production-ready. They would benefit from more features, better cross environment support and less bugs. I would put time and support to improve coding skills of my contributors by giving code reviews and 1-on-1 mentorship But how do one starts with this? My projects are already openly available on GitHub, but I see very little traction on them. One main reason is likely they are not that interesting and good enough to another developers But maybe some people would find them interesting as I do, so how to find these people? Just in case someone here is interested in building their open source contributions track, here's the list: - [Python, TypeScript, Next.js] Gdańsk AI - Full stack AI voice chatbot (speech-to-text, LLM, text-to-speech) with integrations to Auth0, OpenAI, Google Cloud and Stripe - Web App, Web API and AI API - [Python, TypeScript] Spellbook - Shell and Powershell scripts registry - demo - [Python] ktotu - Identify devices in your network and monitor it against intruders - [Rust] pff - Examine your Internet connection quality and status in terminal - [Rust] xiexie - Static site generator - [CSS] Bulma helpers - Library with Functional / Atomic CSS classes for Bulma framework - [Vue, JavaScript] Basic Vue Chat - Easy to use Vue chat Thanks!
