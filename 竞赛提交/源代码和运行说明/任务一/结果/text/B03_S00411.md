## 正文
Basically what happened is that due to some strange luck I have gotten a real-time OLAP mysql database for 3 months with a storage of 2000 GB. This is the first time I've come into contact with OLAP so I'm still reading up on it. (am still looking into this HN Post: ["The Rise and Fall of the OLAP Cube"]( ) && also on [OLAP mining]( ) ) From what I understand an OLAP mysql db is basically a highly performative mysql db that can do very fast search on a large amount of data (with the so-called OLAP operations to cater for the needs to do boring business logic in a more organised way), and is extended with co-operate-ish data visualisation tools. Presumably an OLAP mysql db is something that early-stage start-ups won't touch at all because most of the things are kind of useless unless you have a lot of transaction-related data, or very complex business logic with data in a very weird shape, etc. (as far as my understanding goes) So here I'm wondering if anyone knows or has experimented interesting use cases of real-time OLAP sql db? e.g. in an app that does NLP or video processing? Or more generally, in machine learning and neural networks? Or what are some possible use cases e.g. in reinforcement learning or evolution algorithm that has to perform search & access GBs of data in real-time? Or in knowledge representation? Or automated reasoning? Many thanks!
