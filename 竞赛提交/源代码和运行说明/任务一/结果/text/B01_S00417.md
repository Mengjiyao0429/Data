# Ask HN: What would you like in a workflow builder inside a CRM?

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=39533743
- 发布时间：2024-02-28
- 热度：点赞3

## 正文
We are building a CRM software which converges a lot of tools. Think of your customer support, engineering, sales working out of one unified system, eliminating the need of dozens of tool and tools for stitching tools together. On this unified system of record, we are building a no code/low code workflow builder(ofcourse it will have external triggers and actions both). What would you like in this workflow builder? What is the best and worst in workflow builder(or similar solutions) in tools like Zendesk, SNOW, Jira etc? Particularly fed up with workflow automation tools, which does not give me better logic constructs to use on the UI. Zendesk only have an "if" statement which you can use in their workflow builder. Can't imagine ANY sophisticated real life process implemented there. ServiceNow has a lot of these logic constructs but the design is absent there. You need training. What do you guys think about the AI piece in workflow builder? Anyone finding "give me a prompt and I will make a draft workflow for you" approach helpful? Zapier has introduced it. Does it work for complex cases?
