# Solution for computing equity portfolio using transaction list

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=39051962
- 发布时间：2024-01-19
- 热度：点赞1

## 正文
Greetings I'm looking for an API or open source package that takes in a list of transactions (equity/futures/etc), and then performs various computations over it. This includes things like calculating current holdings, providing an RoI chart and potentially other financial metrics like Sharpe Ratio. I initially set out to code this myself by taking the individual prices of the equities (from something like Yahoo Finance), however, soon enough I realised that things like stock splits, mergers, dividends, etc make this task much more complicated than I expected. Since this is a relatively complicated tooling (which almost every finance-related website would have a need for), I expected that there would be an existing software or a SaaS solving this problem, but couldn't find any. Could someone point me in the right direction?
