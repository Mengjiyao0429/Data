# Ask HN: OCR or integrated system for company financial accounts extraction

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=31847564
- 发布时间：2022-06-23
- 热度：点赞2、评论1

## 正文
I have been investigating tools for managing large volumes of financial statements, as part of an operational process for an SME lender, and OCR for financial statements seems to be the most likely candidate. (Financial statements specifically: Cash Flow Statement, Income Statement, Balance Sheet) I have struggled to find a vendor that ticks all of the following, and looking for suggestions: 1. OCR of financial statements of individual companies 2. Maintain a custom "Chart of Accounts" for each company, which is customisable by a credit analyst role 3. Ability to create persistent rules for each company 4. Bonus to be able to connect directly or API aggregator if the company will agree to this (eg Xero API or codat API aggregator) to pull real time raw ledger and build the accounts. NB - Not looking for OCR of invoices, bank statements and receipts, that is quite commonly available
