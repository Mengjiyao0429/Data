# [Feature Request] Add audio preview samples for built-in Text-to-Speech voices in Unsloth Studio

- 来源：GitHub
- 链接：https://github.com/unslothai/unsloth/issues/18251
- 发布时间：2026-11-18

## 正文
### Environment - **Platform:** Unsloth Studio Desktop (`0.1.919-beta`) - **OS:** Windows 11 - **Model:** `Kokoro-82M-GGUF` (`kokoro-82m/Q8_0`) ### Problem In **Audio → Text to Speech**, the **Voice** dropdown lists numerous built-in speakers (e.g., *Alloy, Aoede, Bella, Heart, Jessica, Kore, Nicole, Nova, River, Sarah, Sky, Adam, Echo, Eric, Fenrir, Liam*, etc.) with only text labels for language/accent and gender, and no audio preview. Because there is no way to hear how a voice sounds beforehand, users either waste time generating throwaway test clips for every voice or repeatedly stick to one or two familiar voices. ### Proposed Solution - Add a play/preview icon button next to each built-in voice inside the **Voice** dropdown list and next to the active voice selector. Like I added sound effect previews in #16365 that not yet accepted. I am really waiting to use voice typing feature with its lightning fast speed and features that it packs. - Play a short bundled sample clip (e.g., *"Peace Be Upon You!"*, *"Adam's voice is very famous."*) on click so users can audition built-in voices instantly without running a full generation. ### Prior Research Searched `is:issue tts voice preview` and `is:issue built-in voice sample` in `unslothai/unsloth` before opening; no existing request for built-in TTS voice previews in Unsloth Studio was found.
