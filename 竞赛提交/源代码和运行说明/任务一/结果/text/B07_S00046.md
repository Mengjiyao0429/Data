# Software to turn my Android phone into an AI agent

## 正文
Context : I need to find the best deals for a particular product on shopping websites, currently Antigravity does this for me on my laptop. Problem : I can't leave my laptop running all the time. Non-solution : Many people buy tiny computers such as Mac Minis to run AI agents on them. But I don't want to buy more hardware. Idea : I believe my Android phone could perform such tasks. It can only run smaller LLMs, but that could be good enough, and I am hopeful embedded models will get better soon. Requirements: Must be able to run without interfering with my normal phone usage. Must be able to run even when the phone is locked. Must have an option to run only when the phone is charging. Must be able to run Gemini Nano. Must have a way to send instructions, and check progress/results, on the phone itself. Must be open source. Nice to have: Ability to run other models. Interface to send instructions, and check progress/results, from other devices. Note: Android is quite strict with background apps and doing stuff while the screen is locked, so I believe I will need someone more heavy-handed than an app. I am OK with using Magisk-type software, or even a modified AOSP image as long as it is open source.
