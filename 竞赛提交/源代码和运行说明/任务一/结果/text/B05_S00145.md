# Ask HN: Would you use a tool that builds AI agents from a prompt?

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=44021047
- 发布时间：2025-05-18
- 热度：点赞1、评论3

## 正文
I’m building a web app where you describe what you want in plain language e.g. “an agent that replies to customer emails using ChatGPT and Gmail” and it builds the automation for you. No APIs, no code, no setup. Just describe the outcome, and it generates the agent + connections. The idea is to help people (especially small teams and solo founders) offload repetitive tasks without technical overhead. Would this be valuable to you? What would you want it to automate?
