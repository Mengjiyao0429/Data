# Ask HN: Getting started with automated trading?

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=1752835
- 发布时间：2010-10-03
- 热度：点赞3、评论6

## 正文
I want to get into automated trading (individually) to validate a few ideas about markets. I read Larry Harris' book Trading and Exchanges and am confident that I could write a computer program that trades on my behalf. Now I have a whole bunch of technical questions: 1) Which platform should I use for trading? I need a solution that allows me to backtest my algorithms and executes trades quickly. Ideally I'd not have to install anything and I'd like to write trading strategies in whatever programming language I like. A platform with an API sounds best. 2) What are other features to consider when choosing a platform? 3) Is there any way to get into high-frequency trading as an individual investor? How fast can a trade be executed using any automated trading platform? 4) Are there any good communities around this topic? 5) Is there anything else I should know?
