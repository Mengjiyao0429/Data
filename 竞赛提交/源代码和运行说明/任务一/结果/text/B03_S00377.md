# What cartoonists (and moviemakers) need in an AI tool

- 来源：Hacker News
- 链接：https://news.ycombinator.com/item?id=32691168
- 发布时间：2022-09-02
- 热度：点赞7、评论1

## 正文
Everyone here has probably seen the current MidJourney, Dalle2, and StableDiffusion tools (which are getting updates every few weeks). There has been talk of an 'Anime' version of stable diffusion. What we need for that is 1. Characters. An interface that allows us to save Characters with a name, so that we can prompt with that name to employ the character. (Currently, people storyboarding with AI image generation use famous actors because they're the only thing the AI can reproduce in each scene). It would be nice if we could also save a few images of the character, from different angles, so the AI knows what they look like and can produce fewer mistakes. 2. Clothing. Characters needs to keep / change clothing based on the scene. This could be done by naming clothing, or with a prompt-language such as 'clothing-234j320' and this number corresponds with an image we already generated, which has been assigned an image number. 3. Locations. Same. We could also have a prompt, 'same-location-as-previous' or 'same-location-as-234j320' 4. Style. Putting several prime example images into a folder to indicate the style of render. Better than 'realistic' or 'photorealism' or 'anime'. 5. Angle. Zoom / crop / indicated angle (possibly from model of a 'sphere around the scene'). eg 'closer-zoom than this' or 'from-Zaxis-45/90-from-Y-axis-50'. Usually, the angle doesn't need to be specific, or can be like 'viewed from above' but occasionally a specific angle is needed.
