## 正文
I maintain a set of REST microservices (Go and Node.js, running in Docker on Linux) and our API regression suite is mostly hand-written Postman collections. Keeping them updated as endpoints takes too much time, and our mocks for downstream services (Postgres, Redis, a couple of third-party APIs) drift from real behaviour. I’m looking for a tool that can: Generate API test cases automatically, ideally by recording real requests/responses rather than me writing each assertion Create mocks/stubs for dependencies (DB calls, external HTTP) from that same recorded traffic Run headless in CI (GitHub Actions) and fail the build on regressions Run on Linux, either open-source or with a usable free tier Ideally not require code changes or SDK instrumentation in every service What I’ve looked at so far: Postman/Newman and REST Assured work, but tests are still written by hand. What would you recommend, and how well does it handle noisy fields like timestamps and random IDs in responses?
