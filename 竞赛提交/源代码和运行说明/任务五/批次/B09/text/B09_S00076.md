Hi HN I built Sidekick AI, an open-source VS Code extension that works like GitHub Copilot. But it’s 100% local, free, and privacy-first. Why? I saw developers struggling with: Paying $10/month for Copilot Code being sent to cloud servers (privacy + compliance issues) Slow responses on weak internet connections Painful account/payment setups I wanted to build something different: a tool that anyone can install in 2 minutes, that runs entirely on their machine, with no subscriptions or cloud dependency. What Sidekick AI Does (Today in v1): -Inline completions (~450ms latency on CPU) -Copilot-style interactive chat -Smart code fixes + context-aware refactoring -Code explanations (great for onboarding/learning) -Automatic unit test generation Tech Details: Current model: Qwen 2.5 Coder (1GB) → lightweight Achieved 30 tokens/sec on local hardware using llama.cpp + smart caching Multi-language support (8+ languages) via prompt engineering Built-in server health monitoring + auto-restart for stability 2-minute zero-config setup wizard (detects and configures automatically) Roadmap: Adding DeepSeek Coder 6.7B in v2 → should bring it close to Copilot-level performance while staying fully offline. Impact So Far: Already 70+ organic downloads on the VS Code Marketplace (no marketing, just devs finding it). Early feedback: devs like it for privacy, offline workflows, and avoiding subscription costs.
