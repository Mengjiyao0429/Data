## 正文
I'm creating RAG using Azure technologies. To do that I need to stream content to frontend to quick result. Otherwise it takes a long time to respond. Here is my ASP.NET Core Web API code: [HttpPost("getCopilotResponseV3")] public IEnumerable<string> GetCopilotResponsev3(BLCopilotRequestV2 req) { CollectionResult<StreamingChatCompletionUpdate> response; try { response = _bLOpenAIService.GetOpenAIResponseStream(req); } catch (Exception ex) { _logger.LogError(ex, "Error getting OpenAI response stream."); yield break; } var enumerator = response.GetEnumerator(); using (enumerator) { while (enumerator.MoveNext()) { foreach (var cnt in enumerator.Current.ContentUpdate) { yield return cnt.Text; } } } } Here is the Angular service code I wrote: requestFromBLCopilotAIV3(request: BLCopilotRequestV2) { return this.http .post(environment.getEndpoint() + 'Common/getCopilotResponseV3', request,{ responseType: 'text',observe: 'events' }); } This is the frontend component code: this.copilotService.requestFromBLCopilotAIV3({ messageList: cpMessageList, indexName: this.copilotComponent.defaultValue, semanticConfigName:this.copilotComponent.mapName } as BLCopilotRequestV2) .pipe(takeUntil(this.stopSignal)) .subscribe({ next: (event : any) => { console.log(event) }, complete: () => { //this.changeDetector.detectChanges(); }, error: (err) => { console.error(err); this.isLoading = false; this.responseStarted = false; this.changeDetector.detectChanges(); } }); When I am testing console, the code will print something like this: { "headers": { "normalizedNames": {}, "lazyUpdate": null }, "status": 200, "statusText": "OK", "url": " "ok": true, "type": 4, "body": "[\"The\",\" requested\",\" information\",\" is\",\" not\",\" available\",\" in\",\" the\",\" retrieved\",\" data\",\".\",\" Please\",\" try\",\" another\",\" query\",\" or\",\" topic\",\".\"]" } It's ok content not found response is not a problem, but this is not my expected output. My expected output would be: the requested information is not found like one by one response. yield return seems ok. How can I have that kind of output instead getting the entire response?
