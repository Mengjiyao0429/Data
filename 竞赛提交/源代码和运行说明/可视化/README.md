# 可视化：任务一～任务四 信息量与分析过程图表

本文件夹保存全流程可视化图表与可复现脚本，用于直观展示“数据信息量”与“分析过程”，
同时可作为赛题“成果附件（以图片形式保存全流程结果）”的图表素材。

**口径：v4 需求导向数据（4322 条 / 1728 机会 / 55 簇 / 阈值 0.60 / 权重 0.293、0.5065、0.2005）。**

## 目录

```
可视化/
├── README.md        # 本说明
├── make_charts.py   # 图表生成脚本（matplotlib，直接读取仓库真实结果文件）
└── 图表/            # 14 张 PNG（200 dpi）
```

## 复现

```bash
python 可视化/make_charts.py
```

数据来源全部为仓库内真实结果文件，不引入任何外部或手工数据：

- `任务一/结果/result1.csv`（+ `text/` 正文快照）→ 图 01–04
- `任务二/结果/result2.csv`、`任务二/源码/gold_labels.csv` → 图 05–08
- `任务三/结果/result3.csv`、`任务三/结果/result3_聚类元信息.json` → 图 09–11
- `任务四/结果/result4_中间指标.json`、`result4.csv` → 图 12–14

依赖：Python 3 + matplotlib + numpy（图 11 另需 scikit-learn）。中文字体使用 Microsoft YaHei / SimHei。
