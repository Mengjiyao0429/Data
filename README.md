# Data —— AI 应用场景的智能挖掘与机会评估系统

第三届甘肃省大学生数据挖掘挑战赛（本科组）参赛作品仓库。赛题要求围绕“AI 应用场景”，
完成从多源数据采集清洗到结果呈现与决策支持的端到端分析，各环节结果可溯源至原始记录。

## 当前进度

- **任务一已完成（已更新）**：多源采集、清洗、去重后保留 **5517 条**真实记录，分 B01–B05 **五个批次**，
  含 12 个公开来源、5517 个正文快照，结果见 `任务一/结果/result1.csv`（另附 Excel 版）。
- **任务二已完成（已随新数据集重跑）**：对任务一同一批次的 5517 条记录逐条判别是否构成 AI 应用机会并给出置信度，
  对判为机会的记录标注功能类别与所属行业；判为机会 **388 条（7.0%）**，
  结果见 `任务二/结果/result2.csv`，附逐条证据链、验收报告与质量评估报告
  （人工标注集 116 条：Accuracy 0.845 / Precision 0.630 / Recall 0.967 / F1 0.763）。
- **任务三已完成**：对 388 条机会记录做**语义级聚类**（jieba 分词 + TF-IDF + LSA 96 维 + KMeans，k=14，
  以 NPMI 主题一致性 + 规模均衡 + 稳定性 ARI=0.408 选优），形成 **14 个主题簇**，覆盖全部 388 条、无遗漏无重复；
  簇内机会记录统一为 `Bxx-Sxxxxx` 批号限定格式，可唯一溯源。结果见 `任务三/结果/result3.csv`，
 附主题簇报告（含逐簇 NPMI/轮廓/余弦相似度）与 388 条机会快照。
- **任务四已完成**：对 14 个主题簇从「多源指向度 / 记录规模 / 商业信号」三维度各打 0~100 分，
  按 0.35/0.35/0.30 加权合成机会价值分并给出优先级（1 最高）；权重敏感性分析 Spearman ≥ 0.98，排序稳健。
  结果见 `任务四/结果/result4.csv`（C1 大模型 API 与行业应用开发 99.4 居首）。
- **可视化已完成**：基于任务一～四真实结果文件生成 **14 张图表**（`可视化/图表/`），
  覆盖全流程漏斗、批次×来源构成、发布时间、正文长度与语种、各批次机会率、置信度分布、
  功能类别与行业、混淆矩阵、簇规模与质量指标、簇×来源热力图、语义空间散点、价值分排序、
  三维度加权贡献、权重敏感性，脚本 `可视化/make_charts.py` 可一键复现。
- **任务五已完成**：实现结果呈现与决策支持——离线可用的**仪表盘**（KPI、全流程漏斗、价值排序、
  三维度贡献、簇×来源热力图、检索筛选、抽屉式溯源），支持按价值分/优先级选取高价值主题簇；
  每个主题簇可**一键生成立项策划案**并下载 Markdown（目标用户与痛点、核心功能、技术路线、实施周期、
  WBS、依据来源、价值评分、成本与风险），14 份策划案见 `任务五/示例立项策划案/`；
  并明确角色与权限（需求发起者/决策者）、成本资源与部署运行说明。

## 数据链路

任务一清洗记录 → 任务二机会判别与归类 → 任务三机会记录主题聚合 → 任务四主题簇价值评分排序
→ 任务五结果呈现与决策支持（仪表盘 + 立项策划案），
各环节使用同一批次数据，保证研究链条一致、可复现、可追溯。
