# Data —— AI 应用场景的智能挖掘与机会评估系统

第三届甘肃省大学生数据挖掘挑战赛（本科组）参赛作品仓库。赛题要求围绕“AI 应用场景”，
完成从多源数据采集清洗到结果呈现与决策支持的端到端分析，各环节结果可溯源至原始记录。

## 当前进度

- **任务一已完成（已更新）**：多源采集、清洗、去重后保留 **5517 条**真实记录，分 B01–B05 **五个批次**，
  含 12 个公开来源、5517 个正文快照，结果见 `任务一/结果/result1.csv`（另附 Excel 版）。
- **任务二已完成（已随新数据集重跑）**：对任务一同一批次的 5517 条记录逐条判别是否构成 AI 应用机会并给出置信度，
  对判为机会的记录标注功能类别与所属行业；判为机会 **388 条（7.0%）**，
  结果见 `任务二/结果/result2.csv`，附逐条证据链、验收报告与质量评估报告
  （人工标注集 116 条：Accuracy 0.845 / Precision 0.630 / Recall 0.967 / F1 0.763）。
- **任务三已完成**：对 388 条机会记录做 TF-IDF + 余弦 KMeans 语义聚类，形成 **14 个主题簇**
  （k 由轮廓系数选定），覆盖全部 388 条、无遗漏无重复，结果见 `任务三/结果/result3.csv`，
 附主题簇报告、验收报告与 388 条机会快照。
- 任务四已建立目录与方法说明，将基于任务三的主题簇做价值评分与优先级排序。

## 数据链路

任务一清洗记录 → 任务二机会判别与归类 → 任务三机会记录主题聚合 → 任务四主题簇价值评分排序，
各环节使用同一批次数据，保证研究链条一致、可复现、可追溯。
