## 正文
Yeah, Scratch helped bootstrap so many folks, but that was a generation ago -- I can't imagine exhorting children to learn to code with Scratch (or any other Visual Programming Language) in good faith today. If you're trying to get away from the burden of syntax or other onerous aspects of coding, well then just use an AI coding assistant. OTOH, if you (for some reason) want to learn a textual programming language, then write code in that language yourself.
