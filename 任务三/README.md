# 任务三：赛道热点主题聚合（语义级 v3）

第三届甘肃省大学生数据挖掘挑战赛（本科组）赛题《AI 应用场景的智能挖掘与机会评估系统》。
本文件夹完整保存任务三的目标、方法、所用数据、结果与源码，可复现。

> 输入：任务二判为“机会”的 **388 条**记录（跨 B01–B05）。
> 输出：**14 个主题簇**，覆盖全部 388 条机会记录，产出 `result3.csv`（官方 8 列）。

## 一、任务目标

对任务二判为机会的记录做**语义级聚类**，形成若干主题簇；为每簇提炼**一句话主题名称**；
统计簇内机会记录数与来源网站覆盖，识别多源共同指向的热点；列出簇内机会记录编号以便溯源。
对应官方列：

`采集批次号, 主题簇编号, 主题簇名称, 功能类别, 所属行业, 簇内机会记录数, 来源覆盖, 簇内机会记录`

## 二、方法（语义级流水线）

1. **分词与向量化**：对每条机会记录正文（任务二快照“## 正文”之后）用 **jieba** 中文分词
   （内置 AI 术语词典，如大模型/智能体/知识图谱/检索增强等），英文词保留；再构建 **TF-IDF**
   （ngram 1–2，min_df=2，max_df=0.6，sublinear_tf）。
2. **语义投影**：**TruncatedSVD（LSA）** 把高维稀疏 TF-IDF 投影到 96 维稠密语义空间
   （累计方差 0.449），用低维语义向量替代词频向量，缓解同义/近义分散问题。
3. **候选聚类**：KMeans 与层次聚类（Ward），在 k∈[12,20] 上生成候选方案。
4. **评估方案（自设计）**：五指标归一化加权——
   - 轮廓系数（紧密度，权重 0.20，越大越好）；
   - Davies-Bouldin 指数（类内紧致/类间分离，权重 0.20，越小越好）；
   - Calinski-Harabasz 指数（类间方差比，权重 0.15，越大越好）；
   - **NPMI 主题一致性**（基于簇内 Top-10 词共现，权重 0.30，越大主题越连贯）；
   - 簇规模均衡度（1 − 最大簇占比，权重 0.15，越大越均衡）。
   最终在“最大簇占比 ≤16%”约束下最大化 NPMI → **KMeans，k=14**。
5. **稳定性检验**：5 次不同随机种子 KMeans 两两 ARI 均值 = **0.408**，验证划分稳健。
6. **主题命名**：先由 c-TF-IDF 高权重词自动提取概念词，再**人工核定**一句话主题名
   （映射固化在 `源码/curated_names.json`，按**批号限定**的簇内记录编号确定性匹配，可复现）；
   功能类别、所属行业同步按簇内容与附件1 标签体系核定，避免继承任务二的单标签误判。
7. **溯源修复（关键）**：聚类跨 B01–B05，而各批次记录编号都从 `S00001` 独立编号，若「簇内机会记录」
   只存 `Sxxxxx` 会产生**跨批次歧义**（同一簇可能同时出现 `B01-S00005` 与 `B02-S00005`，显示为两个 `S00005`）。
   现已统一输出为 **`Bxx-Sxxxxx` 批号限定格式**，并同步重建 `curated_names.json` 的 key，保证簇→原始记录唯一可溯源。
8. **热点识别**：来源覆盖含 2 个及以上网站的簇判为“多源共同指向”的热点。

## 五、如何复现

```bash

python cluster_task3.py
```

依赖：`numpy`、`scipy`、`scikit-learn`、`jieba`（requirements 见 `ai-opportunity-system/requirements.txt`）。
固定随机种子 SEED=42，重复运行结果确定。脚本自动从 `任务二/结果/result2.csv` 读取机会记录、
从 `任务二/正文快照` 读取正文，并向 `任务三/结果/result3.csv`、`task3_主题簇报告.md` 写入产物。

## 六、如何验证

1. `result3.csv` 表头与官方 `附件/result3.csv` 模板一致（8 列）。
2. 每行“簇内机会记录”按 `；` 拆开，均为 **`Bxx-Sxxxxx` 批号限定**格式，逐条回查 `任务二/结果/result2.csv`
   的 (采集批次号, 记录编号)，均应为“是否构成机会=1”；14 簇合计 388 条，等于机会集总数，
   批号限定后**簇内与全局均无重复**。
3. 每簇“簇内机会记录数”等于该行记录编号个数。
4. 功能类别、所属行业均取自附件1 的 16 类 / 30 类标签体系，无自造标签。
5. 任意编号可在 `机会快照/` 找到对应正文，核对主题归属。

## 七、评估结论与已知局限（如实说明）

- **主题一致性较好**：NPMI = 0.436（全簇均值），簇内关键词共现较强，主题可读。
- **逐簇质量指标（新增）**：报告第三节给出每簇的 NPMI、轮廓系数、簇内平均余弦相似度与行业标签一致率。
  小簇（C12 医疗影像、C13 教育、C14 能源）NPMI 与簇内余弦相似度最高（主题最紧凑）；
  大簇（C1/C2 大模型 API 宏观赛道）覆盖多来源多子主题，NPMI 相对偏低，属宏观簇的正常特征。
- **簇规模均衡**：最大簇占比 15%，无极端巨簇。
- **稳定性中等**：ARI = 0.408，说明 14 簇划分在不同随机种子下基本稳定，但仍存在簇间重叠。
- **轮廓系数偏低（约 0.06）**：机会记录以中英混杂、短文本为主，高维稀疏语义空间下轮廓系数
  结构性偏弱，属短文本聚类的常见现象；本任务以 NPMI 主题一致性 + 均衡度 + 稳定性共同佐证，
  不依赖单一轮廓系数。
- **英文开源/问答记录主题天然交叠**：数据约 77% 为 GitHub/SO 英文内容，部分簇（如 C1/C2/C4）
  属于“AI 应用开发”宏观赛道，主题粒度较粗；中文 CSDN 内容（如 C10 知识图谱增强检索、
  C12 医疗、C13 教育、C14 能源智能体）主题则更清晰。
- **主题名经人工核定**：一句话主题名在关键词自动提取基础上经人工凝练，符合大赛“人工核验、
  避免 AI 味”的使用规范。
